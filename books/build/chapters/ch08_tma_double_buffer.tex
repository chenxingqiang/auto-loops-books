\section{Double-Buffer Pipelines: Depth Decision Method}
\label{sec:ch08_pipeline_theory}

A software pipeline overlaps stage $n{+}1$ load with stage $n$ compute \citep{dao2022flashattention,dlbook,semianalysis2024tma}.
\textbf{Double-buffering} is the minimum depth (two buffers); deeper pipelines help only until the bottleneck stage saturates \citep{shah2024flashattention3,memoryfloor2026}.

\paragraph{Serial vs overlapped baseline.}
Without pipeline, each tile pays $t_{\mathrm{load}} + t_{\mathrm{compute}}$ serially \citep{dlbook,patel2025llminference,semianalysis2024tma}.
With ideal ping-pong on load-bound tiles, steady state pays $\max(t_{\mathrm{load}}, t_{\mathrm{compute}})$ per tile after prologue \citep{shah2024flashattention3,dao2022flashattention}.
The gap is the pipeline dividend---bounded by bandwidth, not arithmetic peak \citep{memoryfloor2026,taxbreak2026,yirage2026}.

\paragraph{When not to pipeline.}
If $t_{\mathrm{compute}} \gg t_{\mathrm{load}}$, deeper buffers do not help---fix compute or add consumers (Ch.~7) \citep{shah2024flashattention3,patel2025llminference}.
If $N{=}1$ tile per token and depth$>2$, prologue may erase benefit---stay serial or use persistent outer loop \citep{mpk2025,nvidia2024cudagraphs,taxbreak2026}.
If Ch.~6 cannot fit $2b$ bytes, do not pipeline---split fusion first \citep{memoryfloor2026,yirage2026,chen2020compilerbasedhardw}.

\paragraph{Three-step depth decision.}
\textbf{Step 1---Stage throughput ratio:} measure $t_{\mathrm{load}}$ and $t_{\mathrm{compute}}$ per tile \citep{shah2024flashattention3,patel2025llminference}.
Bottleneck $B = \max(t_{\mathrm{load}}, t_{\mathrm{compute}})$; steady-state step cost $\approx B$ after prologue \citep{semianalysis2024tma,dao2022flashattention}.
\textbf{Step 2---Buffer budget:} from Ch.~6 fast-memory cap, subtract resident tensors and sync metadata; divide by tile bytes for max depth $D_{\max}$ \citep{yirage2026,chen2020compilerbasedhardw,dao2022flashattention}.
\textbf{Step 3---Marginal benefit:} with $N$ tiles/token, prologue/epilogue cost $\approx (D-1)\cdot B$ each; deepen only if $N \gg 2(D-1)$ and $D \le D_{\max}$ \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.

\paragraph{Bandwidth floor.}
Pipelining cannot beat bytes/token bandwidth limit---it removes serial load+compute waste \citep{memoryfloor2026,taxbreak2026,patel2025llminference}.
Residency (Ch.~6) reduces bytes; pipeline ensures remaining bytes overlap compute \citep{dao2022flashattention,kwon2023vllm,yirage2026}.

\paragraph{Multi-stream rule.}
Weight and KV streams have different sizes and lifetimes---separate depth per stream \citep{kwon2023vllm,dao2023flashdecoding,shah2024flashattention3}.
Unified depth is anti-pattern~4 (Section~\ref{sec:ch08_pipeline_pitfalls}) \citep{yirage2026,patel2025llminference}.

\paragraph{Attention-layer pipeline sketch.}
QKV projection: weight stream dominates---depth from weight tile bytes \citep{taxbreak2026,shah2024flashattention3}.
Attention matmul: KV stream joins---split streams before depth search \citep{kwon2023vllm,dao2023flashdecoding,dao2022flashattention}.
Output projection: similar to QKV---reuse weight stream template \citep{yirage2026,patel2025llminference}.
Document per-subgraph depth in pipeline IR---monolithic depth fails \citep{chen2020compilerbasedhardw,wu2024mirage}.

\paragraph{MoE and pipeline.}
Expert weights increase bytes/step---load-bound regime strengthens \citep{taxbreak2026,liu2024deepseekv3}.
Pipeline hides latency but not expert routing dispatch (Ch.~7 L3) \citep{mpk2025,wu2024mirage,patel2025llminference}.
Per-expert fusion still needs ping-pong inside expert GEMV \citep{yirage2026,memoryfloor2026,shah2024flashattention3}.

\paragraph{Quantization interaction.}
INT4/FP8 weights shrink tile bytes---may reduce $D_{\max}$ need but increase pack/unpack compute \citep{taxbreak2026,patel2025llminference}.
Re-run step 1 after quant---bottleneck may flip to compute \citep{shah2024flashattention3,yirage2026,memoryfloor2026}.
Pipeline pass should re-search when dtype changes \citep{wu2024mirage,chen2020compilerbasedhardw}.

\paragraph{Benchmarking methodology (Ch.~3 link).}
Report ms/token at batch-1 with pipeline on/off \citep{patel2025llminference,kwon2023vllm}.
Include stall breakdown: memory throttle vs barrier wait \citep{memoryfloor2026,shah2024flashattention3}.
Include bytes/token---pipeline should not increase bytes \citep{taxbreak2026,dao2022flashattention}.
Compare same fusion region---apples-to-apples with Ch.~6 residency held constant \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Prologue/epilogue accounting (decode).}
Let $N$ = tiles per token, $D$ = pipeline depth, $B$ = bottleneck stage cycles \citep{patel2025llminference,dlbook}.
Serial cost $\approx N \cdot (t_{\mathrm{load}} + t_{\mathrm{compute}})$; pipelined cost $\approx (D{-}1)B + N B + (D{-}1)B$ \citep{semianalysis2024tma,dao2022flashattention}.
When $N$ is small (decode), $(D{-}1)B$ dominates---shallow $D$ often wins \citep{memoryfloor2026,taxbreak2026,patel2025llminference}.
Persistent kernels (Ch.~7 L2) amortize prologue across tokens---pair with shallow in-kernel depth \citep{mpk2025,nvidia2024cudagraphs,shah2024flashattention3}.

\paragraph{Step 1 procedure (measurement).}
Profile or model per-tile load latency (TMA completion to mbarrier) and consumer matmul cycles \citep{shah2024flashattention3,patel2025llminference}.
Use Nsight memory throttle vs math throttle warps---not SM occupancy alone \citep{memoryfloor2026,yirage2026}.
Repeat at batch-1 decode operating point---prefill profiles mislead \citep{kwon2023vllm,taxbreak2026}.

\paragraph{Step 2 procedure (budget).}
From Ch.~6 peak worksheet: $M_{\mathrm{fast}}$ = available shared/tile SRAM after residents \citep{yirage2026,dao2022flashattention,chen2020compilerbasedhardw}.
Per-buffer bytes $b$ = tile operand footprint; $D_{\max} = \lfloor M_{\mathrm{fast}} / b \rfloor$ for single-stream \citep{memoryfloor2026,semianalysis2024tma}.
Multi-stream: sum buffer regions---weight and KV buffers do not share addresses \citep{kwon2023vllm,shah2024flashattention3}.

\paragraph{Step 3 procedure (marginal benefit).}
If $t_{\mathrm{load}} > t_{\mathrm{compute}}$, deepening past 2 helps only when extra buffers hide residual load stalls without exceeding $D_{\max}$ \citep{semianalysis2024tma,patel2025llminference}.
If $t_{\mathrm{compute}} > t_{\mathrm{load}}$, pipeline depth cannot hide compute---add consumers (Ch.~7) or shrink tile \citep{shah2024flashattention3,yirage2026}.
Reject depth that fails $N \gg 2(D{-}1)$ for decode layers \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Reading the worksheet.}
Load-bound tile (${\sim}400/300$) $\Rightarrow$ steady step ${\sim}400$ cycles; compute fully hidden \citep{shah2024flashattention3,semianalysis2024tma}.
Small $N$ $\Rightarrow$ stay at depth 2; depth 3 needs enough tiles to amortize extra prologue \citep{patel2025llminference,taxbreak2026}.
Cross-check Ch.~7 producer ratio---pipeline depth does not replace producer capacity \citep{yirage2026,dao2022flashattention}.

\paragraph{Decode vs prefill (operational).}
Prefill: large $N$, thick tiles---deeper pipelines and TMA multicast can help \citep{kwon2023vllm,shah2024flashattention3}.
Decode: small $N$, thin tiles---prologue share and descriptor overhead cap depth \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.
Maintain separate depth worksheets per regime \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Latency hide rate.}
Define hide rate $= 1 - t_{\mathrm{exposed}} / (t_{\mathrm{load}} + t_{\mathrm{compute}})$ under serial baseline \citep{dlbook,semianalysis2024tma}.
Ideal ping-pong on load-bound tiles approaches $t_{\mathrm{compute}} / (t_{\mathrm{load}} + t_{\mathrm{compute}})$ \citep{shah2024flashattention3,patel2025llminference}.
Cannot exceed bandwidth-implied minimum step time \citep{memoryfloor2026,taxbreak2026}.

\paragraph{FA3 lessons without FA3 copy-paste.}
Take async overlap pattern from FlashAttention-3 \citep{shah2024flashattention3}.
Do not take prefill tile shapes, depth-4 defaults, or multicast schedules for batch-1 decode \citep{patel2025llminference,taxbreak2026,semianalysis2024tma}.
Table~\ref{tab:ch08_depth_worked_example} replaces FA3 depth tables for decode \citep{yirage2026,memoryfloor2026}.

\paragraph{Simulation before silicon.}
Pipeline worksheets are hypotheses---validate with stall replay or cycle simulation \citep{patel2025llminference,yirage2026,shah2024flashattention3}.
Reject configs that improve overlap metrics but not tokens/sec at batch-1 \citep{kwon2023vllm,taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Operator fusion boundary.}
Pipeline depth applies per fused region---do not assume one depth for whole model \citep{yirage2026,wu2024mirage,dao2022flashattention}.
Attention subgraph may be load-bound at depth 2; MLP subgraph may be compute-bound at depth 1 \citep{shah2024flashattention3,patel2025llminference,memoryfloor2026}.
Mirage search may propose different fusion boundaries---re-run pipeline pass per candidate \citep{mpk2025,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Carrier tensors and pipelines.}
Softmax carriers from Ch.~6--7 consume register or smem budget---reduce $D_{\max}$ when carriers are large \citep{dao2022flashattention,shah2024flashattention3,yirage2026}.
Pipeline buffers and carriers share the same fast-memory envelope \citep{memoryfloor2026,nvidia2022hopper,amd2024aie}.
Chapter~10 details carrier placement; pipeline pass must reserve carrier home before allocating ping-pong \citep{dao2022flashattention,patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Attach depth worksheet before enabling ping-pong in codegen \citep{yirage2026,dao2022flashattention,chen2020compilerbasedhardw}.

\section{GPU TMA Pipeline Design (Decode)}
\label{sec:ch08_gpu_tma}

Hopper \textbf{TMA} is the async bulk-movement primitive for producer warps (Ch.~7)---hardware detail in Chapter~\ref{chap:ch04} \citep{nvidia2022hopper,semianalysis2024tma,shah2024flashattention3}.
This section covers \emph{pipeline rules}, not ISA catalogs \citep{yirage2026}.

\paragraph{Producer-consumer handshake.}
Ch.~7 fixed \emph{who} issues TMA; this section fixes \emph{when} consumers may read \citep{shah2024flashattention3,yirage2026,semianalysis2024tma}.
The handshake is always: async issue $\rightarrow$ byte-complete signal $\rightarrow$ consumer matmul $\rightarrow$ buffer flip \citep{nvidia2022hopper,dao2022flashattention}.
Breaking any step yields stalls, races, or silent wrong answers \citep{patel2025llminference,taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Decode GEMV pipeline shape.}
Batch-1 decode matmuls are thin---consumer warpgroups may finish before next TMA completes \citep{patel2025llminference,shah2024flashattention3,memoryfloor2026}.
That is acceptable when producers stay ahead; it is failure when consumers wait on mbarrier \citep{semianalysis2024tma,yirage2026}.
Tune producer count (Ch.~7) and pipeline depth jointly---depth alone does not fix insufficient TMA issue bandwidth \citep{shah2024flashattention3,taxbreak2026}.

\paragraph{Persistent kernel interaction.}
Ch.~7 L2 persistent grids loop tokens without relaunch \citep{mpk2025,nvidia2024cudagraphs,shah2024flashattention3}.
Pipeline prologue runs once per grid launch; steady ping-pong runs each token inside the loop \citep{patel2025llminference,yirage2026}.
This is how decode amortizes prologue while keeping shallow in-kernel depth \citep{taxbreak2026,memoryfloor2026,dao2022flashattention}.

\paragraph{L2 multicast caveat (decode).}
Prefill benefits from multicast when many blocks share weights \citep{kwon2023vllm,shah2024flashattention3}.
Batch-1 decode often sees one consumer block---multicast setup may not repay \citep{taxbreak2026,patel2025llminference,semianalysis2024tma}.
Profile bytes moved and descriptor overhead before enabling multicast in decode graphs \citep{yirage2026,chen2020compilerbasedhardw,memoryfloor2026}.

\paragraph{Nsight validation checklist.}
Report memory throttle vs math throttle warp cycles \citep{shah2024flashattention3,patel2025llminference}.
Report mbarrier wait time per consumer warp \citep{semianalysis2024tma,nvidia2022hopper}.
Pipeline success: memory throttle high in producers, math throttle high in consumers, low barrier wait \citep{yirage2026,memoryfloor2026,taxbreak2026}.

Assign non-overlapping smem regions---no alias between streams \citep{yirage2026,dao2022flashattention}.

\paragraph{Decode caveat.}
Multicast/L2 promotion wins shrink at batch-1---primary win is asynchrony + register relief, not prefill sharing patterns \citep{taxbreak2026,semianalysis2024tma,patel2025llminference}.

\paragraph{TMA vs cp.async decision tree.}
(1) If tile bytes $\lt$ threshold and issue rate matters $\rightarrow$ cp.async \citep{dao2022flashattention,patel2025llminference}.
(2) If multidimensional bulk copy with single producer thread $\rightarrow$ TMA \citep{semianalysis2024tma,nvidia2022hopper}.
(3) If producer warps are register-starved $\rightarrow$ TMA offloads address math \citep{shah2024flashattention3,yirage2026}.
Profile both on target silicon---thresholds are not portable \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Barrier walkthrough (A/B ping-pong).}
Iteration $n$: producer TMA$\rightarrow$buffer A; signal mbarrier$_A$ with byte count \citep{semianalysis2024tma,shah2024flashattention3}.
Consumer waits mbarrier$_A$, WGMMA on A; concurrently producer loads B \citep{nvidia2022hopper,yirage2026}.
Iteration $n{+}1$: swap---consumer on B while producer fills A \citep{dao2022flashattention,semianalysis2024tma}.
Barrier indices must alternate consistently---off-by-one causes silent corruption \citep{patel2025llminference,taxbreak2026}.

\paragraph{Avoiding pipeline bubbles.}
Bubble = consumer ready but buffer not signaled---usually insufficient producer warps (Ch.~7) or TMA queue stall \citep{shah2024flashattention3,memoryfloor2026}.
Deadlock = consumer waits wrong barrier or producer signals before copy completes---audit emit order in pipeline IR \citep{yirage2026,semianalysis2024tma,nvidia2022hopper}.
Target ${\lt}5\%$ consumer stall from barriers in steady state \citep{patel2025llminference,shah2024flashattention3}.

\paragraph{Weight vs KV buffer map.}
Reserve disjoint smem regions: e.g.\ weight ping-pong at offset 0, KV ping-pong at offset $2w$ \citep{yirage2026,dao2022flashattention,kwon2023vllm}.
Pipeline pass emits map as IR metadata---codegen must not reorder \citep{chen2020compilerbasedhardw,wu2024mirage}.
KV growth with context may force smaller KV tiles or separate depth---re-run worksheet per context bucket \citep{dao2023flashdecoding,patel2025llminference}.

\paragraph{WGMMA consumer timing.}
Consumers start only after mbarrier proves bytes resident---premature WGMMA reads garbage \citep{shah2024flashattention3,semianalysis2024tma}.
Schedule consumer warpgroups so matmul duration $\approx$ next TMA duration in steady state \citep{memoryfloor2026,yirage2026}.
Thin decode GEMV may finish before TMA---acceptable if producer keeps ahead \citep{patel2025llminference,taxbreak2026}.

\section{CPU Async Pipeline Design (Decode)}
\label{sec:ch08_cpu_dma}

CPU has no programmer scratchpad---pipeline is \textbf{prefetch-shaped} (Ch.~6 blocking) \citep{dlbook,patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{Why CPU pipelines differ.}
GPUs name buffers in shared memory; CPUs rely on cache hierarchy as implicit buffers \citep{dlbook,nvidia2022hopper,semianalysis2024tma}.
You cannot insert mbarrier---you tune prefetch distance and blocking so LLC hits overlap SIMD work \citep{patel2025llminference,yirage2026,chen2020compilerbasedhardw}.
Decode on CPU is almost always DRAM-bandwidth bound---pipeline wins are smaller but still measurable at batch-1 \citep{memoryfloor2026,taxbreak2026,kwon2023vllm}.

\paragraph{Weight streaming on CPU.}
Dense 1B decode reads full weight columns per token---sequential streams favor hardware prefetchers \citep{kwon2023vllm,patel2025llminference,dlbook}.
Blocked micro-tiles from Ch.~6 must fit LLC---otherwise each tile is a cold miss and pipeline collapses \citep{yirage2026,dao2022flashattention,memoryfloor2026}.
Co-locate weight shards with compute threads---NUMA mistakes look like ``pipeline does not work'' \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{KV streaming on CPU.}
PagedAttention scatters KV---prefetch trains break \citep{kwon2023vllm,dao2023flashdecoding,patel2025llminference}.
CPU decode pipelines often accept lower KV reuse---focus prefetch on hot weight streams first \citep{yirage2026,memoryfloor2026}.
Re-run prefetch distance when page layout changes \citep{chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Prefetch distance formula (sketch).}
Let $L$ = memory latency (cycles), $C$ = compute per iteration \citep{dlbook,memoryfloor2026}.
Prefetch distance $d \approx \lceil L / C \rceil$ iterations ahead---tune empirically \citep{patel2025llminference,yirage2026}.
Too small: stalls; too large: cache pollution/eviction \citep{dlbook,taxbreak2026}.

\paragraph{NUMA-aware pipelining.}
Partition weight/KV blocks per socket; reader threads prefetch local pages only \citep{patel2025llminference,kwon2023vllm,memoryfloor2026}.
Cross-NUMA prefetch breaks pipeline---remote latency dominates \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{SIMD alignment.}
Prefetch cache-line granularity; align blocks to SIMD width to avoid partial-line waste \citep{dlbook,patel2025llminference}.
Sequential contiguous weight streams maximize hardware prefetcher tracking \citep{kwon2023vllm,yirage2026}.

\paragraph{Explicit DMA (when available).}
Some server CPUs offer async copy engines---explicit double-buffer between DRAM and compute buffers \citep{dlbook}.
Validate with bandwidth counters; implicit prefetch often suffices for decode GEMV \citep{patel2025llminference,memoryfloor2026}.

\paragraph{CPU pipeline as implicit software pipeline.}
No programmer-visible ping-pong---L1/L2/LLC act as hidden buffers \citep{dlbook,chen2020compilerbasedhardw}.
\textbf{Design rule:} keep working set $\lt$ LLC slice per socket; sequential access patterns maximize hit rate \citep{patel2025llminference,memoryfloor2026}.
Blocking factors from Ch.~6 must fit cache hierarchy---oversized tiles evict pipeline stages \citep{yirage2026,dao2022flashattention}.

\paragraph{Prefetch distance worked example.}
Suppose $L{=}300$ cycles DRAM latency, $C{=}40$ cycles per SIMD micro-tile \citep{dlbook,patel2025llminference}.
$d \approx \lceil 300/40 \rceil = 8$ iterations ahead---start with 4, binary search for LLC miss minimum \citep{yirage2026,taxbreak2026}.
Decode GEMV with small $N$: prologue analog is cold-cache first tiles---warm persistent threads help \citep{mpk2025,patel2025llminference}.

\paragraph{NUMA pinning procedure.}
(1) Pin reader threads to socket owning weight shard \citep{kwon2023vllm,patel2025llminference}.
(2) Allocate KV pages local to compute socket when possible \citep{memoryfloor2026}.
(3) Never prefetch across sockets for hot loop \citep{taxbreak2026,chen2020compilerbasedhardw}.
Remote DRAM doubles effective $L$---depth worksheet must use measured remote latency \citep{patel2025llminference,yirage2026}.

\paragraph{SIMD + prefetch alignment.}
Use \texttt{\_mm\_prefetch} or compiler hints at cache-line boundaries \citep{dlbook}.
Align micro-tile rows to AVX-512 width (64 bytes) to avoid unaligned loads breaking prefetch train \citep{patel2025llminference}.
Weight matrices in decode are often row-major streams---favor contiguous producer loops \citep{kwon2023vllm,yirage2026}.

\paragraph{CPU vs GPU pipeline contrast.}
GPU: explicit smem ping-pong + mbarrier \citep{semianalysis2024tma,shah2024flashattention3}.
CPU: implicit cache pipeline + software prefetch distance \citep{dlbook,patel2025llminference}.
Same depth worksheet math applies---only buffer tier and sync mechanism differ \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Measure LLC miss rate and NUMA remote \% at decode operating point \citep{patel2025llminference,taxbreak2026}.

\section{NPU Spatial Pipeline Design (Decode)}
\label{sec:ch08_npu_pipeline}

XDNA pipelines are \textbf{mandatory explicit DMA}---no cache fallback (Ch.~5) \citep{amd2024xdna,amd2024aie,yirage2026}.

\paragraph{Why NPU pipelines are non-optional.}
GPU can fall back to synchronous global loads (slow); NPU MAC array stalls if DMA does not refill tile SRAM \citep{amd2024aie,amd2024xdna,patel2025llminference}.
Every fused decode cell on XDNA needs a documented DMA schedule---not an optional optimization \citep{yirage2026,chen2020compilerbasedhardw,memoryfloor2026}.
Chapter~\ref{chap:ch05} documents DMA mechanics; this section documents scheduling policy \citep{amd2024xdna,taxbreak2026}.

\paragraph{Time vs space pipeline.}
Temporal ping-pong: buffer A/B on one tile \citep{amd2024aie,dao2022flashattention}.
Spatial pipeline: stage $k$ on tile row $k$, data flows neighbor-to-neighbor \citep{amd2024xdna,patel2025llminference}.
Large fused regions may need both---YiRage pipeline pass selects mix per subgraph \citep{yirage2026,wu2024mirage,chen2020compilerbasedhardw}.

\paragraph{Ping-pong on tile SRAM.}
DMA fills buffer B while MAC consumes A; completion tokens sequence swap \citep{amd2024aie,amd2024xdna,dao2022flashattention}.
$2\times$ operand bytes in Ch.~6 peak---depth usually 2 on tile \citep{yirage2026,memoryfloor2026}.

\paragraph{Spatial stage balancing.}
Split compute across tiles so per-stage latency is balanced---slow stage idles downstream array \citep{amd2024xdna,patel2025llminference}.
Fuse light stages; split heavy ops across tiles \citep{amd2024aie,chen2020compilerbasedhardw}.

\paragraph{DMA priority queues.}
Weights (critical path) $>$ KV stream $>$ debug/scratch \citep{amd2024xdna,dao2023flashdecoding,shah2024flashattention3}.
Mis-prioritized queues starve MAC array \citep{yirage2026,patel2025llminference}.

\paragraph{Multi-tile cascade.}
Use neighbor tile links for assembly-line stages---intermediate tensors stay on-chip \citep{amd2024aie,amd2024xdna,dao2022flashattention}.
Watch stream-switch bandwidth---do not oversubscribe column links \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.

\paragraph{Spatial balance procedure.}
(1) Profile per-stage cycles on single tile \citep{amd2024xdna,patel2025llminference}.
(2) Identify slowest stage---downstream tiles idle waiting \citep{amd2024aie,yirage2026}.
(3) Split heavy op across tiles or fuse light ops with neighbor \citep{chen2020compilerbasedhardw}.
(4) Re-run DDR bytes/token---spatial imbalance shows as MAC util gap \citep{memoryfloor2026,taxbreak2026}.

\paragraph{DMA queue design.}
Priority 1: weight tiles for current layer \citep{taxbreak2026,amd2024xdna}.
Priority 2: KV slices for active context \citep{kwon2023vllm,dao2023flashdecoding}.
Priority 3: scratch/intermediate spill (avoid if possible) \citep{yirage2026,patel2025llminference}.
Starvation of priority 1 is anti-pattern---profile DMA completion vs MAC start \citep{amd2024aie,shah2024flashattention3}.

\paragraph{Decode on NPU specifics.}
Thin batch-1 tiles underfill MAC arrays---spatial pipeline keeps array busy while DMA refills SRAM \citep{patel2025llminference,amd2024aie}.
Depth rarely exceeds 2 on tile SRAM---invest in stage balance over deeper time pipeline \citep{yirage2026,memoryfloor2026,amd2024xdna}.
Chapter~\ref{chap:ch05} covers XDNA DMA mechanics; here we fix scheduling policy \citep{amd2024xdna,chen2020compilerbasedhardw}.

\paragraph{NPU vs GPU pipeline contrast.}
GPU overlaps time stages in one SM with smem \citep{semianalysis2024tma,nvidia2022hopper}.
NPU overlaps space stages across tiles \emph{and} time ping-pong on each tile \citep{amd2024aie,amd2024xdna}.
YiRage lowers one pipeline IR to both---backend pass selects spatial vs temporal schedule \citep{yirage2026,wu2024mirage,patel2025llminference}.

\paragraph{$\checkmark$ Practice checkpoint.}
Verify DDR bytes/token drops when spatial pipeline is enabled \citep{memoryfloor2026,amd2024aie}.

\section{Joint Budget with Chapters~6--7}
\label{sec:ch08_joint_budget}

Pipeline depth is not independent of residency or roles \citep{yirage2026,dao2022flashattention,shah2024flashattention3,chen2020compilerbasedhardw}.

\paragraph{Why triple coupling exists.}
Depth multiplies fast-memory bytes; roles decide who touches each buffer; residency caps total bytes \citep{memoryfloor2026,dao2022flashattention,yirage2026}.
Changing any one without revisiting the others is the dominant source of ``mysterious spill'' bugs after fusion merges \citep{chen2020compilerbasedhardw,wu2024mirage,taxbreak2026}.
Treat Ch.~6--8 as one optimization surface---not three tickets \citep{mpk2025,patel2025llminference,shah2024flashattention3}.

\paragraph{Memory pass coupling.}
Each buffer $\times$ depth adds bytes to Ch.~6 peak---deepening without worksheet update causes spill \citep{memoryfloor2026,yirage2026}.
Pipeline pass must reject depths that overflow memory-pass cap \citep{wu2024mirage,chen2020compilerbasedhardw}.

\paragraph{Role pass coupling.}
Only producer roles issue async copies---pipeline IR references role IDs from Ch.~7 tiling pass \citep{shah2024flashattention3,yirage2026,mpk2025}.
Changing roles without regenerating pipeline breaks barrier mapping \citep{semianalysis2024tma,patel2025llminference}.

\paragraph{Fixed-point loop.}
Memory $\rightarrow$ tiling $\rightarrow$ pipeline $\rightarrow$ re-validate memory; split fusion if no fixed point \citep{yirage2026,wu2024mirage,mpk2025,dao2022flashattention}.

\paragraph{Worked joint example.}
Ch.~6 peak allows ${\sim}96$\,KB ping-pong after residents; tile $32$\,KB $\Rightarrow$ $D_{\max}{=}2$ single-stream \citep{yirage2026,dao2022flashattention,taxbreak2026}.
Adding KV stream second pair needs ${\sim}64$\,KB more---may exceed cap $\Rightarrow$ shrink tile or split fusion \citep{kwon2023vllm,memoryfloor2026,shah2024flashattention3}.
Ch.~7 assigned 4 producer warps---pipeline pass must emit TMA order matching those role IDs \citep{semianalysis2024tma,yirage2026}.

\paragraph{Triple legality reports.}
Ship one bundle: memory legality (Ch.~6), role legality (Ch.~7), pipeline legality (Ch.~8) \citep{chen2020compilerbasedhardw,yirage2026,wu2024mirage}.
CI should fail if any report drifts without coordinated regen \citep{taxbreak2026,patel2025llminference,mpk2025}.

\paragraph{Spill as joint failure.}
Spill after pipeline merge means depth or stream map violated Ch.~6---not a codegen bug to patch with local memory \citep{memoryfloor2026,dao2022flashattention,yirage2026}.
Rollback depth first; split fusion second; never silently spill \citep{chen2020compilerbasedhardw,wu2024mirage}.

\paragraph{$\checkmark$ Practice checkpoint.}
Ship Ch.~6 peak + Ch.~7 role + Ch.~8 depth worksheets together \citep{chen2020compilerbasedhardw,taxbreak2026}.

\section{Pipeline Pitfalls, Checklist, and Debug}
\label{sec:ch08_pipeline_pitfalls}

\subsection{Five common pipeline anti-patterns}
\begin{enumerate}
\item \textbf{Depth excessive.}
\emph{Symptom:} Ch.~6 spill after adding buffers \citep{memoryfloor2026,yirage2026}.
\emph{Root cause:} depth up without byte budget \citep{dao2022flashattention,chen2020compilerbasedhardw}.
\emph{Fix:} reduce depth or split fusion \citep{wu2024mirage}.
\emph{Prevention:} step 2 of depth method; Pattern~1 mandatory \citep{yirage2026,taxbreak2026}.

\item \textbf{Depth insufficient.}
\emph{Symptom:} consumer stalls on mbarrier \citep{shah2024flashattention3,patel2025llminference}.
\emph{Root cause:} synchronous load path or depth=1 \citep{semianalysis2024tma}.
\emph{Fix:} enable ping-pong; add producer capacity (Ch.~7) \citep{yirage2026}.
\emph{Prevention:} measure $t_{\mathrm{load}}$ vs $t_{\mathrm{compute}}$ before merge \citep{memoryfloor2026,shah2024flashattention3}.

\item \textbf{Sync errors.}
\emph{Symptom:} races, deadlock, bubbles \citep{shah2024flashattention3,nvidia2022hopper}.
\emph{Root cause:} barrier misplacement or byte-count mismatch \citep{semianalysis2024tma}.
\emph{Fix:} one barrier pair per buffer stage; golden IR diff \citep{yirage2026,chen2020compilerbasedhardw}.
\emph{Prevention:} barrier walkthrough in Section~\ref{sec:ch08_gpu_tma} \citep{semianalysis2024tma,patel2025llminference}.

\item \textbf{Single-stream parameters.}
\emph{Symptom:} KV path idle while weight path congested \citep{kwon2023vllm,dao2023flashdecoding}.
\emph{Root cause:} unified depth for heterogeneous streams \citep{patel2025llminference}.
\emph{Fix:} independent depth per stream; Figure~\ref{fig:ch08_multi_stream_timeline} \citep{yirage2026,shah2024flashattention3}.
\emph{Prevention:} Pattern~2 on all attention fusion PRs \citep{dao2022flashattention,taxbreak2026}.

\item \textbf{Prefill copy-paste.}
\emph{Symptom:} deep pipeline, few tiles, slow decode \citep{shah2024flashattention3,taxbreak2026}.
\emph{Root cause:} high prologue share; large $D$ with small $N$ \citep{patel2025llminference,memoryfloor2026}.
\emph{Fix:} shallow depth + persistent kernel (Ch.~7 L2) \citep{mpk2025,nvidia2024cudagraphs}.
\emph{Prevention:} separate decode/prefill depth worksheets \citep{kwon2023vllm,yirage2026}.
\end{enumerate}

\paragraph{Anti-pattern culture.}
Treat ``we enabled double buffer'' without worksheet as review blocker \citep{yirage2026,dao2022flashattention,chen2020compilerbasedhardw}.
Celebrate overlap metrics only with tokens/sec at batch-1 \citep{patel2025llminference,taxbreak2026,memoryfloor2026}.
Pipeline depth is not a merit badge---it is a budgeted trade \citep{memoryfloor2026,semianalysis2024tma,shah2024flashattention3}.

\subsection{Pipeline design self-check}
\begin{itemize}
\item[$\square$] Per-tile $t_{\mathrm{load}}$, $t_{\mathrm{compute}}$ measured; bottleneck named
\item[$\square$] Depth fits Ch.~6 fast-memory budget (ping-pong counted)
\item[$\square$] Weight and KV streams have independent depth/buffers
\item[$\square$] Barriers verified---no deadlock or excess bubbles
\item[$\square$] Prologue/epilogue share assessed for decode tile count $N$
\item[$\square$] Residency + role + pipeline legality reports archived
\end{itemize}

\paragraph{Postmortem.}
Replay depth worksheet $\rightarrow$ stall counters $\rightarrow$ bytes/token $\rightarrow$ bisect barrier or depth \citep{shah2024flashattention3,yirage2026,taxbreak2026,memoryfloor2026}.

\paragraph{Debug playbook.}
\textbf{Stalls high, bytes/token flat:} depth insufficient or sync bubbles---check mbarrier timeline \citep{semianalysis2024tma,patel2025llminference}.
\textbf{Spill after merge:} depth excessive---reconcile with Ch.~6 \citep{memoryfloor2026,yirage2026}.
\textbf{Correctness bug:} barrier order or buffer alias---dump pipeline IR \citep{chen2020compilerbasedhardw,shah2024flashattention3}.
\textbf{Decode regression only:} compare $N$ and prologue share vs prefill config \citep{taxbreak2026,kwon2023vllm}.

\section{Pipeline Engineering Patterns}
\label{sec:ch08_pipeline_patterns}

\paragraph{Pattern 1: Depth worksheet first.}
\textbf{Scene:} ``enable double buffer'' PR without numbers \citep{dao2022flashattention,yirage2026}.
\textbf{Solution:} Table~\ref{tab:ch08_depth_worked_example} + Ch.~6 peak + measured $t_{\mathrm{load}}$/$t_{\mathrm{compute}}$ \citep{chen2020compilerbasedhardw,shah2024flashattention3}.
\textbf{Benefit:} avoids spill and false depth \citep{memoryfloor2026,taxbreak2026}.
\textbf{Notes:} depth $\not=$ always 2; decode $N$ caps $D$ \citep{patel2025llminference,semianalysis2024tma}.
\textbf{When:} every pipeline PR; first gate in review \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Pattern 2: Split streams.}
\textbf{Scene:} long-context KV dominates attention step \citep{kwon2023vllm,dao2023flashdecoding}.
\textbf{Solution:} independent KV pipeline depth and smem region \citep{shah2024flashattention3,yirage2026}.
\textbf{Benefit:} weight path no longer starves KV or vice versa \citep{patel2025llminference,memoryfloor2026}.
\textbf{Notes:} Figure~\ref{fig:ch08_multi_stream_timeline}; re-run per context bucket \citep{semianalysis2024tma,taxbreak2026}.
\textbf{When:} paged KV or variable context serving \citep{kwon2023vllm,nvidia2024cudagraphs}.

\paragraph{Pattern 3: Persistent warm pipeline.}
\textbf{Scene:} prologue tax visible every token at batch-1 \citep{mpk2025,patel2025llminference}.
\textbf{Solution:} Ch.~7 L2 persistent grid + shallow in-kernel ping-pong \citep{shah2024flashattention3,nvidia2024cudagraphs}.
\textbf{Benefit:} amortize warm-up across token loop \citep{taxbreak2026,memoryfloor2026}.
\textbf{Notes:} pairs Ch.~7 staticization ladder; do not deepen kernel to fix launch tax \citep{yirage2026,mpk2025}.
\textbf{When:} ms/token flat after fusion but launches already at 1 \citep{patel2025llminference,dao2022flashattention}.

\paragraph{Pattern 4: Triplet pipeline row.}
\textbf{Scene:} GPU TMA schedule fails on NPU or CPU backend \citep{amd2024xdna,taxbreak2026}.
\textbf{Solution:} Table~\ref{tab:ch08_tri_hw_pipeline} + Table~\ref{tab:ch08_cross_hw_decode} per target \citep{yirage2026,chen2020compilerbasedhardw}.
\textbf{Benefit:} fleet-safe IR; same depth math \citep{patel2025llminference,amd2024aie}.
\textbf{Notes:} primitives differ; worksheets identical \citep{nvidia2022hopper,dlbook,amd2024xdna}.
\textbf{When:} multi-backend YiRage builds \citep{wu2024mirage,yirage2026}.

\paragraph{Pattern 5: Pipeline pass golden.}
\textbf{Scene:} hand-edited mbarrier index lost on rebase \citep{shah2024flashattention3,yirage2026}.
\textbf{Solution:} CI golden pipeline IR per canonical layer \citep{wu2024mirage,chen2020compilerbasedhardw}.
\textbf{Benefit:} reproducible barriers and depth \citep{semianalysis2024tma,taxbreak2026}.
\textbf{Notes:} pair Ch.~6 memory and Ch.~7 tiling goldens \citep{yirage2026,mpk2025}.
\textbf{When:} any change to pipeline pass or barrier lowering \citep{chen2020compilerbasedhardw,shah2024flashattention3}.

\paragraph{Pattern 6: Tri-hardware regression row.}
\textbf{Scene:} GPU pipeline lands; NPU build breaks DMA schedule \citep{amd2024xdna,taxbreak2026}.
\textbf{Solution:} Table~\ref{tab:ch08_cross_hw_decode} + per-backend golden \citep{yirage2026,patel2025llminference}.
\textbf{Benefit:} fleet parity \citep{chen2020compilerbasedhardw}.
\textbf{Notes:} same depth math, different primitives \citep{amd2024aie,nvidia2022hopper}.
\textbf{When:} every multi-backend release train \citep{wu2024mirage,yirage2026,mpk2025}.

\paragraph{Pattern catalog summary.}
Patterns~1--2 are decode attention essentials \citep{dao2022flashattention,kwon2023vllm,shah2024flashattention3}.
Pattern~3 pairs Ch.~7 persistent kernels \citep{mpk2025,nvidia2024cudagraphs}.
Patterns~4--6 are fleet/CI hygiene \citep{patel2025llminference,chen2020compilerbasedhardw,taxbreak2026}.
Adopt all six before claiming pipeline maturity \citep{yirage2026,memoryfloor2026,semianalysis2024tma}.

\paragraph{Pattern usage.}
Pattern~1 on all pipeline PRs; Pattern~2 on context-sensitive models; Pattern~5--6 in CI \citep{yirage2026,taxbreak2026,shah2024flashattention3,patel2025llminference}.

\section{Pipeline Review Workflow}
\label{sec:ch08_pipeline_review}

\paragraph{R1--R5.}
R1: depth worksheet; R2: Ch.~6 peak with buffers; R3: Ch.~7 role map; R4: pipeline pass IR; R5: checklist \citep{yirage2026,chen2020compilerbasedhardw,shah2024flashattention3,dao2022flashattention}.
\textbf{Gate A:} spill after pipeline merge \citep{memoryfloor2026}.
\textbf{Gate B:} mbarrier stalls $\gg$ compute \citep{shah2024flashattention3,patel2025llminference}.
\textbf{Gate C:} bytes/token flat \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Reviewer questions.}
Does depth worksheet match measured $t_{\mathrm{load}}$/$t_{\mathrm{compute}}$? \citep{patel2025llminference,yirage2026}
Are weight and KV buffers disjoint in IR? \citep{kwon2023vllm,dao2023flashdecoding}
Is decode $N$ documented for prologue decision? \citep{taxbreak2026,memoryfloor2026}
Does CI include golden pipeline IR diff? \citep{wu2024mirage,chen2020compilerbasedhardw}
Is downgrade path logged for older GPUs? \citep{dao2022flashattention,yirage2026}

\paragraph{Sign-off bundle.}
Attach: Table~\ref{tab:ch08_depth_worked_example}, buffer map, mbarrier index table, pipeline-pass JSON excerpt, checklist screenshot \citep{yirage2026,semianalysis2024tma,shah2024flashattention3,taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Review timeline.}
Day 0: author completes depth worksheet and pipeline IR \citep{yirage2026,dao2022flashattention}.
Day 1: reviewer verifies Ch.~6 peak includes $D \times b$ bytes \citep{memoryfloor2026,chen2020compilerbasedhardw}.
Day 2: silicon owner confirms stall profile matches bottleneck hypothesis \citep{shah2024flashattention3,patel2025llminference}.
Merge only after Gate A--C green \citep{taxbreak2026,wu2024mirage,mpk2025}.

\paragraph{Escalation paths.}
If Gate A (spill): reduce depth or split fusion---do not widen tile \citep{memoryfloor2026,yirage2026,dao2022flashattention}.
If Gate B (stalls): add producers (Ch.~7) or fix barriers---do not deepen blindly \citep{shah2024flashattention3,semianalysis2024tma}.
If Gate C (bytes flat): pipeline is not your bottleneck---return to Ch.~6 residency \citep{taxbreak2026,chen2020compilerbasedhardw,patel2025llminference}.

\paragraph{$\checkmark$ Practice checkpoint.}
Block merge without triple worksheet bundle (Ch.~6--8) \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.

\section{Decode Pipeline Benchmarking Methodology}
\label{sec:ch08_pipeline_benchmarking}

Pipeline changes must be judged with the same decode-first metrics as Chapter~\ref{chap:ch03}---not isolated kernel FLOPs \citep{patel2025llminference,kwon2023vllm,taxbreak2026}.

\paragraph{Minimum benchmark bundle.}
Run batch-1 ms/token with pipeline enabled vs disabled on the \emph{same} fused region and Ch.~6 residency plan \citep{yirage2026,dao2022flashattention,memoryfloor2026}.
Record bytes/token (should be unchanged), launches/token (unchanged if already fused), and stall breakdown \citep{taxbreak2026,shah2024flashattention3,chen2020compilerbasedhardw}.
Pipeline success is visible in consumer stall reduction, not TFLOPs counters \citep{patel2025llminference,semianalysis2024tma}.

\paragraph{GPU stall metrics.}
Export Nsight Compute: memory throttle on producer warps, math throttle on consumer warps, mbarrier wait cycles \citep{shah2024flashattention3,nvidia2022hopper,yirage2026}.
Healthy ping-pong: producers memory-bound, consumers math-bound, barrier waits ${\lt}5\%$ of consumer cycles \citep{semianalysis2024tma,memoryfloor2026,taxbreak2026}.
If barrier waits dominate, fix sync before deepening buffers \citep{patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{CPU cache metrics.}
LLC miss rate per decode step; remote NUMA access percentage \citep{dlbook,patel2025llminference,memoryfloor2026}.
Prefetch win shows as miss rate drop without bytes/token increase \citep{yirage2026,taxbreak2026,kwon2023vllm}.
If misses flat, blocking factor or NUMA placement failed---not prefetch distance tuning alone \citep{chen2020compilerbasedhardw,dao2022flashattention}.

\paragraph{NPU DDR metrics.}
DDR bytes per token with spatial+time pipeline on vs off \citep{amd2024xdna,amd2024aie,memoryfloor2026}.
MAC utilization estimate from cycle counters---imbalanced spatial stages show low util despite low DDR \citep{patel2025llminference,yirage2026,amd2024aie}.
Pipeline should increase MAC busy fraction without increasing DDR \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{A/B discipline.}
Never compare pipelined prefill kernel to non-pipelined decode path \citep{kwon2023vllm,shah2024flashattention3,taxbreak2026}.
Never compare different quantizations or context lengths in the same chart \citep{patel2025llminference,dao2022flashattention}.
Document $N$, $D$, and stream split in benchmark metadata \citep{yirage2026,chen2020compilerbasedhardw,memoryfloor2026}.

\paragraph{Regression CI hooks.}
Golden pipeline IR diff on canonical layers \citep{wu2024mirage,yirage2026,shah2024flashattention3}.
Optional silicon smoke: stall threshold gates on nightly H100 + Ryzen AI cells \citep{amd2024xdna,nvidia2022hopper,patel2025llminference}.
Fail CI on barrier index drift without worksheet update \citep{semianalysis2024tma,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Worked reporting template.}
Report: model, layer, batch, context, $t_{\mathrm{load}}$, $t_{\mathrm{compute}}$, chosen $D$, weight/KV depths, ms/token delta, stall delta \citep{taxbreak2026,shah2024flashattention3,yirage2026}.
Attach Table~\ref{tab:ch08_depth_worked_example} and buffer map \citep{dao2022flashattention,chen2020compilerbasedhardw}.
This template is what reviewers expect in Pattern~1 PRs \citep{patel2025llminference,memoryfloor2026,mpk2025}.

\paragraph{Fleet triplet parity.}
Run the same template row on GPU, CPU, and NPU backends from one YiRage IR \citep{yirage2026,patel2025llminference,amd2024xdna,nvidia2022hopper}.
Depth math should match; only primitive columns differ in Table~\ref{tab:ch08_tri_hw_pipeline} \citep{chen2020compilerbasedhardw,taxbreak2026,amd2024aie}.
Ship all three rows or document explicit backend deferral \citep{wu2024mirage,mpk2025}.

\paragraph{When pipeline is not the lever.}
If bytes/token is high, return to Ch.~6 residency before more buffering \citep{memoryfloor2026,dao2022flashattention,yirage2026}.
If launches/token is high, return to Ch.~7 staticization before overlap tuning \citep{taxbreak2026,mpk2025,nvidia2024cudagraphs}.
Pipeline optimizes timing of \emph{legal} bytes---not volume of bytes or dispatch count \citep{patel2025llminference,shah2024flashattention3,semianalysis2024tma}.

\paragraph{Microbenchmark trap.}
Isolated TMA or prefetch microbenchmarks can show huge speedups that disappear in fusion---barriers, prologue, and stream interaction dominate real kernels \citep{shah2024flashattention3,semianalysis2024tma,yirage2026}.
Always benchmark inside the fused subgraph with Ch.~7 roles enabled \citep{mpk2025,patel2025llminference,taxbreak2026}.
If microbenchmark and fused cell disagree, trust the fused cell \citep{memoryfloor2026,chen2020compilerbasedhardw,dao2022flashattention}.

\paragraph{Context-length sweeps.}
KV stream bytes grow with context---depth worksheets at 4K context may fail at 128K \citep{kwon2023vllm,dao2023flashdecoding,patel2025llminference}.
Bucket graphs by context and store separate pipeline IR per bucket \citep{nvidia2024cudagraphs,yirage2026,shah2024flashattention3}.
Serving SLOs should cite which bucket was validated \citep{taxbreak2026,memoryfloor2026,chen2020compilerbasedhardw}.

\paragraph{Sign-off evidence bar.}
Reviewers should see: worksheet, stall screenshot, bytes/token unchanged, pipeline IR hash \citep{yirage2026,shah2024flashattention3,semianalysis2024tma}.
Missing any item returns PR to author---no ``trust me, overlap is on'' merges \citep{chen2020compilerbasedhardw,taxbreak2026,patel2025llminference}.

\section{Key Takeaways}
\label{sec:ch08_key_takeaways}

Asynchronous pipelines complete the movement layer opened in Chapters~\ref{chap:ch06}--\ref{chap:ch07}: residency budgets and static roles become timed overlap that hides memory latency \citep{yirage2026,shah2024flashattention3,semianalysis2024tma,dao2022flashattention}.
The principles below pair design rules with actions your team can adopt this sprint \citep{chen2020compilerbasedhardw,taxbreak2026,memoryfloor2026,patel2025llminference}.

\begin{itemize}
\item \textbf{Latency-hiding principle.}
Pipeline overlaps movement with compute; cannot beat bandwidth floor \citep{memoryfloor2026,semianalysis2024tma,patel2025llminference}.
Serial load+compute wastes cycles every tile at batch-1 decode \citep{taxbreak2026,kwon2023vllm}.
\textbf{Action:} name bottleneck stage first (step 1); attach stall replay \citep{shah2024flashattention3,yirage2026}.

\item \textbf{Depth-adaptation principle.}
Depth from memory budget, load/compute ratio, and decode tile count $N$ \citep{dao2022flashattention,chen2020compilerbasedhardw,taxbreak2026}.
Blind depth-4 from prefill configs is anti-pattern~5 \citep{shah2024flashattention3,patel2025llminference}.
\textbf{Action:} complete Table~\ref{tab:ch08_depth_worked_example} and Table~\ref{tab:ch08_pipeline_economics} \citep{yirage2026,memoryfloor2026}.

\item \textbf{Multi-stream principle.}
Weight and KV get independent pipeline parameters \citep{kwon2023vllm,dao2023flashdecoding,shah2024flashattention3}.
Unified depth starves one stream while buffering the other \citep{patel2025llminference,yirage2026}.
\textbf{Action:} separate buffer regions, depths, and barrier chains per stream \citep{semianalysis2024tma,dao2022flashattention}.

\item \textbf{Hardware-adaptation principle.}
GPU explicit software pipeline; CPU implicit prefetch; NPU spatial DMA \citep{nvidia2022hopper,dlbook,amd2024xdna,amd2024aie}.
Same worksheet math; different primitives and sync \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.
\textbf{Action:} fill Table~\ref{tab:ch08_tri_hw_pipeline} per backend in CI \citep{patel2025llminference,amd2024aie}.

\item \textbf{Compiler-automation principle.}
Pipeline generation is a pass coupled to memory and tiling passes \citep{yirage2026,wu2024mirage,mpk2025,shah2024flashattention3}.
Hand barrier edits do not survive model or hardware churn \citep{chen2020compilerbasedhardw,semianalysis2024tma}.
\textbf{Action:} attach pipeline IR + checklist to CI; block drift without worksheet updates \citep{yirage2026,taxbreak2026}.
\end{itemize}

Chapter~\ref{chap:ch04}--\ref{chap:ch05} hardware async features are \emph{used} by pipelines, not re-taught here \citep{nvidia2022hopper,amd2024xdna,patel2025llminference}.
Chapter~\ref{chap:ch09} generalizes sync when coordination scales beyond ping-pong \citep{taxbreak2026,yirage2026,chen2020compilerbasedhardw}.

\paragraph{Megakernel stack preview.}
Pipelines (Ch.~8) $\rightarrow$ hierarchical sync (Ch.~9) $\rightarrow$ softmax carriers (Ch.~10) $\rightarrow$ assembly (Ch.~11) \citep{dao2022flashattention,semianalysis2024tma,shah2024flashattention3,mpk2025,patel2025llminference}.

\section{Conclusion}
\label{sec:ch08_conclusion}

Asynchronous pipelines spend Chapters~\ref{chap:ch06}--\ref{chap:ch07}'s budget and roles on timed movement: every producer issues ahead of every consumer without per-tile dispatch \citep{shah2024flashattention3,yirage2026,semianalysis2024tma,dao2022flashattention}.
The three-step depth method, tri-hardware tables, YiRage pipeline pass, and pitfall catalog turn overlap from folklore into repeatable engineering \citep{patel2025llminference,chen2020compilerbasedhardw,taxbreak2026,mpk2025}.

\paragraph{Closing metaphor.}
If Chapter~\ref{chap:ch06} is the warehouse layout and Chapter~\ref{chap:ch07} is the org chart, this chapter is the conveyor timing---trucks arrive while assemblers work \citep{dao2022flashattention,yirage2026,shah2024flashattention3}.
Perfect roles with synchronous loads still have assemblers standing idle at the belt each tile \citep{memoryfloor2026,taxbreak2026}.
Pipelines eliminate that idle; Chapter~\ref{chap:ch09} coordinates when many belts cross \citep{semianalysis2024tma,patel2025llminference}.

Chapter~\ref{chap:ch09} addresses \textbf{hierarchical synchronization}---when many producers and consumers coordinate, barriers themselves become a design problem \citep{taxbreak2026,patel2025llminference,shah2024flashattention3}.
Carry depth worksheets, stream maps, and barrier indices into sync design \citep{yirage2026,semianalysis2024tma,chen2020compilerbasedhardw}.

\paragraph{Part~IV bridge.}
Residency (Ch.~6) + roles (Ch.~7) + pipelines (this chapter) + sync (Ch.~9) assemble the megakernel execution stack \citep{dao2022flashattention,shah2024flashattention3,mpk2025}.
Chapter~20's search assumes pipeline-annotated IR---skipping here breaks the compiler story \citep{wu2024mirage,yirage2026,chen2020compilerbasedhardw}.

\paragraph{Budget--structure--execution recap.}
Chapter~\ref{chap:ch06}: where bytes live \citep{dao2022flashattention,yirage2026,chen2020compilerbasedhardw}.
Chapter~\ref{chap:ch07}: which units touch bytes \citep{shah2024flashattention3,mpk2025,patel2025llminference}.
Chapter~\ref{chap:ch08}: when bytes arrive relative to compute \citep{semianalysis2024tma,amd2024aie,nvidia2022hopper}.
Together they define a deployable decode cell---not an isolated microbenchmark \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Teaching vs production.}
Whiteboard pipeline timelines (Figures~\ref{fig:pipeline_theory_pipeline}, \ref{fig:ch08_multi_stream_timeline}) for onboarding \citep{shah2024flashattention3,dlbook}.

\paragraph{Summary sentence.}
Chapter~\ref{chap:ch06} budgeted bytes; Chapter~\ref{chap:ch07} assigned actors; Chapter~\ref{chap:ch08} synchronized their movement; Chapter~\ref{chap:ch09} will discipline coordination at scale \citep{dao2022flashattention,semianalysis2024tma,yirage2026,shah2024flashattention3}.
