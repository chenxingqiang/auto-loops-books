\section{Why XDNA Is Not a Slower GPU}
\label{sec:industrial_hook}

A GPU team ported a Llama decoder to Ryzen AI and expected ``CUDA, but slower.''
The graph either \textbf{failed to compile} or ran at DDR bandwidth with watt advantages erased \citep{amd2024xdna,amd2024aie}.
Nsight-on-GPU habits misled them: there is no runtime warp scheduler, no configurable shared memory, and no silent spill to HBM when tile SRAM overflows \citep{yirage2026,nvidia2022hopper}.

\textbf{XDNA is a spatial dataflow array}, not a SIMT machine with smaller scratchpad.
Every buffer lifetime, DMA edge, and tile assignment must be fixed before the first token \citep{patel2025llminference,chen2020compilerbasedhardw}.
Illegal plans fail at compile time---or worse, export intermediates to DDR and lose the NPU's watt/token edge \citep{memoryfloor2026}.

\paragraph{Bridge from Chapters~3--4.}
Chapter~3 listed the NPU row in the constraint matrix; Chapter~4 showed Hopper's \emph{dynamic} tiers (shared memory, TMA, launches) \citep{nvidia2022hopper,semianalysis2024tma}.
This chapter is the symmetric \emph{static} story: tile SRAM, DMA chains, and shape buckets \citep{amd2024xdna,amd2024aie}.
The decode metric lens is unchanged---TaxBreak's launches/token on GPU become DMA edges/token and DDR bytes/token here \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Unified optimization logic.}
Whether the target is HBM or DDR, batch-1 decode still reads every weight and every KV vector each step \citep{dao2022flashattention,dlbook}.
Cut activation egress first; cut orchestration second; polish MAC utilization last \citep{memoryfloor2026,taxbreak2026}.
On XDNA, ``orchestration'' is host graph submission plus DMA descriptor setup---not CUDA kernel launches \citep{amd2024xdna,yirage2026}.

\section{XDNA Tile Hardware: Fixed SRAM, No Runtime Scheduler}
\label{sec:ch05_xdna_tiles}

AMD \textbf{XDNA} groups AI Engine (\textbf{AIE}) \textbf{tiles} into a spatial array \citep{amd2024xdna,amd2024aie}.
Each tile owns local SRAM, connects through stream switches, and executes MAC datapaths under compiler-scheduled DMA---not under a hardware warp scheduler \citep{patel2025llminference}.

\paragraph{Engineering meaning.}
Tile SRAM is smaller than Hopper shared memory and \emph{fixed} at compile time---there is no ``configure 228\,KB and hope'' knob \citep{nvidia2022hopper,amd2024aie}.
Overflow does not spill gracefully; it illegalizes the graph or forces DDR round trips \citep{yirage2026,memoryfloor2026}.

\paragraph{Common pitfall.}
Sizing tiles from GPU comfort zones (``HBM is huge'') instead of per-SKU SRAM datasheets \citep{amd2024xdna}.
\textbf{Debug:} static buffer table high-water versus tile cap; DDR bytes/token rising while MAC active \% stays flat \citep{patel2025llminference}.

\paragraph{Core bottleneck.}
When weights, KV cache, and live intermediates cannot simultaneously fit tile SRAM, decode becomes DDR-bandwidth bound---the NPU roofline collapses to external memory \citep{memoryfloor2026,dao2022flashattention}.
Chapter~2's export-edge mindset applies: every DDR round trip is a bytes/token bill \citep{chen2020compilerbasedhardw}.

\paragraph{Ryzen AI context.}
Ryzen AI pairs Zen cores with XDNA for laptop and edge inference \citep{amd2024xdna}.
DDR is shared with CPU, graphics, and I/O---contention inflates p99 decode even when isolated NPU peaks look healthy \citep{patel2025llminference,dlbook}.

\paragraph{Decode vs prefill.}
Prefill parallelizes over prompt tokens; decode appends one token with full KV history \citep{dao2022flashattention,dao2023flashdecoding}.
Graphs compiled for rectangular prefill matmuls may waste tile arrays on thin $M{=}1$ decode---qualify decode-shaped buckets separately \citep{amd2024aie,yirage2026}.

\begin{example}
A decode matmul streams weights from DDR into tile SRAM while activations ping-pong on a DMA chain.
Two weight tiles with overlapping lifetimes exceed SRAM---compile fails with no HBM spill fallback \citep{yirage2026,amd2024xdna}.
\end{example}

\paragraph{Worked contrast.}
Hopper may recover from a suboptimal schedule with CUDA Graphs and extra launches \citep{nvidia2024cudagraphs,taxbreak2026}.
XDNA rarely gets that slack: the static graph ships or it does not \citep{amd2024aie,yirage2026}.

\paragraph{Tile array topology.}
Multiple AIE tiles connect in a grid; decode megakernels assign pipeline stages to tile columns or rows \citep{amd2024xdna,amd2024aie}.
Compiler passes must respect inter-tile stream-switch bandwidth---not every fusion that fits one tile fits the array \citep{yirage2026,chen2020compilerbasedhardw,patel2025llminference}.
Oversubscription may not fail compile; it stalls runtime and inflates p99 \citep{memoryfloor2026}.

\paragraph{Weight streaming.}
Weights are read every decode token \citep{dao2022flashattention,dlbook}.
On GPU, weight bandwidth competes with KV in HBM; on XDNA, weights DMA from DDR unless hot slices pin in tile SRAM across tokens \citep{memoryfloor2026,amd2024xdna}.
Plans that reload full layers each token saturate DDR regardless of MAC peak \citep{patel2025llminference,taxbreak2026}.

\paragraph{KV on DDR.}
KV typically lives in DDR on edge NPUs; attention reads history each token \citep{kwon2023vllm,dao2023flashdecoding}.
Paged KV still requires static page tables in many XDNA stacks \citep{yirage2026,memoryfloor2026}.
Qualify with bytes/token, not parameter count alone \citep{taxbreak2026}.

\paragraph{Rotary and norms.}
Layer norm and rotary embedding look tiny in FLOPs; unfused they become separate DMA rounds \citep{taxbreak2026,amd2024aie}.
Fuse into attention or MLP stages where carriers are already resident \citep{dao2022flashattention,yirage2026}.

\paragraph{Quantization note.}
INT8 and INT4 weights reduce DDR pressure---critical on XDNA \citep{amd2024xdna,memoryfloor2026}.
Quantization scales must embed in static graphs; runtime per-op scale lookup reintroduces dynamicism \citep{amd2024aie,yirage2026}.

\paragraph{Occupancy versus fusion trade.}
Fewer resident tiles may raise MAC active \% yet lose on ms/token when fusion exports to DDR \citep{memoryfloor2026,patel2025llminference}.
Optimize MAC charts only after DDR bytes/token improves \citep{yirage2026}.

\paragraph{Tier assignment exercise.}
For one transformer layer, list every $\Theta(d)$ tensor between attention and MLP: post-norm hidden, Q/K/V fragments, attention output, MLP intermediates, residuals \citep{dao2022flashattention,memoryfloor2026}.
Mark each as tile SRAM, DDR staging, or illegal export for your XDNA plan \citep{yirage2026,chen2020compilerbasedhardw}.
Any DDR mark between fused stages is a bytes/token bug unless proven dead \citep{taxbreak2026,memoryfloor2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Attach a tile SRAM line-item sheet listing every buffer alive during one decode step before requesting codegen \citep{yirage2026,memoryfloor2026}.

\textbf{Dataflow} propagates tokens through spatial pipelines---not through a sequence of host-launched kernels \citep{chen2020compilerbasedhardw,yirage2026}.

\paragraph{Host responsibilities.}
The host configures graph runners and submits execute calls---but must not allocate full tensors per token \citep{amd2024xdna}.
When KV exceeds compiled max context, the product recompiles or rejects---not fall back to unplanned buffers \citep{kwon2023vllm,yirage2026}.

\paragraph{Synchronization model.}
GPUs misuse \texttt{cudaDeviceSynchronize}; XDNA relies on DMA completion tokens wired in the graph \citep{amd2024aie,patel2025llminference}.
Host waits between stages add jitter to p99 decode \citep{memoryfloor2026}.

\paragraph{Deployment pitfall.}
Benchmarking prefill-length graphs then deploying batch-1 decode with growing KV violates static buffer tables unless context was bucketed upfront \citep{dao2022flashattention,dao2023flashdecoding}.
Treat ctx buckets as compile parameters, not runtime surprises \citep{kwon2023vllm,yirage2026}.

\paragraph{Recompile economics.}
Static specialization amortizes compile minutes over thousands of tokens \citep{yirage2026,patel2025llminference}.
Edge products with cold starts must budget compile latency in UX---unlike GPU JIT hidden in first batch \citep{taxbreak2026,nvidia2024cudagraphs}.

\paragraph{Chapter~2 iron rule link.}
Iron Rule~2 (keep activations on-chip) becomes a \emph{hard} compile gate on XDNA---violations export to DDR, not to a forgiving spill path \citep{chen2020compilerbasedhardw,memoryfloor2026}.

\paragraph{Compiler IR implications.}
MLIR and YiRage attach static lifetime intervals to memref views before lowering to AIE \citep{yirage2026,chen2020compilerbasedhardw}.
Generic bufferization that inserts heap fallback breaks static rules immediately \citep{memoryfloor2026,kwon2023vllm}.

\paragraph{Testing static graphs.}
Validate at min and max context buckets, not only nominal length \citep{dao2023flashdecoding,amd2024aie}.
Off-by-one carrier sizes often appear only at max context \citep{memoryfloor2026}.
Run DDR byte counters in simulation before silicon \citep{amd2024xdna}.

\paragraph{Continuous batching.}
vLLM-style batching on GPU does not port literally---XDNA batching requires padded static batch classes \citep{kwon2023vllm,amd2024xdna,yirage2026}.
Each batch class is a separate compiled graph with its own buffer table \citep{patel2025llminference}.

\paragraph{PyTorch eager anti-pattern.}
Chapter~1 diagnosed operator-first GPU stacks; on XDNA eager dispatch is often unsupported outright \citep{taxbreak2026,amd2024xdna}.
The compiler must emit one static graph per shape bucket and recompile when buckets change \citep{yirage2026,patel2025llminference}.

\paragraph{Static dataflow worked example.}
Imagine a two-stage decode cell: attention then MLP \citep{dao2022flashattention}.
Stage one DMA-loads K/V while MAC arrays update softmax carriers entirely in tile SRAM.
Stage two consumes attention output from stream registers without a DDR round trip \citep{amd2024aie,semianalysis2024tma}.
If MLP weights DMA mid-stage without double buffering, MAC units stall---visible as higher ms/token despite healthy FLOPs counters \citep{patel2025llminference,memoryfloor2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Every merge attaches a buffer lifetime diagram: which tensors coexist in tile SRAM at each decode step \citep{amd2024aie,yirage2026}.

\label{sec:ch05_cuda_xdna_mapping}

GPU engineers think in TMA descriptors and shared-memory tiles; XDNA engineers think in \textbf{buffer descriptor}s and tile SRAM assignments \citep{nvidia2022hopper,semianalysis2024tma,amd2024xdna}.
The mapping is \emph{conceptual}---CUDA scheduling experience does not transplant \citep{patel2025llminference,yirage2026}.

\paragraph{TMA lesson transfer.}
TMA hides HBM latency while MMA computes \citep{semianalysis2024tma,nvidia2022hopper}.
XDNA needs explicit ping-pong buffer descriptor pairs in the static graph---compiler assigns both buffers and DMA edges \citep{amd2024aie,yirage2026}.
Without overlap, MAC utilization collapses and watt/token rises \citep{patel2025llminference}.

\paragraph{Graph capture analogy.}
CUDA Graphs freeze launch order; XDNA freezes DMA order \citep{nvidia2024cudagraphs,amd2024xdna}.
Mutating either without re-record/re-compile breaks decode silently \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Applicable when.}
Regular tiles, amortized descriptor setup, steady MegaKernel pipelines inside one shape bucket \citep{amd2024xdna,semianalysis2024tma}.

\paragraph{Avoid when.}
Expecting dynamic batching, speculative branches, or per-token \texttt{malloc} on the hot path \citep{patel2025llminference,liu2024deepseekv3}.

\paragraph{Common pitfall.}
Mandating DMA on micro-copies where descriptor tax exceeds copy benefit---mirror Chapter~4's thin-$M$ TMA anti-pattern on DDR \citep{taxbreak2026,yirage2026}.

\paragraph{Debug.}
MAC active \% versus DDR throughput; DMA edges/token versus graph submission time \citep{amd2024aie,patel2025llminference}.

\begin{example}
GPU: TMA loads Q while softmax partials stay in shared memory.
XDNA: DMA chain loads Q into tile $A$ while tile $B$ holds running max/sum carriers---roles swap at compile-time ping-pong, not runtime alloc \citep{yirage2026,dao2022flashattention}.
\end{example}

\paragraph{Double buffering depth.}
Hopper TMA double buffering hides HBM latency; XDNA ping-pong DMA chains require explicit buffer descriptor pairs in the static graph \citep{semianalysis2024tma,nvidia2022hopper,amd2024aie,yirage2026}.
Shallow pipelines under-utilize MAC arrays; deep pipelines overflow tile SRAM \citep{memoryfloor2026,patel2025llminference}.

\paragraph{Buffer descriptors in practice.}
A buffer descriptor names source address, destination tile buffer, length, and stride---analogous to TMA copy descriptors on Hopper \citep{nvidia2022hopper,amd2024xdna}.
Ping-pong uses two descriptors alternating roles each token step \citep{yirage2026,kwon2023vllm}.
Decode graphs freeze descriptor contents per shape bucket; changing context without recompile implies descriptors were padded for max context upfront \citep{patel2025llminference,amd2024aie}.

\paragraph{Host orchestration.}
CUDA uses streams; XDNA uses graph runners that submit entire dataflow frames \citep{nvidia2024cudagraphs,amd2024xdna,yirage2026}.
Per-token host work must be O(1) and allocation-free---TaxBreak's kernel launch overhead has a direct analogue in graph submission overhead \citep{taxbreak2026,memoryfloor2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Diff static buffer tables against tile SRAM caps; list every DDR transaction per decode step \citep{memoryfloor2026,amd2024aie}.

\section{Online Softmax on Spatial Hardware}
\label{sec:ch05_online_softmax_hw}

Attention decode needs numerically stable \textbf{softmax} over growing KV context \citep{dao2022flashattention,dao2023flashdecoding}.
FlashAttention-style algorithms keep running max and sum in on-chip \textbf{carriers} rather than materializing full attention maps to DDR \citep{memoryfloor2026}.

\paragraph{Hardware requirement.}
On GPU, carriers live in shared memory with warp-synchronous updates; on XDNA they need fixed tile buffer \emph{slots} in the static dataflow \citep{amd2024aie,yirage2026}.
A standalone softmax op lowered independently forces a full map to DDR---doubling bytes/token \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Applicable when.}
QK$^\top$, carrier update, and PV accumulate fuse in one spatial pipeline with carriers never leaving tile SRAM \citep{dao2022flashattention,semianalysis2024tma}.

\paragraph{Avoid when.}
Importing unfused GPU softmax kernels ``because numerics are already validated'' \citep{amd2024xdna,yirage2026}.
The rejection is correct---residency failed, not the NPU \citep{patel2025llminference}.

\paragraph{Common pitfall.}
Carrier buffers sized for prefill-length vectors when decode KV tiles are smaller---overflow splits the graph into DDR-bound pieces \citep{dao2023flashdecoding,memoryfloor2026}.

\paragraph{Debug.}
Compare logits against GPU reference at short ctx before trusting long ctx; inspect carrier placement in cycle-accurate simulation \citep{amd2024aie,yirage2026}.

\paragraph{Carrier precision.}
Fixed-point carriers save SRAM but risk saturation at long context \citep{dao2022flashattention}.
Compiler search must joint-optimize placement and numeric format per tile budget \citep{yirage2026,patel2025llminference}.

\paragraph{Worked contrast.}
Hopper Flash-Decoding adds sequence parallelism with more blocks \citep{dao2023flashdecoding}.
XDNA lacks a ``launch more blocks'' escape---sequence parallelism must be spatial lanes or compile-time rejection \citep{amd2024xdna,yirage2026}.

\paragraph{KV loop structure.}
For each KV block: DMA $K/V$ tiles, MAC $QK^\top$, online softmax carrier update, MAC $PV$ accumulate \citep{dao2022flashattention,semianalysis2024tma,dao2023flashdecoding}.
The loop body must stay inside the same static graph as QKV and MLP---exporting partial attention between blocks reopens DDR bytes/token \citep{memoryfloor2026,yirage2026,taxbreak2026}.

\paragraph{Numerical stability.}
Online softmax relies on stable accumulation order; spatial reductions must preserve mathematical equivalence to GPU reference implementations \citep{dao2022flashattention,dao2023flashdecoding}.
Validation should compare logits against GPU reference on short contexts before trusting long-context deployments \citep{memoryfloor2026,amd2024aie}.

\paragraph{Carrier placement.}
Assign carrier buffers adjacent to attention tiles in the dataflow to minimize stream latency \citep{amd2024xdna,patel2025llminference,chen2020compilerbasedhardw}.
Poor placement increases stage cycles without changing FLOPs---visible only in cycle-accurate simulation \citep{yirage2026,amd2024aie}.

\paragraph{$\checkmark$ Practice checkpoint.}
Softmax region must show fused carrier updates in the static graph---no DDR materialization edge \citep{dao2022flashattention,yirage2026}.

\paragraph{When XDNA wins.}
Fixed-model edge assistants with bounded context, watt caps, and fully static megakernels \citep{amd2024xdna,yirage2026,dao2022flashattention}.

\paragraph{When CUDA wins.}
Dynamic batching, speculative decoding, long-context cloud serving, frequent graph changes \citep{kwon2023vllm,nvidia2024cudagraphs,taxbreak2026,liu2024deepseekv3}.

\paragraph{MoE starkest split.}
TaxBreak reports thousands of GPU kernel launches per MoE decode token \citep{taxbreak2026,liu2024deepseekv3}.
XDNA cannot absorb that count---experts must fuse, batch, or compile as separate static graphs with explicit routing DMA \citep{yirage2026,amd2024aie}.
Choosing XDNA for MoE without a static routing plan repeats GPU orchestration failure in a stricter legality environment \citep{patel2025llminference,memoryfloor2026}.

\paragraph{Hybrid fleets.}
Production may run GPU decode pools plus XDNA edge nodes---schedules must diverge by design, not by accident \citep{patel2025llminference,liu2024deepseekv3,amd2024xdna,yirage2026}.

\paragraph{Speculative decoding caveat.}
Speculative paths introduce dynamic branches hostile to static graphs \citep{patel2025llminference,liu2024deepseekv3}.
Compile separate graphs per policy or keep speculation on GPU \citep{yirage2026,amd2024xdna}.

\paragraph{Software stack depth.}
Ryzen AI ships runtime, compiler, and drivers---teams must coordinate versions like CUDA toolkit pins \citep{amd2024aie,amd2024xdna,chen2020compilerbasedhardw}.
Upgrading one layer without requalifying decode graphs repeats familiar MLIR upgrade failures \citep{yirage2026,taxbreak2026,memoryfloor2026}.

\paragraph{Power envelopes.}
Watt/token often drives XDNA product wins even when raw ms/token loses to H100 \citep{amd2024xdna,amd2024aie,memoryfloor2026,patel2025llminference}.
Architecture reviews should publish both metrics when fleets mix silicon \citep{yirage2026,taxbreak2026}.

\paragraph{Observability.}
Instrument DMA bytes, MAC active ratio, and graph submission time separately \citep{amd2024xdna,patel2025llminference,memoryfloor2026}.
Without decomposition, teams misallocate effort to weight quantization when scheduling is the bottleneck \citep{yirage2026,amd2024aie}.

\paragraph{Multi-layer decode step.}
A full decoder step chains layer graphs or one fused multi-layer graph \citep{yirage2026,amd2024aie}.
Chaining increases host submissions; fusing increases SRAM pressure \citep{patel2025llminference,memoryfloor2026}.
Autotune Pareto fronts across those axes rather than optimizing one layer in isolation \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Architecture review picks primary metric---watt/token or ms/token---before silicon selection \citep{amd2024xdna,patel2025llminference}.

\section{Dataflow Inference Conclusions}
\label{sec:ch05_dataflow_conclusion}

\textbf{Dataflow} is the operational model for NPU inference when decode must meet watt and latency envelopes \citep{amd2024xdna,chen2020compilerbasedhardw,yirage2026}.

\begin{enumerate}
\item Treat decode as a static MegaKernel per shape bucket; recompile when buckets change \citep{yirage2026,patel2025llminference}.
\item Measure DDR bytes/token and DMA edges/token---not FLOPs \citep{memoryfloor2026,taxbreak2026}.
\item Reject graphs that materialize KV or softmax intermediates to DDR \citep{dao2022flashattention,dao2023flashdecoding}.
\item Pair GPU and XDNA baselines from the same high-level IR \citep{chen2020compilerbasedhardw,yirage2026}.
\end{enumerate}

\paragraph{Operator runbooks.}
List compiled shape buckets, max context, recompile triggers, and expected DDR bytes/token \citep{patel2025llminference,amd2024xdna}.
Operators otherwise misdiagnose KV growth as model quality issues \citep{kwon2023vllm,memoryfloor2026}.

\paragraph{Failure modes (symptom $\rightarrow$ counter).}
Compile rejection $\rightarrow$ buffer table overflow row \citep{yirage2026,amd2024aie}.
DDR saturation $\rightarrow$ bytes/token versus roofline \citep{memoryfloor2026}.
Host jitter $\rightarrow$ p99 graph submission time \citep{patel2025llminference,taxbreak2026}.

Identical weights do not imply identical schedules across GPU and NPU fleets \citep{liu2024deepseekv3,patel2025llminference}.
Compiler stacks must fork early; ``port the CUDA kernel'' without static replanning fails \citep{yirage2026,taxbreak2026}.

\paragraph{Epilogue for practitioners.}
XDNA rewards teams that think like compiler engineers first and MAC micro-optimizers second \citep{amd2024xdna,amd2024aie,yirage2026,chen2020compilerbasedhardw}.
Static dataflow is the price of watt-efficient decode; pay it deliberately \citep{memoryfloor2026,patel2025llminference}.
When graphs fail, celebrate early rejection---it is cheaper than DDR-bound production \citep{yirage2026,amd2024aie}.

\paragraph{Roadmap to later chapters.}
Chapter~8 specializes async copy theory on GPU; Chapter~9 sync hierarchy; Chapter~10 softmax numerics; Chapter~11 MegaKernel assembly \citep{dao2022flashattention,dao2023flashdecoding,taxbreak2026,yirage2026}.
XDNA bounds here are prerequisites---later chapters reference GPU labels while NPU teams keep static buffer tables parallel \citep{amd2024xdna,semianalysis2024tma,nvidia2022hopper}.

\paragraph{Energy and TCO (short).}
Fusion DDR bytes/token savings reduce external memory energy even when ms/token gains look modest \citep{memoryfloor2026,patel2025llminference,taxbreak2026,amd2024xdna}.
Edge TCO cares about joules per useful token---not peak TOPS banners \citep{taxbreak2026,dlbook}.

\paragraph{Postmortem sequence.}
When XDNA decode regresses after a merge: diff DDR bytes/token, replay buffer table high-water, compare DMA edge count, bisect fusion versus bucket change, \emph{then} consider driver issues \citep{taxbreak2026,memoryfloor2026,patel2025llminference,amd2024aie,yirage2026}.
Skipping bytes/token replay wastes weeks on MAC-only noise \citep{chen2020compilerbasedhardw}.

\item \textbf{Softmax carriers fused}---\emph{YiRage:} \texttt{CarrierFusionPass} rejects full-map materialization \citep{dao2022flashattention,dao2023flashdecoding}.
\item \textbf{Triplet bufferization}---\emph{YiRage:} same IR must export legality summaries for CUDA, CPU, and XDNA \citep{chen2020compilerbasedhardw,patel2025llminference}.
\end{enumerate}

\subsection{Engineering patterns (XDNA decode)}
\paragraph{Pattern 1: Static fused layer skeleton.}
\textbf{Scene:} single-layer decode on Ryzen AI \citep{taxbreak2026}.
\textbf{Solution:} DMA load $\rightarrow$ QKV MAC $\rightarrow$ KV loop with online softmax $\rightarrow$ SwiGLU $\rightarrow$ residual---no DDR activation stores \citep{dao2022flashattention,amd2024aie}.
\textbf{Benefit:} ${\sim}6$--$8$ DDR round trips removed; DMA edges drop from ${\sim}14$ to $1$ per layer \citep{memoryfloor2026}.
\textbf{Notes:} pre-compute tile SRAM budget (Table~\ref{tab:ch05_tile_budget}) \citep{yirage2026}.

\paragraph{Pattern 2: Context buckets + static graphs.}
\textbf{Scene:} production ctx $\in\{512,2048,8192\}$ \citep{kwon2023vllm,amd2024xdna}.
\textbf{Solution:} separate compiled graphs per bucket; padded max ctx inside each \citep{yirage2026}.
\textbf{Benefit:} deterministic decode latency; no runtime realloc \citep{patel2025llminference}.
\textbf{Notes:} bucket count trades storage for predictability \citep{amd2024aie}.

\paragraph{Pattern 3: Ping-pong DMA in KV loop.}
\textbf{Scene:} KV loop DDR-bound \citep{semianalysis2024tma,dao2023flashdecoding}.
\textbf{Solution:} paired buffer descriptors alternate K/V tiles while MAC consumes previous slot \citep{amd2024xdna,nvidia2022hopper}.
\textbf{Benefit:} raises MAC active \% without extra DDR traffic \citep{patel2025llminference}.
\textbf{Notes:} mis-timed DMA completion tokens stall the pipeline \citep{yirage2026}.

\paragraph{Pattern 4: Spatial softmax carriers.}
\textbf{Scene:} attention decode \citep{dao2022flashattention}.
\textbf{Solution:} fixed tile slots for $(m,\ell,o)$; spatial reduction tree \citep{amd2024aie,dao2023flashdecoding}.
\textbf{Benefit:} avoids full attention map DDR materialization \citep{memoryfloor2026}.
\textbf{Notes:} Chapter~10 owns numerics; this chapter owns placement \citep{yirage2026}.

\paragraph{Pattern 5: Triplet parity.}
\textbf{Scene:} fleet with GPU + NPU endpoints \citep{patel2025llminference,amd2024xdna}.
\textbf{Solution:} same IR, three backends; compare normalized bytes/token \citep{yirage2026,chen2020compilerbasedhardw}.
\textbf{Benefit:} prevents GPU-only schedule drift \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Pattern 6: MoE static routing (advanced).}
\textbf{Scene:} MoE decode with expert selection \citep{liu2024deepseekv3,taxbreak2026}.
\textbf{Solution:} compile expert subgraphs + routing DMA table; batch experts where SRAM allows \citep{amd2024aie,yirage2026}.
\textbf{Benefit:} only path to legal MoE on static arrays \citep{patel2025llminference}.
\textbf{Notes:} hardest XDNA integration---profile at multiple ctx buckets \citep{kwon2023vllm}.

Compile separate static graphs for each $(\text{batch},\text{ctx})$ class you ship; never extrapolate from a single prefill graph \citep{amd2024xdna,amd2024aie,kwon2023vllm,patel2025llminference,yirage2026}.

Without published counters, partners cannot tell whether regressions come from graphs, drivers, or contention \citep{chen2020compilerbasedhardw,taxbreak2026}.

\section{Key Takeaways}
\label{sec:ch05_key_takeaways}

\begin{itemize}
\item \textbf{Static legality principle.}
XDNA has no runtime scheduler---illegal buffer plans fail compile or DDR-bind execution \citep{amd2024xdna,amd2024aie}.
\textbf{Action:} treat compile rejection as success; fix buffer tables before silicon \citep{yirage2026}.

\item \textbf{Metric principle.}
Optimize DDR bytes/token and watt/token before MAC \% polish \citep{memoryfloor2026,patel2025llminference}.
\textbf{Action:} publish DDR ledger beside ms/token in every Ryzen AI release note \citep{amd2024xdna}.

\item \textbf{Translation principle.}
Map CUDA concepts (TMA, graphs, carriers) but re-plan schedules for static tiles \citep{semianalysis2024tma,nvidia2022hopper,amd2024aie}.
\textbf{Action:} use Table~\ref{tab:cuda_xdna_map} in design review, not as a porting checklist \citep{yirage2026}.

\item \textbf{Fusion principle.}
Online softmax carriers must stay in tile SRAM for the full attention pipeline \citep{dao2022flashattention,dao2023flashdecoding}.
\textbf{Action:} block merges that add a DDR softmax materialization edge \citep{memoryfloor2026}.

\item \textbf{Verification principle.}
Triplet IR must compile on CUDA and XDNA; bytes/token must move together with latency \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.
\textbf{Action:} attach Table~\ref{tab:ch05_ryzen_benchmark} rows and five review gates to CI artifacts \citep{patel2025llminference}.
\end{itemize}
