\section{The Lifeline of Fused Kernels: Sync Correctness}
\label{sec:industrial_hook}

A team shipped a fused decode kernel with perfect bytes/token---then production hung on a barrier-count mismatch \citep{shah2024flashattention3,taxbreak2026,yirage2026}.
Chapters~\ref{chap:ch06}--\ref{chap:ch08} optimized residency, roles, and pipelines; \textbf{this chapter makes those optimizations correct and deadlock-free} \citep{nvidia2022hopper,dao2022flashattention,mpk2025}.

\textbf{The more aggressive the overlap, the more dangerous a sync bug.} At batch-1 decode, a coarse block barrier on the critical path can cost more than the matmul it guards---yet omitting a needed barrier corrupts output silently \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.
\textbf{This chapter is the MegaKernel correctness pillar}---minimal-scope synchronization with compile-time proof \citep{yirage2026,wu2024mirage,shah2024flashattention3}.

\paragraph{Bridge from Chapters~6--8.}
Transaction barriers from Ch.~8 are point-to-point handoffs---this chapter generalizes scope selection and proves they cannot deadlock \citep{semianalysis2024tma,shah2024flashattention3}.
Static roles from Ch.~7 fix who coordinates---sync can be minimal only because roles are known at compile time \citep{yirage2026,mpk2025}.
Barrier objects consume Ch.~6 fast-memory budget---count mbarrier slots in peak worksheets \citep{memoryfloor2026,chen2020compilerbasedhardw}.
Decode metrics: Chapter~\ref{chap:ch03}; hardware primitives: Chapters~\ref{chap:ch04}--\ref{chap:ch05} \citep{patel2025llminference,nvidia2022hopper,amd2024xdna}.

Prefill amortizes coarse sync across many tokens; decode does not \citep{kwon2023vllm,shah2024flashattention3,patel2025llminference}.

\paragraph{Design iron rule.}
\textbf{Fine when possible, coarse only when necessary.} Two warps handing off one buffer $\Rightarrow$ mbarrier, not block sync \citep{shah2024flashattention3,semianalysis2024tma}.
Whole CTA phase change $\Rightarrow$ block barrier \citep{nvidia2022hopper}.
Shard sum across GPUs $\Rightarrow$ collective---overlap with next layer compute \citep{patel2025llminference,dlbook}.

\paragraph{Decode-specific rules.}
(1)~Reductions (softmax stats, partial sums): prefer warp shuffle + atomics over block sync \citep{dao2022flashattention,shah2024flashattention3}.
(2)~Pipeline handoffs: only point-to-point mbarrier---never block sync as a pipeline substitute \citep{semianalysis2024tma,yirage2026}.
(3)~Coarse sync on critical path: treat as bug unless proven necessary \citep{taxbreak2026,patel2025llminference,memoryfloor2026}.

\paragraph{Sync economics vs pipeline depth.}
Every extra pipeline stage from Ch.~8 adds at least one mbarrier edge---sync cost scales with depth even when memory budget allows deeper buffering \citep{semianalysis2024tma,yirage2026}.
Table~\ref{tab:ch09_sync_economics} pairs scope choice with decode impact: the goal is not zero sync but \emph{minimal necessary} sync on the critical path \citep{shah2024flashattention3,patel2025llminference}.

\paragraph{Worked decode sync audit (Llama-3.2-1B, batch-1).}
Consider a fused attention tile with Ch.~8 depth $D{=}2$ and Ch.~7 roles: four producer warps load KV, one consumer warpgroup computes softmax+GEMM \citep{shah2024flashattention3,kwon2023vllm}.
\textbf{Sync sites to prove:} (a)~TMA$\rightarrow$smem handoff per buffer slot---mbarrier with byte count; (b)~softmax row max across warpgroup---warp shuffle then at most one atomic per row group, not \texttt{\_\_syncthreads}; (c)~optional KV index update---single atomic per page slot \citep{dao2022flashattention,patel2025llminference}.
\textbf{Reject:} block sync between load and compute---destroys the overlap Ch.~8 built; block sync between softmax and GEMM warpgroups when FA3-style narrow pairing suffices \citep{shah2024flashattention3,semianalysis2024tma}.
\textbf{Certificate output:} two mbarrier rings (weight stream, KV stream), zero block barriers on pipeline path, shuffle path for stats---archive hash with quadruple legality \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Scope decision worksheet (template).}
For each dependency edge, record: (1)~producer unit id (from Ch.~7 role map); (2)~consumer unit id; (3)~buffer id and byte range; (4)~narrowest legal primitive; (5)~CFG paths where both units participate \citep{yirage2026,mpk2025}.
If step~(4) lands on block or wider scope, write one-sentence proof why narrower scopes fail---blank proof fields fail review Gate~B \citep{chen2020compilerbasedhardw,taxbreak2026}.
Decode kernels should show ${\geq}80\%$ of sync sites at warp or mbarrier scope on the critical path \citep{patel2025llminference,memoryfloor2026}.

\paragraph{Transaction barrier as Ch.~8 foundation.}
Ch.~8 ping-pong \emph{is} mbarrier discipline---producer arrive with byte count, consumer wait, then read \citep{shah2024flashattention3,semianalysis2024tma,nvidia2022hopper}.
Coarse block sync between load and compute would serialize the overlap Ch.~8 built \citep{dao2022flashattention,yirage2026}.

\paragraph{Static roles enable minimal sync.}
Ch.~7 fixed producer/consumer IDs---sync pass knows exactly which units pair \citep{yirage2026,shah2024flashattention3,mpk2025}.
Dynamic roles would force wider barriers ``just in case'' \citep{taxbreak2026,patel2025llminference}.

\paragraph{mbarrier in residency budget.}
Each mbarrier object has metadata cost in Ch.~6 peak---deep pipelines multiply barriers \citep{memoryfloor2026,chen2020compilerbasedhardw,yirage2026}.
Deeper pipeline (Ch.~8) $\Rightarrow$ more barrier indices to prove consistent \citep{wu2024mirage,shah2024flashattention3}.

\paragraph{Cluster and grid scope.}
Use cluster barriers only when DSM sharing (Ch.~6) genuinely requires cross-CTA visibility \citep{nvidia2022hopper,shah2024flashattention3}.
Grid sync only in persistent kernels with proven co-residency---expensive at batch-1 \citep{mpk2025,patel2025llminference,nvidia2024cudagraphs}.

\paragraph{Why hierarchy mirrors thread hierarchy.}
Warp $\subset$ block $\subset$ cluster $\subset$ grid mirrors Ch.~7 unit nesting---sync scope should match the smallest containing set for each dependency \citep{shah2024flashattention3,nvidia2022hopper,yirage2026}.
Mismatching scope wastes work: block sync forces fast warps to wait for slow ones on unrelated data \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.

\paragraph{Prefill vs decode sync economics.}
Prefill: many warps busy---block sync cost amortized across parallel work \citep{kwon2023vllm,shah2024flashattention3}.
Decode: few active warps---one \texttt{\_\_syncthreads} can dominate step time \citep{patel2025llminference,taxbreak2026,memoryfloor2026}.
Maintain separate sync audit tabs for decode and prefill kernels \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Quantifying sync tax on decode critical path.}
Let $T_{\mathrm{step}}$ be batch-1 decode step time and $T_{\mathrm{sync}}$ the sum of stall cycles from barriers on the critical path \citep{patel2025llminference,shah2024flashattention3}.
When $T_{\mathrm{sync}} / T_{\mathrm{step}} > 0.05$, treat as P1 optimization---often fixable by replacing one block sync with mbarrier or shuffle \citep{semianalysis2024tma,taxbreak2026}.
Nsight exports $T_{\mathrm{sync}}$ via barrier stall counters; compare against Table~\ref{tab:ch09_sync_economics} expectations before accepting new sync sites \citep{nvidia2022hopper,yirage2026}.
Prefill kernels may tolerate $T_{\mathrm{sync}} / T_{\mathrm{step}}$ up to ${\sim}0.15$ when parallelism hides stalls---do not copy prefill sync plans into decode \citep{kwon2023vllm,memoryfloor2026,patel2025llminference}.

\paragraph{Multi-stream weight/KV independence.}
Chapter~\ref{chap:ch08} split weight and KV pipelines---sync must mirror that split \citep{semianalysis2024tma,kwon2023vllm,dao2023flashdecoding}.
Cross-stream barriers are forbidden unless a true data dependency exists (e.g., attention needs both weight and KV ready for the same tile index) \citep{shah2024flashattention3,dao2022flashattention}.
When dependency is per-tile, use a join mbarrier whose arrive count reflects both streams---not two block syncs in sequence \citep{yirage2026,semianalysis2024tma,chen2020compilerbasedhardw}.
Mis-ordered weight/KV sync is anti-pattern trigger~\#1 in Section~\ref{sec:ch09_deadlock_detection} \citep{taxbreak2026,patel2025llminference}.

\paragraph{Collectives as coarsest sync.}
Tensor-parallel all-reduce is synchronization across devices---treat as graph edge with same acyclic rules \citep{patel2025llminference,dlbook,mpk2025}.
Overlap collective with next-layer compute when dependency graph allows---mirror Ch.~8 latency hiding one scope up \citep{shah2024flashattention3,yirage2026}.

\paragraph{Worked scope decision (attention handoff).}
Dependency: producer warp fills smem tile; consumer warpgroup reads it \citep{shah2024flashattention3,semianalysis2024tma}.
\textbf{Wrong:} \texttt{\_\_syncthreads}---stalls entire CTA \citep{nvidia2022hopper,patel2025llminference}.
\textbf{Right:} mbarrier pair scoped to producer+consumer role IDs from Ch.~7 \citep{yirage2026,dao2022flashattention,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
For each sync site, document dependency span (which units, which buffer) before choosing primitive \citep{yirage2026,chen2020compilerbasedhardw,shah2024flashattention3}.

\paragraph{Cross-hardware law (staticity gradient).}
Reading Table~\ref{tab:ch09_tri_hw_sync} left to right: \textbf{staticity rises, compiler responsibility rises, runtime forgiveness falls} \citep{yirage2026,amd2024xdna,nvidia2022hopper}.
GPU keeps flexible explicit barriers---powerful overlap, but scope mistakes tax decode and deadlocks hide in divergent CFG \citep{shah2024flashattention3,patel2025llminference,taxbreak2026}.
CPU sits in the middle: coherence makes many syncs ``invisible,'' yet false sharing and NUMA remote atomics punish decode helpers silently \citep{dlbook,memoryfloor2026,chen2020compilerbasedhardw}.
NPU freezes every sync at compile time---zero runtime scheduling tax, but a missing token halts the array with no recovery path \citep{amd2024xdna,amd2024aie,yirage2026}.

\paragraph{Decode landing rules (three directions).}
\textbf{GPU:} minimize sync \emph{scope}---fine primitives on a thin per-token critical path \citep{semianalysis2024tma,shah2024flashattention3}.
\textbf{CPU:} minimize cross-core sync \emph{frequency}---partition and pad before adding fences \citep{patel2025llminference,dlbook}.
\textbf{NPU:} maximize compile-time sync \emph{correctness}---token graph must be complete before silicon \citep{amd2024aie,wu2024mirage}.
These directions are not interchangeable; YiRage Sync Pass (Section~\ref{sec:ch09_yirage_sync_pass}) lowers one dependency graph three ways with matching proof strength per row \citep{yirage2026,chen2020compilerbasedhardw,mpk2025}.

\subsection{GPU synchronization rules}
Hopper mbarrier mechanics for pipeline handoff: Section~\ref{sec:ch08_gpu_tma} and Chapter~\ref{chap:ch04} \citep{semianalysis2024tma,nvidia2022hopper,shah2024flashattention3}.
Table~\ref{tab:ch09_tri_hw_sync} row~1 is the contract---subsections below are implementation detail, not a second taxonomy \citep{yirage2026,patel2025llminference}.

\paragraph{mbarrier arrive/wait pairing.}
Producer: TMA complete $\rightarrow$ \texttt{mbarrier.arrive} with expected bytes \citep{semianalysis2024tma,shah2024flashattention3}.
Consumer: \texttt{mbarrier.wait} $\rightarrow$ read buffer $\rightarrow$ compute \citep{nvidia2022hopper,yirage2026}.
Ping-pong: alternate barrier indices $b_0, b_1, \ldots, b_{D-1}$ in ring---off-by-one causes corruption or hang \citep{dao2022flashattention,chen2020compilerbasedhardw}.

\paragraph{Atomic vs barrier boundary.}
\textbf{Barrier:} phase boundary---no participant proceeds until all arrive \citep{nvidia2022hopper,shah2024flashattention3}.
\textbf{Atomic:} single-location update---units need not all stop \citep{dao2022flashattention,memoryfloor2026}.
Partial reductions, KV index updates: atomics or warp shuffle \citep{kwon2023vllm,patel2025llminference}.
Stage handoff after async copy: mbarrier only \citep{semianalysis2024tma,yirage2026}.

\paragraph{Decode GPU tricks.}
Softmax row stats: warp shuffle reduce before any block sync \citep{dao2022flashattention,shah2024flashattention3}.
FA3-style warpgroup overlap uses narrow barriers between softmax and GEMM warpgroups---not block-wide stalls \citep{shah2024flashattention3,patel2025llminference}.

\paragraph{mbarrier ring walkthrough (depth $D{=}2$).}
Buffer slots $B_0, B_1$ alternate; barrier indices $b_0, b_1$ form a ring \citep{semianalysis2024tma,dao2022flashattention}.
\textbf{Initialization:} both buffers empty; producer owns both; consumer waits on $b_0$ before first read \citep{shah2024flashattention3,yirage2026}.
\textbf{Steady state:} producer fills $B_0$, arrives $b_0$ with byte count $N$; consumer waits $b_0$, reads $B_0$, computes, releases $B_0$ to producer via arrive on consumer-side phase barrier; producer fills $B_1$ while consumer works on $B_0$ output---overlap is valid only if arrives precede waits in consistent order \citep{nvidia2022hopper,semianalysis2024tma}.
\textbf{Failure modes:} producer arrives $b_1$ while consumer still reads $B_1$ (depth mis-config); consumer waits $b_0$ twice without intervening producer arrive (pairing bug); byte count $N$ does not match actual TMA bytes after dtype change (silent corruption) \citep{taxbreak2026,chen2020compilerbasedhardw}.
YiRage generates this ring from Ch.~8 pipeline IR---hand-editing indices is the top source of anti-pattern~2 \citep{wu2024mirage,yirage2026}.

\paragraph{KV cache index updates.}
Paged attention updates slot metadata once per token---use atomics on the page table entry, not a block barrier across the CTA \citep{kwon2023vllm,dao2023flashdecoding}.
If multiple warps update disjoint pages, no sync between them; if two warps can touch the same page, serialize with atomics on that page only \citep{patel2025llminference,yirage2026}.
This pattern foreshadows Ch.~10 carrier updates---running softmax stats obey the same ``shuffle first, atomic only if cross-warp'' rule \citep{dao2022flashattention,shah2024flashattention3}.

\paragraph{mbarrier timeout and debug.}
Production kernels should log barrier index on watchdog timeout \citep{taxbreak2026,shah2024flashattention3,yirage2026}.
Development builds may enable arrive-count assertions before wait \citep{nvidia2022hopper,chen2020compilerbasedhardw,semianalysis2024tma}.

\paragraph{Atomic contention on decode.}
Hot global atomics serialize warps---prefer warp-local shuffle then single atomic per warp \citep{dao2022flashattention,memoryfloor2026,patel2025llminference}.
KV length updates: atomics on paged structures---minimize frequency \citep{kwon2023vllm,dao2023flashdecoding,yirage2026}.

\subsection{CPU synchronization rules}
No scratchpad barriers---memory ordering and coherence do the work (Ch.~6 blocking); see Table~\ref{tab:ch09_tri_hw_sync} row~2 \citep{dlbook,chen2020compilerbasedhardw}.

\paragraph{Fence level selection.}
Producer publishes with \texttt{release}; consumer loads with \texttt{acquire} \citep{dlbook,patel2025llminference}.
Use \texttt{seq\__cst} only when global total order required---decode hot loops rarely need it \citep{yirage2026,taxbreak2026}.

\paragraph{False sharing quantified.}
Two threads on one cache line (${\sim}64$\,B): coherence ping-pong can cut effective bandwidth 30--50\% \citep{dlbook,memoryfloor2026}.
\textbf{Fix:} pad per-thread accumulators to cache-line boundaries \citep{chen2020compilerbasedhardw,patel2025llminference}.

\paragraph{NUMA cross-node sync.}
Remote atomics/fences often 2--3$\times$ local latency \citep{patel2025llminference,taxbreak2026}.
Partition weights/KV per socket; avoid hot atomics on cross-node lines \citep{kwon2023vllm,yirage2026}.

\paragraph{CPU decode pipeline analogy.}
CPU ``pipeline'' is cache + prefetch (Ch.~8)---sync is fence placement ordering loads to consumers \citep{dlbook,yirage2026,patel2025llminference}.
Mis-ordered fence $\Rightarrow$ stale read without hang---harder than GPU deadlock \citep{chen2020compilerbasedhardw,taxbreak2026,memoryfloor2026}.

\paragraph{Worked CPU layout fix.}
Per-thread partial sum array: pad struct to 64\,B alignment \citep{dlbook,chen2020compilerbasedhardw}.
Before: 8 threads false-share on one line; after: LLC miss rate drops, ms/token improves \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.

\paragraph{CPU decode helper threading model.}
Many deployments run token sampling, logits post-processing, or small expert routers on CPU while GPU runs the megakernel \citep{patel2025llminference,kwon2023vllm}.
Handoff uses a single-producer single-consumer queue: producer publishes slot index with \texttt{release}, consumer loads with \texttt{acquire} \citep{dlbook,yirage2026}.
Do not use \texttt{seq\__cst} on every token---batch-1 decode issues one fence per step at most on the hot path \citep{taxbreak2026,chen2020compilerbasedhardw}.
If multiple CPU threads reduce partial statistics for speculative decoding, give each thread a cache-line-aligned accumulator---mirrors GPU shuffle-before-atomic discipline at core granularity \citep{memoryfloor2026,patel2025llminference}.

\paragraph{When CPU sync matters for fused stacks.}
Even GPU-only megakernels interact with CPU through graph capture buckets and dynamic shape guards \citep{nvidia2024cudagraphs,yirage2026}.
Bucket boundaries must not change barrier participant sets without re-proof---CPU-side bucket selection is a sync-affecting control-flow edge \citep{shah2024flashattention3,patel2025llminference}.
Document which buckets share the same sync certificate; splitting buckets multiplies proof artifacts but prevents context-length hangs \citep{kwon2023vllm,taxbreak2026}.

\subsection{NPU synchronization rules}
XDNA completion tokens and static dataflow: Section~\ref{sec:ch05_static_dataflow_rules} and Chapter~\ref{chap:ch05}; Table~\ref{tab:ch09_tri_hw_sync} row~3 mandates full static proof \citep{amd2024xdna,amd2024aie,yirage2026}.

\paragraph{Token pairing.}
One completion token per DMA$\rightarrow$MAC handoff; wait instruction references exact token id \citep{amd2024aie,amd2024xdna}.
Multi-stream (weight vs KV): disjoint token index spaces---no cross-stream alias \citep{yirage2026,shah2024flashattention3,kwon2023vllm}.

\paragraph{Cross-tile stream sync.}
Neighbor tile links have finite bandwidth---long chains accumulate latency \citep{amd2024xdna,patel2025llminference,memoryfloor2026}.
Balance spatial pipeline (Ch.~8) with sync depth---do not serialize array on one token chain \citep{amd2024aie,chen2020compilerbasedhardw}.

\paragraph{Static validation mandate.}
Every wait must have a proven producer on all paths---NPU has no runtime recovery \citep{amd2024xdna,yirage2026,wu2024mirage}.
Compile-time token graph is fully simulatable \citep{amd2024aie,taxbreak2026}.

\paragraph{NPU multi-stream decode layout.}
Weight DMA stream and KV DMA stream use disjoint token namespaces---token~7 on weight stream must never satisfy a wait on KV stream \citep{amd2024xdna,amd2024aie,yirage2026}.
Spatial pipeline across tiles assigns forward tokens along the chain; backward dependency (e.g., partial sum return) needs reverse token path or explicit stream sync at subgraph boundary \citep{patel2025llminference,memoryfloor2026}.
Long chains accumulate latency: if each tile adds 50 cycles of sync tax, a 16-tile chain adds 800 cycles before MAC sees last tile's data---balance Ch.~8 spatial depth with sync chain length \citep{amd2024aie,chen2020compilerbasedhardw,shah2024flashattention3}.
Validation exports a token DAG; simulation runs topological order with timeout---any wait without producer is release-blocking \citep{yirage2026,wu2024mirage}.

\paragraph{Lowering GPU mbarrier plans to NPU tokens.}
Do not transliterate mbarrier arrive/wait as ``token per buffer slot'' without checking MAC schedule---NPU tokens bind to DMA completion events, not arbitrary warp phases \citep{amd2024xdna,yirage2026,patel2025llminference}.
YiRage backend pass maps each pipeline handoff edge to (DMA\_id, token\_id) pairs; cross-hardware fleet builds share dependency graph, not textual CUDA barrier code \citep{chen2020compilerbasedhardw,mpk2025}.

Fill Table~\ref{tab:ch09_tri_hw_sync} row per backend before fleet merge \citep{yirage2026,patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{Three classic deadlock patterns.}
\textbf{(1) Arrival mismatch:} barrier expects $n$ arrivals; divergent path delivers $n{-}1$ \citep{shah2024flashattention3,nvidia2022hopper}.
\textbf{(2) Circular wait:} producer waits on free buffer while consumer waits on full---broken initial condition or reversed order \citep{semianalysis2024tma,dao2022flashattention}.
\textbf{(3) Barrier ring disorder:} multi-buffer pipeline with inconsistent cyclic order \citep{shah2024flashattention3,yirage2026}.

\paragraph{Static detection methods.}
\textbf{Arrival counts:} for each barrier, enumerate CFG paths; count reaching units; compare to expected \citep{yirage2026,chen2020compilerbasedhardw,shah2024flashattention3}.
\textbf{Cycle detection:} build wait-for graph on handoff edges; reject if cycle exists \citep{wu2024mirage,mpk2025}.
\textbf{Ring consistency:} verify producer/consumer pointers advance monotonically on buffer ring \citep{semianalysis2024tma,dao2022flashattention}.

\paragraph{Decode high-frequency triggers.}
\textbf{Weight vs KV stream cross-wait:} mismatched ordering between independent mbarrier chains \citep{kwon2023vllm,dao2023flashdecoding,shah2024flashattention3}.
\textbf{Context bucket branches:} some warps skip barrier in one bucket template \citep{nvidia2024cudagraphs,yirage2026,patel2025llminference}.
\textbf{Wrong pipeline depth:} producer overwrites buffer consumer still reads---often race before hang \citep{semianalysis2024tma,memoryfloor2026,taxbreak2026}.

\paragraph{Static analysis algorithm (conceptual).}
\textbf{Step 1---Build wait-for graph:} nodes are role units (Ch.~7); directed edge $A \rightarrow B$ means $A$ waits on a barrier/token that $B$ must signal \citep{yirage2026,wu2024mirage}.
\textbf{Step 2---Cycle detection:} run DFS or Tarjan on the wait-for graph; any cycle is a compile failure with listed nodes \citep{chen2020compilerbasedhardw,mpk2025}.
\textbf{Step 3---CFG arrival parity:} for each barrier $b$ expecting $n$ arrivals, intersect participating units with each CFG path; if any path contributes $k \neq n$, emit barrier id and path id \citep{shah2024flashattention3,nvidia2022hopper}.
\textbf{Step 4---Ring monotonicity:} for buffer index sequence $(i_t)$, verify $i_{t+1} = (i_t + 1) \bmod D$ on both producer and consumer sides \citep{semianalysis2024tma,dao2022flashattention}.
\textbf{Step 5---Token coverage (NPU):} every wait instruction id appears as a completion token on some DMA or MAC edge in the static schedule \citep{amd2024xdna,amd2024aie}.
This five-step pipeline is what the YiRage sync pass implements; manual review mirrors the same checks using exported IR \citep{yirage2026,taxbreak2026}.

\paragraph{Simulation and soak strategy.}
Compile-time proof catches structural deadlock; simulation catches timing assumptions---e.g., consumer wait before producer arrive on first tile because initialization lowering was wrong \citep{shah2024flashattention3,patel2025llminference}.
Run cycle-accurate or instruction-level simulation with timeout on every wait primitive; log barrier id and cycle count at timeout \citep{nvidia2022hopper,semianalysis2024tma}.
Production soak: replay decode traces across context-length buckets; hangs at 1 in $10^4$ still fail release gates when serving SLA is millions of tokens per day \citep{taxbreak2026,mpk2025,kwon2023vllm}.

\paragraph{Tiered defense.}
\textbf{Compile-time:} sync pass rejects unprovable regions (${\sim}$90\%+ bug class) \citep{yirage2026,wu2024mirage,chen2020compilerbasedhardw}.
\textbf{Simulation:} cycle-accurate wait timeout in validation \citep{shah2024flashattention3,patel2025llminference}.
\textbf{Runtime:} watchdog + barrier index dump for residual cases \citep{taxbreak2026,mpk2025}.

\paragraph{Initial conditions for producer-consumer cycles.}
Ping-pong starts with defined buffer ownership---usually empty buffers owned by producer, first consumer wait on buffer 0 \citep{semianalysis2024tma,dao2022flashattention,shah2024flashattention3}.
Sync pass must emit and verify initial state---hand kernels often get this wrong on first tile \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{CUTLASS structural lesson.}
Circular barrier list generated from single pipeline spec---humans should not hand-maintain ring indices \citep{shah2024flashattention3,wu2024mirage}.
YiRage sync pass is the compiler analogue for whole fused subgraphs \citep{yirage2026,mpk2025,chen2020compilerbasedhardw}.

\paragraph{NPU determinism advantage.}
Fully static token graph enables exhaustive compile-time simulation---strongest proof story of three backends \citep{amd2024xdna,amd2024aie,yirage2026}.
GPU proof harder due to dynamic warp scheduling---rely on CFG + role staticness from Ch.~7 \citep{shah2024flashattention3,nvidia2022hopper,patel2025llminference}.

\paragraph{Control-flow divergence rule.}
Barriers only at points \emph{all} participating units reach unconditionally \citep{nvidia2022hopper,shah2024flashattention3}.
Conditional barriers are anti-pattern~3 (Section~\ref{sec:ch09_sync_pitfalls}) \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Attach sync-pass legality report---not just ``kernel compiles'' \citep{yirage2026,wu2024mirage,shah2024flashattention3}.

\section{Joint Budget with Chapters~6--8}
\label{sec:ch09_joint_budget}

Sync is not free in memory or proof complexity \citep{yirage2026,dao2022flashattention,shah2024flashattention3,chen2020compilerbasedhardw}.

\paragraph{Barrier objects in Ch.~6 peak.}
mbarrier state, token slots, collective scratch---account in fast-memory worksheet \citep{memoryfloor2026,nvidia2022hopper,amd2024xdna}.
Deep pipeline (Ch.~8) $\Rightarrow$ more live barriers simultaneously \citep{semianalysis2024tma,yirage2026}.

\paragraph{Role-fixed dependency graph.}
Sync pass consumes Ch.~7 role IDs and Ch.~8 buffer map---changing either without re-running sync pass invalidates proof \citep{shah2024flashattention3,yirage2026,wu2024mirage,mpk2025}.

\paragraph{Quadruple legality bundle.}
Ship Ch.~6 memory + Ch.~7 role + Ch.~8 pipeline + Ch.~9 sync reports together \citep{chen2020compilerbasedhardw,taxbreak2026,patel2025llminference}.
CI fails on any drift without coordinated regen \citep{yirage2026,mpk2025}.

\paragraph{Fixed-point loop.}
Memory $\rightarrow$ tiling $\rightarrow$ pipeline $\rightarrow$ \textbf{sync} $\rightarrow$ re-validate barrier count vs footprint \citep{yirage2026,wu2024mirage,dao2022flashattention,shah2024flashattention3}.

\paragraph{Worked quadruple example.}
Attention fusion: Ch.~6 peak includes $2$ mbarrier objects + ping-pong smem \citep{yirage2026,dao2022flashattention,semianalysis2024tma}.
Ch.~7: 4 producer warps, 1 consumer warpgroup \citep{shah2024flashattention3,mpk2025}.
Ch.~8: depth $D{=}2$, weight/KV stream maps \citep{kwon2023vllm,semianalysis2024tma}.
Ch.~9: 2 mbarrier rings proven acyclic---certificate hash archived in CI \citep{yirage2026,wu2024mirage,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Spill vs sync confusion.}
Spill after sync merge usually means barrier metadata exceeded Ch.~6---not a sync bug but budget violation \citep{memoryfloor2026,yirage2026,dao2022flashattention}.
Rollback barrier count or split fusion before weakening proof \citep{wu2024mirage,chen2020compilerbasedhardw,mpk2025}.

\paragraph{MoE and sync.}
Expert routing adds control-flow edges---each bucket needs sync re-proof \citep{taxbreak2026,liu2024deepseekv3,mpk2025,patel2025llminference}.
Static expert buckets mirror CUDA graph bucketing \citep{nvidia2024cudagraphs,yirage2026,shah2024flashattention3}.

\paragraph{Tensor-parallel and pipeline-parallel edges.}
Tensor parallel inserts all-reduce or reduce-scatter as collective sync edges---every rank must enter the same collective in the same order relative to local mbarrier phases \citep{patel2025llminference,dlbook,mpk2025}.
Pipeline parallel inserts send/recv between stages---model as directed sync edge from sender rank to receiver rank; cycle detection includes cross-rank wait-for graph \citep{yirage2026,shah2024flashattention3}.
Decode batch-1 often runs TP inside the megakernel; PP may be absent---but when PP exists, a hang on rank~2 blocks the whole replica set \citep{taxbreak2026,patel2025llminference}.
Quadruple legality extends to \emph{quintuple} when TP collectives are in scope: add collective symmetry report to the bundle \citep{chen2020compilerbasedhardw,wu2024mirage}.

\paragraph{Budget rollback triggers.}
If sync pass inserts more mbarrier objects than Ch.~6 peak allows, do not weaken proof---reduce pipeline depth, split fusion, or spill cold tensors first \citep{memoryfloor2026,yirage2026,dao2022flashattention}.
Teams sometimes add block sync to ``fix'' races after budget failure---that trades proof debt for ms/token tax; reject in review \citep{taxbreak2026,shah2024flashattention3,patel2025llminference}.

\paragraph{$\checkmark$ Practice checkpoint.}
Quadruple worksheet bundle on every sync-affecting PR \citep{chen2020compilerbasedhardw,taxbreak2026}.

\begin{enumerate}
\item Ingest pipeline IR: buffer map, depth $D$, stream ids, role participant sets \citep{yirage2026,semianalysis2024tma}.
\item For each handoff edge, attempt lowering: warp $\rightarrow$ mbarrier $\rightarrow$ block $\rightarrow$ cluster; stop at first scope that satisfies visibility \citep{shah2024flashattention3,nvidia2022hopper}.
\item Insert acquire/release or mbarrier arrive/wait with byte counts derived from memory pass layout \citep{dao2022flashattention,chen2020compilerbasedhardw}.
\item Run deadlock checks (Table~\ref{tab:ch09_deadlock_checks}); on failure, emit structured error \citep{wu2024mirage,yirage2026}.

\paragraph{Interaction with prior passes.}
Memory pass change $\Rightarrow$ re-run tiling $\Rightarrow$ re-run pipeline $\Rightarrow$ re-run sync---skipping sync after layout change is a common regression \citep{wu2024mirage,yirage2026,dao2022flashattention}.
Role pass change $\Rightarrow$ re-run sync even if pipeline depth unchanged---participant sets changed \citep{shah2024flashattention3,mpk2025}.
Pipeline-only depth tweak $\Rightarrow$ sync must regenerate ring indices; never patch barrier ids in emitted CUDA \citep{semianalysis2024tma,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Pass search for minimal scope.}
For each dependency edge, sync pass tries warp $\rightarrow$ mbarrier $\rightarrow$ block in order---stops at first legal primitive \citep{yirage2026,shah2024flashattention3,nvidia2022hopper,chen2020compilerbasedhardw}.
Widening requires proof that narrower scopes cannot express the dependency \citep{wu2024mirage,mpk2025,patel2025llminference}.

\paragraph{Depth-sensitive barrier rings.}
Pipeline depth $D$ from Ch.~8 implies $D$ mbarrier slots in ring---sync pass generates consistent cyclic order \citep{semianalysis2024tma,dao2022flashattention,shah2024flashattention3}.
Changing $D$ without regenerating sync IR is high-risk merge \citep{yirage2026,taxbreak2026,memoryfloor2026}.

\paragraph{Precision and layout interaction.}
INT4/FP8 packing changes which warps touch which bytes---barrier byte counts must update with dtype lowering \citep{taxbreak2026,yirage2026,shah2024flashattention3}.
Sync pass re-runs when memory pass changes tile layout \citep{wu2024mirage,chen2020compilerbasedhardw,dao2022flashattention}.

\paragraph{Reproducibility across GPU generations.}
Hand-tuned barrier counts assuming fixed warp counts break on next SKU \citep{nvidia2022hopper,patel2025llminference,taxbreak2026}.
Regenerated sync IR from dependency graph ports across fleet \citep{yirage2026,chen2020compilerbasedhardw,mpk2025}.

\section{Sync Pitfalls, Checklist, and Debug}

\subsection{Five common sync anti-patterns}
\begin{enumerate}
\item \textbf{Over-coarse sync.}
\emph{Symptom:} ms/token up after ``adding safety sync'' \citep{taxbreak2026,patel2025llminference,shah2024flashattention3}.
\emph{Root cause:} block sync replaced mbarrier handoff \citep{semianalysis2024tma,yirage2026}.
\emph{Fix:} narrow scope per Table~\ref{tab:ch09_sync_cost_ladder} \citep{nvidia2022hopper}.
\emph{Prevention:} scope justification on every sync site \citep{chen2020compilerbasedhardw}.
\emph{Decode note:} at batch-1, one unnecessary \texttt{\_\_syncthreads} per layer across 32 layers can add tens of microseconds per token---often larger than the arithmetic saved by fusion \citep{patel2025llminference,memoryfloor2026}.

\item \textbf{Barrier pairing error.}
\emph{Symptom:} hang or rare corruption on multi-buffer pipeline \citep{shah2024flashattention3,semianalysis2024tma}.
\emph{Root cause:} arrive/wait count or byte mismatch \citep{nvidia2022hopper,yirage2026}.
\emph{Fix:} regenerate from pipeline IR; golden diff \citep{wu2024mirage,chen2020compilerbasedhardw}.
\emph{Prevention:} static arrival check (Table~\ref{tab:ch09_deadlock_checks}) \citep{yirage2026,chen2020compilerbasedhardw}.
\emph{Decode note:} weight and KV streams each carry independent rings---swapping $b_0$ indices across streams is a common copy-paste failure \citep{kwon2023vllm,dao2023flashdecoding}.

\item \textbf{Conditional barrier.}
\emph{Symptom:} nondeterministic hang \citep{nvidia2022hopper,shah2024flashattention3}.
\emph{Root cause:} barrier inside branch not taken by all warps \citep{yirage2026}.
\emph{Fix:} hoist sync; restructure control flow \citep{chen2020compilerbasedhardw,patel2025llminference}.
\emph{Prevention:} CFG coverage in sync pass \citep{wu2024mirage}.
\emph{Decode note:} variable sequence length tempts \texttt{if (len > bucket)} around barriers---use separate graph buckets with uniform CFG per bucket instead \citep{nvidia2024cudagraphs,kwon2023vllm}.

\item \textbf{CPU false sharing.}
\emph{Symptom:} CPU decode slower than single-thread \citep{dlbook,memoryfloor2026}.
\emph{Root cause:} hot counters on shared cache line \citep{patel2025llminference,taxbreak2026}.
\emph{Fix:} line padding; per-thread private accumulators \citep{chen2020compilerbasedhardw}.
\emph{Prevention:} layout review on parallel loops \citep{yirage2026}.
\emph{Decode note:} speculative decoding threads updating a shared acceptance counter is a frequent offender---pad to 64\,B or shard counters per thread \citep{patel2025llminference,dlbook}.

\item \textbf{NPU token omission.}
\emph{Symptom:} array frozen mid-layer \citep{amd2024xdna,amd2024aie}.
\emph{Root cause:} wait without matching DMA complete token \citep{yirage2026}.
\emph{Fix:} complete token graph; re-validate statically \citep{wu2024mirage,chen2020compilerbasedhardw}.
\emph{Prevention:} token coverage check (Table~\ref{tab:ch09_deadlock_checks}) \citep{amd2024xdna,yirage2026}.
\emph{Decode note:} last tile in spatial chain still needs forward token to host or next subgraph---omitting ``tail'' token hangs the entire array \citep{amd2024aie,patel2025llminference}.
\end{enumerate}

\paragraph{Debug playbook.}
Hang $\rightarrow$ dump last mbarrier/token index $\rightarrow$ compare pipeline IR $\rightarrow$ run sync-pass bisect \citep{shah2024flashattention3,yirage2026,taxbreak2026,memoryfloor2026}.
Corruption without hang $\rightarrow$ race before sync---check byte counts and ordering \citep{semianalysis2024tma,dao2022flashattention,nvidia2022hopper}.

\paragraph{Hang bisect procedure (step-by-step).}
\textbf{1. Capture:} GPU hang dump includes PC, barrier id, warp mask, context bucket id \citep{nvidia2022hopper,shah2024flashattention3}.
\textbf{2. Map id:} look up barrier id in sync IR export---identify stream (weight vs KV), buffer slot, producer/consumer role ids \citep{yirage2026,semianalysis2024tma}.
\textbf{3. CFG check:} verify active bucket's CFG path includes that barrier for all participating warps \citep{nvidia2024cudagraphs,patel2025llminference}.
\textbf{4. Pairing check:} compare arrive count logged in debug build vs expected from pipeline depth $D$ \citep{dao2022flashattention,chen2020compilerbasedhardw}.
\textbf{5. Bisect pass:} replay subgraph with sync pass on/off in simulator; if off hangs disappear, fault is in inserted sync---if on still hangs, fault is in pipeline IR \citep{wu2024mirage,yirage2026,mpk2025}.
\textbf{6. Fix path:} regenerate from pipeline IR (Pattern~2), never add block sync as step~6 shortcut \citep{taxbreak2026,patel2025llminference}.
Median time-to-root-cause under 2 hours when postmortem bundle (Pattern~6) is complete---without bundle, teams loop for days \citep{shah2024flashattention3,memoryfloor2026}.

\subsection{Sync design self-check}
\begin{itemize}
\item[$\square$] Every dependency uses minimal-scope primitive
\item[$\square$] All barrier/token arrive and wait counts match on all CFG paths
\item[$\square$] No sync inside divergent branches
\item[$\square$] Wait-for graph acyclic
\item[$\square$] Decode reductions use shuffle/atomics where possible
\item[$\square$] CPU false sharing and NUMA remote atomics reviewed
\item[$\square$] Quadruple legality (Ch.~6--9) archived
\end{itemize}

Block merge without checklist + sync-pass certificate \citep{yirage2026,chen2020compilerbasedhardw,taxbreak2026}.

\section{Sync Engineering Patterns}
\label{sec:ch09_sync_patterns}

\paragraph{Pattern 1: Scope worksheet.}
\textbf{Scene:} engineer adds \texttt{\_\_syncthreads} ``to be safe'' \citep{shah2024flashattention3,taxbreak2026}.
\textbf{Solution:} list dependency units; pick narrowest row in Table~\ref{tab:ch09_sync_cost_ladder} \citep{yirage2026,nvidia2022hopper}.
\textbf{Benefit:} avoids decode critical-path tax \citep{patel2025llminference,memoryfloor2026}.
\textbf{When:} every new sync site \citep{chen2020compilerbasedhardw}.

\paragraph{Pattern 2: mbarrier ring from pipeline IR.}
\textbf{Scene:} hand-edited barrier indices on ping-pong \citep{semianalysis2024tma,dao2022flashattention}.
\textbf{Solution:} generate ring from Ch.~8 depth $D$ and buffer map \citep{yirage2026,shah2024flashattention3}.
\textbf{Benefit:} pairing errors eliminated \citep{wu2024mirage,chen2020compilerbasedhardw}.
\textbf{When:} any pipeline depth change \citep{taxbreak2026}.

\paragraph{Pattern 3: Shuffle-before-sync.}
\textbf{Scene:} block barrier for softmax partial max \citep{dao2022flashattention,shah2024flashattention3}.
\textbf{Solution:} warp shuffle reduce; atomic only if cross-warp needed \citep{patel2025llminference,memoryfloor2026}.
\textbf{Benefit:} removes full CTA stall \citep{taxbreak2026,yirage2026}.
\textbf{When:} decode attention stats \citep{kwon2023vllm}.

\paragraph{Pattern 4: Tri-hardware sync row.}
\textbf{Scene:} GPU mbarrier plan ported literally to NPU \citep{amd2024xdna,taxbreak2026}.
\textbf{Solution:} Table~\ref{tab:ch09_tri_hw_sync} per backend lowering \citep{yirage2026,patel2025llminference}.
\textbf{Benefit:} fleet-safe coordination \citep{chen2020compilerbasedhardw,wu2024mirage}.
\textbf{When:} multi-backend builds \citep{mpk2025}.

\paragraph{Pattern 5: Sync golden IR.}
\textbf{Scene:} barrier drift on rebase \citep{yirage2026,shah2024flashattention3}.
\textbf{Solution:} CI golden sync IR + certificate \citep{wu2024mirage,chen2020compilerbasedhardw}.
\textbf{Benefit:} hangs caught pre-silicon \citep{taxbreak2026,mpk2025}.
\textbf{When:} sync pass or lowering changes \citep{nvidia2022hopper,amd2024aie}.

\paragraph{Pattern 6: Hang postmortem bundle.}
\textbf{Scene:} production hang with fused kernel \citep{taxbreak2026,patel2025llminference}.
\textbf{Solution:} pipeline IR + sync IR + last barrier index + CFG bucket id \citep{yirage2026,shah2024flashattention3}.
\textbf{Benefit:} fast root-cause \citep{semianalysis2024tma,chen2020compilerbasedhardw}.
\textbf{When:} incident response \citep{memoryfloor2026,mpk2025}.

\paragraph{Pattern usage.}
Patterns~1--3 on kernel PRs; Patterns~4--5 in CI; Pattern~6 in on-call runbooks \citep{yirage2026,taxbreak2026,shah2024flashattention3,patel2025llminference}.

\paragraph{Pattern selection guide.}
\textbf{New sync site?} Start Pattern~1 worksheet before writing CUDA \citep{chen2020compilerbasedhardw,nvidia2022hopper}.
\textbf{Pipeline depth change?} Pattern~2 regeneration mandatory---no manual barrier indices \citep{semianalysis2024tma,yirage2026}.
\textbf{Softmax or norm reduction?} Pattern~3 shuffle path---defer block sync until Ch.~10 carrier proof requires it \citep{dao2022flashattention,shah2024flashattention3}.
\textbf{Fleet triplet build?} Pattern~4 row per backend in CI matrix \citep{amd2024xdna,patel2025llminference,mpk2025}.
\textbf{Compiler change?} Pattern~5 golden diff on every merge to \texttt{sync\_pass/} \citep{wu2024mirage,yirage2026}.
\textbf{Production incident?} Pattern~6 bundle within 30 minutes of hang---barrier index + IR hashes narrow bisect \citep{taxbreak2026,shah2024flashattention3}.
Patterns are not optional style---they are the operational encoding of Sections~\ref{sec:ch09_sync_hierarchy}--\ref{sec:ch09_yirage_sync_pass} \citep{chen2020compilerbasedhardw,mpk2025}.

CFG buckets all proven? \citep{nvidia2024cudagraphs,patel2025llminference}
CPU layout padded against false sharing? \citep{dlbook,chen2020compilerbasedhardw}

\paragraph{PR rubric (expanded).}
\textbf{Scope evidence:} worksheet row per sync site with primitive and justification \citep{yirage2026,chen2020compilerbasedhardw}.

\section{Decode Sync Benchmarking Methodology}
\label{sec:ch09_sync_benchmarking}

Measure sync cost the way Chapter~\ref{chap:ch03} measures decode---not FLOPs alone \citep{patel2025llminference,taxbreak2026,yirage2026}.

\paragraph{Minimum benchmark bundle.}
Batch-1 ms/token: kernel with minimal-scope sync vs coarse-sync variant on \emph{same} fusion region \citep{shah2024flashattention3,memoryfloor2026,dao2022flashattention}.
Nsight: barrier wait cycles, \texttt{\_\_syncthreads} stall time, mbarrier wait histogram \citep{nvidia2022hopper,semianalysis2024tma,patel2025llminference}.
Bytes/token and correctness hash unchanged---sync optimization must not trade bytes or numerics \citep{taxbreak2026,chen2020compilerbasedhardw,yirage2026}.

\paragraph{Nsight metrics interpretation.}
\textbf{Barrier wait cycles:} if mbarrier wait exceeds compute on the same stage, check producer TMA latency or incorrect phase---not always ``add more sync'' \citep{semianalysis2024tma,shah2024flashattention3}.
\textbf{Stall reasons on \texttt{\_\_syncthreads}:} high count on decode path is a red flag---map each stall to sync site worksheet; justify or remove \citep{patel2025llminference,nvidia2022hopper}.
\textbf{Warp issue stall (not selected):} often follows barrier imbalance---one warp arrives early and sleeps while others finish divergent work before the barrier \citep{nvidia2022hopper,yirage2026}.
Report before/after stall histograms in PR template Table~\ref{tab:ch09_pr_template}---numbers beat adjectives in review \citep{chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Acceptance thresholds (decode).}
On batch-1 Llama-class kernels, coarse-sync A/B regression $>5\%$ ms/token without correctness fix is a revert unless scope worksheet proves block barrier unavoidable \citep{patel2025llminference,memoryfloor2026}.
Zero hangs in 24h soak at max context bucket; zero sync-pass failures on golden IR diff \citep{taxbreak2026,yirage2026,mpk2025}.
CPU: LLC coherence traffic should not rise when parallelizing decode helper loops---if it rises, suspect false sharing \citep{dlbook,chen2020compilerbasedhardw}.
NPU: MAC utilization should not drop below pipeline pass prediction because token wait chains are too long---shorten spatial chain or overlap streams \citep{amd2024xdna,amd2024aie}.

\paragraph{Scope A/B discipline.}
Only change sync primitive scope between A and B---hold Ch.~6--8 IR constant \citep{yirage2026,wu2024mirage,dao2022flashattention}.
Document each sync site scope in metadata for reproducibility \citep{chen2020compilerbasedhardw,mpk2025,shah2024flashattention3}.

\paragraph{Hang testing.}
Stress context buckets, batch sizes, and warp counts where CFG differs \citep{nvidia2024cudagraphs,kwon2023vllm,patel2025llminference}.
Soak test with watchdog---hangs may be rare; coverage without soak is insufficient for sync \citep{taxbreak2026,mpk2025,yirage2026}.

\paragraph{CPU/NPU sync metrics.}
CPU: remote NUMA atomic rate, LLC coherence traffic \citep{dlbook,patel2025llminference,memoryfloor2026}.
NPU: token wait cycles, MAC idle while DMA pending \citep{amd2024xdna,amd2024aie,yirage2026}.

\section{Megakernel Sync Composition (Chapters~6--9)}
\label{sec:ch09_megakernel_composition}

Synchronization is the glue that makes Ch.~6--8 composable---without proof, fusion is unsafe at fleet scale \citep{yirage2026,wu2024mirage,mpk2025,shah2024flashattention3}.

\paragraph{Four-pass certification story.}
Memory pass certifies bytes fit \citep{dao2022flashattention,chen2020compilerbasedhardw}.
Tiling pass certifies roles are static \citep{shah2024flashattention3,mpk2025}.
Pipeline pass certifies movement overlaps compute \citep{semianalysis2024tma,yirage2026}.
Sync pass certifies coordination cannot deadlock \citep{wu2024mirage,yirage2026,patel2025llminference}.
Superoptimizer (Ch.~20) proposes; passes disprove bad candidates early \citep{mpk2025,taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Why static roles unlock minimal sync.}
Dynamic assignment would require pessimistic wide barriers---``sync everyone in case'' \citep{taxbreak2026,patel2025llminference,shah2024flashattention3}.
Ch.~7 role IDs give sync pass a precise participant set per edge \citep{yirage2026,mpk2025,nvidia2022hopper}.
This is the performance--correctness coupling of the MegaKernel stack \citep{dao2022flashattention,memoryfloor2026,semianalysis2024tma}.

\paragraph{Pipeline handoffs are sync edges.}
Every Ch.~8 mbarrier is a sync-pass edge with byte-count semantics \citep{semianalysis2024tma,shah2024flashattention3,dao2022flashattention}.
Editing pipeline depth without regenerating sync proof is a top hang vector \citep{yirage2026,taxbreak2026,wu2024mirage}.
Keep pipeline IR and sync IR hashes paired in CI \citep{chen2020compilerbasedhardw,mpk2025}.

\paragraph{Barrier objects in residency.}
mbarrier arrays, token slots, collective scratch---count in Ch.~6 peak like any other fast-memory resident \citep{memoryfloor2026,nvidia2022hopper,amd2024xdna}.
Teams that forget barrier metadata spill or truncate depth silently \citep{yirage2026,dao2022flashattention,chen2020compilerbasedhardw}.

\paragraph{Explicit vs implicit sync spectrum.}
GPU: explicit barriers on partly dynamic machine \citep{nvidia2022hopper,shah2024flashattention3}.
CPU: implicit coherence with hidden cost \citep{dlbook,patel2025llminference,memoryfloor2026}.
NPU: fully explicit tokens---fully analyzable \citep{amd2024xdna,amd2024aie,yirage2026}.
YiRage lowers one dependency graph three ways---Table~\ref{tab:ch09_tri_hw_sync} \citep{chen2020compilerbasedhardw,wu2024mirage,mpk2025}.

\paragraph{Bulk-synchronous vs async trade (again).}
Per-operator stacks sync once per kernel---simple, slow \citep{taxbreak2026,patel2025llminference}.
Fused async kernels sync many times with narrow scope---fast when proven \citep{shah2024flashattention3,semianalysis2024tma,dao2022flashattention}.
Deadlock risk is the price of overlap---pay with compile-time proof, not production hangs \citep{yirage2026,wu2024mirage,mpk2025}.

\paragraph{Softmax preview (Ch.~10).}
Online softmax needs warp-level reductions for $(m,\ell)$ stats---shuffle before any block sync \citep{dao2022flashattention,shah2024flashattention3,memoryfloor2026}.
Carriers must stay consistent across pipeline stages sync pass already proved \citep{yirage2026,patel2025llminference,semianalysis2024tma}.
Ch.~10 specializes carriers; Ch.~9 supplies scope discipline \citep{dao2022flashattention,chen2020compilerbasedhardw}.

\paragraph{Incident response playbook.}
On hang: capture barrier/token index, pipeline depth, context bucket, quadruple IR hashes \citep{taxbreak2026,shah2024flashattention3,yirage2026,mpk2025}.
Bisect: sync pass on $\rightarrow$ off (if safe in lab); compare certificates \citep{wu2024mirage,chen2020compilerbasedhardw,semianalysis2024tma}.
Never ``fix'' hangs by adding block sync without scope worksheet \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.

\paragraph{Chapter~20 search interaction.}
Megakernel candidates mutate fusion, tiles, depth---each mutation re-runs sync pass \citep{mpk2025,wu2024mirage,yirage2026}.
Unprovable variants pruned before codegen saves compile farm and prevents toxic kernels entering soak \citep{chen2020compilerbasedhardw,taxbreak2026,patel2025llminference}.

\paragraph{Serving fleet checklist (operator).}
Version sync certificate with model weights; bucket graphs by context; alert on certificate drift in CI \citep{nvidia2024cudagraphs,kwon2023vllm,yirage2026,shah2024flashattention3}.
Treat certificate mismatch as release blocker---same severity as weight checksum failure \citep{taxbreak2026,mpk2025,chen2020compilerbasedhardw}.

\paragraph{Anti-pattern culture (recap).}
No merge without sync pass green; no coarse sync without written justification; no conditional barriers---ever \citep{yirage2026,shah2024flashattention3,nvidia2022hopper,semianalysis2024tma}.
Patterns in Section~\ref{sec:ch09_sync_patterns}; gates in Section~\ref{sec:ch09_sync_review} \citep{chen2020compilerbasedhardw,taxbreak2026,patel2025llminference}.

\paragraph{End-to-end certification narrative.}
A megakernel candidate flows: superoptimizer proposes fusion graph $\rightarrow$ memory pass proves bytes $\rightarrow$ tiling pass assigns static roles $\rightarrow$ pipeline pass schedules movement $\rightarrow$ \textbf{sync pass proves coordination} $\rightarrow$ codegen \citep{wu2024mirage,yirage2026,mpk2025,shah2024flashattention3}.
Removing sync pass from CI is equivalent to shipping without tests---numerical tests do not observe deadlock \citep{taxbreak2026,patel2025llminference}.
The certificate is the contract between compiler and serving: if certificate hash matches golden, operators trust barrier indices across deploys \citep{chen2020compilerbasedhardw,yirage2026}.

\paragraph{Teaching lab (90-minute).}
\textbf{Part A:} students classify ten dependency edges into scope ladder rows \citep{shah2024flashattention3,dlbook}.
\textbf{Part B:} inject one conditional barrier into sample IR; run sync pass; read error path output \citep{yirage2026,chen2020compilerbasedhardw}.
\textbf{Part C:} Nsight compare minimal vs coarse sync on provided decode kernel \citep{patel2025llminference,nvidia2022hopper}.
\textbf{Deliverable:} completed checklist + one-page scope worksheet---mirrors production review Gates A--C \citep{taxbreak2026,mpk2025}.

\paragraph{$\checkmark$ Practice checkpoint.}
Archive quadruple legality + sync certificate together on every fused-kernel release \citep{yirage2026,wu2024mirage,mpk2025,dao2022flashattention,shah2024flashattention3,chen2020compilerbasedhardw,taxbreak2026}.

\section{Key Takeaways}
\label{sec:ch09_key_takeaways}

Synchronization turns Ch.~6--8 performance into \emph{safe} performance---minimal scope, static proof, per-target lowering \citep{yirage2026,shah2024flashattention3,dao2022flashattention,mpk2025}.

\begin{itemize}
\item \textbf{Minimal-scope principle.}
Cost rises from warp to collective---use narrowest primitive that satisfies the dependency (Table~\ref{tab:ch09_sync_cost_ladder}) \citep{shah2024flashattention3,patel2025llminference}.
\textbf{Action:} scope worksheet on every sync site \citep{yirage2026,chen2020compilerbasedhardw}.

\item \textbf{Decode-adaptation principle.}
Thin per-token work makes coarse sync disproportionately expensive \citep{taxbreak2026,memoryfloor2026,kwon2023vllm}.
\textbf{Action:} shuffle/atomics for reductions; mbarrier for pipeline handoffs only \citep{dao2022flashattention,semianalysis2024tma}.

\item \textbf{Static-proof principle.}
Deadlock is invisible to numerical tests---prove at compile time \citep{shah2024flashattention3,wu2024mirage,yirage2026}.
\textbf{Action:} require sync-pass certificate in CI \citep{chen2020compilerbasedhardw,mpk2025}.

\item \textbf{Hardware-adaptation principle.}
GPU explicit barriers; CPU coherence+fences; NPU static tokens \citep{nvidia2022hopper,dlbook,amd2024xdna,amd2024aie}.
\textbf{Action:} fill Table~\ref{tab:ch09_tri_hw_sync} per backend \citep{patel2025llminference,yirage2026}.

\item \textbf{Compiler-internalization principle.}
Sync insertion belongs in YiRage pass, not hand CUDA \citep{yirage2026,wu2024mirage,shah2024flashattention3,mpk2025}.
\textbf{Action:} golden sync IR + quadruple legality bundle \citep{chen2020compilerbasedhardw,taxbreak2026}.
\end{itemize}

\paragraph{How this chapter connects.}
Ch.~8 pipelines need Ch.~9 proofs; Ch.~7 roles enable minimal edges; Ch.~6 budgets barrier objects \citep{semianalysis2024tma,shah2024flashattention3,dao2022flashattention,yirage2026}.
Chapter~\ref{chap:ch10} applies these rules to online softmax---carriers and running stats with tight warp-level sync \citep{dao2022flashattention,memoryfloor2026,patel2025llminference}.

\section{Conclusion}
\label{sec:ch09_conclusion}

Hierarchical synchronization completes the MegaKernel safety stack: residency, roles, pipelines, and now \emph{proved} coordination \citep{yirage2026,shah2024flashattention3,dao2022flashattention,mpk2025,wu2024mirage}.

\paragraph{Closing metaphor.}
Ch.~8 timed the conveyor; Ch.~9 installs the sensors and interlocks so boxes never collide \citep{semianalysis2024tma,shah2024flashattention3,dao2022flashattention}.
Speed without interlocks is a recall event \citep{taxbreak2026,patel2025llminference,memoryfloor2026}.

Chapter~\ref{chap:ch10} develops \textbf{online softmax}---the algorithm where running statistics must stay resident and synchronized across the pipeline stages this chapter secured \citep{dao2022flashattention,shah2024flashattention3,memoryfloor2026}.

Residency (Ch.~6) $\rightarrow$ roles (Ch.~7) $\rightarrow$ pipelines (Ch.~8) $\rightarrow$ \textbf{sync proof} (Ch.~9) $\rightarrow$ online softmax carriers (Ch.~10) $\rightarrow$ full decoder assembly (Ch.~11) \citep{dao2022flashattention,mpk2025,yirage2026,shah2024flashattention3}.
