\section{The Ultimate Fix for Dispatch Overhead: Static Role Assignment}
\label{sec:industrial_hook}

A serving team measured 847.5 GPU kernel launches per output token on dense Llama-3.2-1B---and realized most launches existed only to \emph{decide who does what} this step \citep{taxbreak2026,patel2025llminference}.
Chapter~\ref{chap:ch06} budgeted \emph{where} bytes live; this chapter fixes \emph{which unit} loads them and which unit computes---at compile time, not per token \citep{yirage2026,shah2024flashattention3}.

\textbf{847.5 launches per token is a scheduling tax.} Each launch reassigns work from host to device; static role assignment moves that decision to compile time so one resident kernel already knows every warp's job \citep{taxbreak2026,mpk2025,nvidia2024cudagraphs}.
\textbf{This chapter is the MegaKernel structural pillar}---from residency budget to schedule-free execution \citep{wu2024mirage,memoryfloor2026}.

\paragraph{Bridge from Chapter~6.}
Residency worksheets tell you peak footprint; role assignment tells you \emph{who} holds each buffer while it is live \citep{yirage2026,chen2020compilerbasedhardw}.
Register skew from producer/consumer splits \emph{changes} the residency distribution---joint optimization is mandatory \citep{shah2024flashattention3,dao2022flashattention}.
General lifetime method: Chapter~\ref{chap:ch06}; here we specialize to decode staticization \citep{patel2025llminference}.

\section{Static Role Assignment: Principles and Decode Payoff}
\label{sec:ch07_static_roles}

\textbf{Static role assignment} fixes each execution unit's job for the kernel lifetime---producer units move data, consumer units compute---instead of a runtime scheduler reassigning per operator \citep{shah2024flashattention3,mpk2025}.
On Hopper the canonical pattern is warp specialization: producer warps issue async loads; consumer warpgroups issue collective matmul \citep{shah2024flashattention3,semianalysis2024tma}.
The compiler emits role-pure instruction streams---no interleaved load/matmul branches---improving overlap scheduling \citep{shah2024flashattention3,wu2024mirage}.

\paragraph{What ``schedule-free'' means.}
The \emph{assignment} of work to units is not recomputed at runtime---no host picks the next operator kernel \citep{taxbreak2026,mpk2025}.
Internal tile \emph{ordering} may remain; cross-operator dispatch does not \citep{shah2024flashattention3}.
That distinction is where decode latency is won \citep{memoryfloor2026,patel2025llminference}.

\paragraph{Mechanical sympathy with asynchrony.}
Async load and compute paths signal through barriers \citep{semianalysis2024tma,nvidia2022hopper}.
A unified warp stalls on its own loads; split roles let producers run ahead while consumers drain buffers---Chapter~\ref{chap:ch06} double-buffering expressed as labor division \citep{dao2022flashattention,yirage2026}.

\paragraph{Megakernel limit case.}
Mirage Persistent Kernel assigns each SM a compile-time task sequence---entire forward pass in one launch \citep{mpk2025,wu2024mirage}.
Full static roles are the structural prerequisite Chapter~20's search assumes \citep{mpk2025,yirage2026}.
TaxBreak-scale launch counts collapse to one per token when roles and fusion are co-designed \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Two scheduling costs.}
\textbf{Assignment scheduling} decides which unit runs which op---host launches, block schedulers \citep{taxbreak2026,mpk2025}.
\textbf{Ordering scheduling} decides tile sequence inside a unit---cheap if assignment is fixed \citep{shah2024flashattention3,patel2025llminference}.
Static roles eliminate assignment cost; persistent tile loops retain minimal ordering cost \citep{nvidia2024cudagraphs,shah2024flashattention3}.
Confusing the two leads teams to CUDA Graph L1 and wonder why bytes/token is flat \citep{memoryfloor2026,dao2022flashattention,yirage2026}.

\paragraph{Serving stack interaction.}
Frameworks queue tokens; static kernels reduce per-step device orchestration \citep{kwon2023vllm,patel2025llminference}.
PagedAttention solves KV DRAM placement; static roles solve per-step operator dispatch inside the step \citep{kwon2023vllm,taxbreak2026}.
Both layers stack---neither replaces the other \citep{dao2023flashdecoding,yirage2026}.

\paragraph{Decode parallelism reality.}
Batch-1 decode has thin matmuls---WGMMA utilization is naturally low \citep{patel2025llminference,shah2024flashattention3}.
Static roles target \emph{feeding} scarce compute slots, not maximizing TFLOPs counters \citep{memoryfloor2026,taxbreak2026}.
Work per step is regular and small---ideal for extreme staticization \citep{kwon2023vllm,yirage2026}.

\paragraph{NPU convergence.}
XDNA tiles are statically configured stages---no runtime tile reassignment \citep{amd2024xdna,amd2024aie}.
GPU adds static specialization atop a dynamic machine; NPU is static by construction \citep{patel2025llminference,chen2020compilerbasedhardw}.
Both reward fixing roles when movement and orchestration dominate \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Specialization as compiler transform.}
Static roles are specialization: runtime role branches fold away \citep{shah2024flashattention3,wu2024mirage}.
Producer streams contain loads and barrier arrivals; consumer streams contain matmuls and waits---no cross-traffic \citep{semianalysis2024tma,nvidia2022hopper}.
That separation is what makes barrier placement a compile-time problem \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Decode vs prefill (again, operationally).}
Prefill: many tokens $\rightarrow$ schedulers hide latency; consumer-heavy splits can maximize tensor-core occupancy \citep{kwon2023vllm,shah2024flashattention3}.
Decode: one token $\rightarrow$ every warp stall is visible; producer-heavy splits keep thin GEMVs fed \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.
Benchmark both regimes separately---do not tune decode with prefill dashboards \citep{yirage2026,taxbreak2026}.

\paragraph{FA3 lessons without FA3 copy-paste.}
FlashAttention-3 demonstrates warp specialization benefits on Hopper \citep{shah2024flashattention3}.
\textbf{Take the pattern, not the constants:} producer/consumer split, register skew, barrier-driven overlap \citep{semianalysis2024tma,nvidia2022hopper}.
\textbf{Do not take:} prefill tile sizes, warpgroup counts, or TFLOPs targets \citep{patel2025llminference,memoryfloor2026,kwon2023vllm}.
Decode worksheets (Table~\ref{tab:ch07_role_worked_example}) replace FA3 tables for batch-1 \citep{yirage2026,taxbreak2026}.

\paragraph{Schedule-free vs persistent.}
Schedule-free emphasizes fixed assignment; persistent kernels may retain lightweight tile ordering \citep{shah2024flashattention3,mpk2025,nvidia2024cudagraphs}.
L2 is often ``schedule-free roles + persistent grid''---the production compromise \citep{patel2025llminference,yirage2026,taxbreak2026}.

\paragraph{MoE and depth scaling.}
Mixture-of-experts multiplies per-layer dispatch decisions in per-op stacks \citep{taxbreak2026,liu2024deepseekv3}.
Static roles at L3 amortize routing overhead across experts when graphs are bucketed \citep{mpk2025,wu2024mirage,patel2025llminference}.
Even L2 per-layer persistent kernels help before full MPK \citep{shah2024flashattention3,nvidia2024cudagraphs,yirage2026}.

\paragraph{Compiler specialization benefit.}
Role-pure warp code enables better instruction scheduling and fewer predicate registers \citep{shah2024flashattention3,wu2024mirage}.
Unified warps interleave async copies and matmuls---harder for compilers to overlap \citep{semianalysis2024tma,nvidia2022hopper}.
This is why static roles pair with YiRage lowering rather than hand-written mega-CUDA only \citep{yirage2026,chen2020compilerbasedhardw,mpk2025}.

\paragraph{Launch storm anatomy.}
Per-operator stacks launch attention, norms, MLP, residuals separately---each launch re-enters driver and scheduler \citep{taxbreak2026,patel2025llminference}.
Even fast kernels pay fixed launch latency at batch-1 \citep{memoryfloor2026,kwon2023vllm}.
Static roles inside fused kernels convert thousands of assignment decisions into zero per token \citep{mpk2025,shah2024flashattention3,yirage2026}.
Measure before/after on the \emph{same} model checkpoint---not different quantizations \citep{taxbreak2026,dao2022flashattention}.

\paragraph{Relationship to CUDA Graphs.}
Graphs batch host launches; they do not by themselves fuse ops or assign warp roles \citep{nvidia2024cudagraphs,shah2024flashattention3}.
L1 removes host replay cost; L2 adds in-kernel specialization---complementary steps \citep{patel2025llminference,yirage2026,taxbreak2026}.
Teams stuck at L1 should ask whether launches are gone but bytes/token is still high---that is Ch.~6 work \citep{dao2022flashattention,memoryfloor2026,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Document producer/consumer split rationale before merging any warp-specialization PR \citep{shah2024flashattention3,yirage2026}.

\section{Joint Optimization with Chapter~6 Residency}
\label{sec:ch07_joint_residency}

Roles and residency are not sequential handoffs---they co-evolve \citep{yirage2026,dao2022flashattention,shah2024flashattention3,chen2020compilerbasedhardw}.

\paragraph{Register file as shared budget.}
Consumer warpgroups demand high per-thread register counts; producers stay low \citep{shah2024flashattention3,nvidia2022hopper}.
Skew shifts bytes between register and shared tiers---update Ch.~6 peak after every skew proposal \citep{memoryfloor2026,yirage2026}.
Spill to local memory means joint optimization failed---split fusion before tuning ratios \citep{dao2022flashattention,chen2020compilerbasedhardw}.

\paragraph{Shared memory for ping-pong.}
Producer/consumer pipelines need A/B buffers in shared memory \citep{semianalysis2024tma,dao2022flashattention}.
Chapter~\ref{chap:ch06} counted $2\times$ tile bytes; roles decide which warps touch each buffer \citep{yirage2026,shah2024flashattention3}.
Illegal role plan can fit on paper but fail when both buffers are live---rerun peak walk with role timeline \citep{wu2024mirage,memoryfloor2026}.

\paragraph{Fixed-point iteration.}
Practical lowering loop: (1)~memory pass max tile; (2)~tiling pass roles+skew; (3)~rerun memory pass; (4)~repeat or split \citep{yirage2026,wu2024mirage,mpk2025,chen2020compilerbasedhardw}.
Teams that run passes once often ship spill bugs \citep{memoryfloor2026,taxbreak2026,patel2025llminference}.

\paragraph{Worked joint example.}
Table~\ref{tab:ch07_role_worked_example} producer count assumes Ch.~6 peak ${\sim}168$\,KB shared on GPU \citep{yirage2026,dao2022flashattention,taxbreak2026}.
Increasing producers without shrinking tiles overflows shared memory---co-search or split \citep{memoryfloor2026,nvidia2022hopper,shah2024flashattention3}.

\paragraph{Carrier tensors and roles.}
Softmax carriers $(m,\ell,o)$ usually live in consumer registers or fixed NPU slots \citep{dao2022flashattention,amd2024aie,shah2024flashattention3}.
Role assignment must reserve carrier home before sizing producer teams---Chapter~10 expands carrier placement \citep{dao2022flashattention,patel2025llminference,yirage2026}.
Demoting carriers to shared memory is a structured fallback when register skew exhausts the file \citep{memoryfloor2026,nvidia2022hopper}.

\paragraph{KV stream roles.}
KV slices are producer-loaded, consumer-read streams across steps \citep{kwon2023vllm,dao2023flashdecoding,semianalysis2024tma}.
Decode staticization assigns dedicated producer bandwidth to KV---ratio worksheet should include KV tile load cycles \citep{patel2025llminference,yirage2026,shah2024flashattention3}.
Chapter~\ref{chap:ch08} implements the movement; roles decide how many warps participate \citep{semianalysis2024tma,dao2022flashattention}.

\paragraph{Checklist coupling.}
Ch.~6 checklist item ``ping-pong counted'' must be green before Ch.~7 ratio worksheet sign-off \citep{yirage2026,chen2020compilerbasedhardw,dao2022flashattention}.
Ch.~7 checklist adds barrier and ratio rows---both checklists ship together \citep{patel2025llminference,taxbreak2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Attach both Ch.~6 peak worksheet and Ch.~7 ratio worksheet on staticization PRs \citep{yirage2026,chen2020compilerbasedhardw,dao2022flashattention}.

\section{Quantitative Role Decision Framework}
\label{sec:ch07_role_decision}

Conceptual warp splits are insufficient for production---use a \textbf{three-axis decision framework} tied to decode throughput mismatch \citep{shah2024flashattention3,patel2025llminference,yirage2026}.

\paragraph{Axis 1: Producer/consumer ratio.}
Estimate bytes moved per step versus useful FLOPs per step \citep{memoryfloor2026,dao2022flashattention}.
Decode GEMV is memory-heavy---tilt toward more producer capacity than prefill-shaped kernels \citep{kwon2023vllm,taxbreak2026}.
Rule of thumb: if load latency exceeds consumer cycle time on a tile, add producer warps until the consumer rarely waits---subject to register/SM caps from Chapter~\ref{chap:ch06} \citep{yirage2026,nvidia2022hopper}.

\paragraph{Quantitative procedure (decode).}
Step A: profile or model bytes per attention micro-tile and cycles per consumer matmul \citep{shah2024flashattention3,patel2025llminference}.
Step B: compute mismatch $M = t_{\mathrm{load}} / t_{\mathrm{compute}}$ \citep{memoryfloor2026}.
Step C: allocate producer warps until simulated consumer idle $\lt 5\%$ \citep{yirage2026,shah2024flashattention3}.
Step D: verify Ch.~6 peak and register file; iterate \citep{dao2022flashattention,chen2020compilerbasedhardw}.
Document $M$ and final split in the PR \citep{taxbreak2026,patel2025llminference}.

\paragraph{Axis 2: Register skew bounds.}
Hopper allows warpgroup register reallocation---consumers need more registers than TMA producers \citep{shah2024flashattention3,nvidia2022hopper}.
\textbf{Skew policy:} allocate minimum registers to producers; give remainder to consumer warpgroup until spill threshold \citep{memoryfloor2026,dao2022flashattention}.
Re-run Chapter~\ref{chap:ch06} peak worksheet after skew---roles change residency \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Skew procedure.}
(1) Measure producer instruction footprint---usually small for TMA-only warps \citep{semianalysis2024tma,shah2024flashattention3}.
(2) Allocate consumer registers to hold accumulators and softmax state without spill \citep{dao2022flashattention,nvidia2022hopper}.
(3) If total exceeds SM file, shrink tile or split fusion---do not spill to local memory \citep{memoryfloor2026,yirage2026}.
(4) Document final per-role register counts in tiling IR metadata \citep{chen2020compilerbasedhardw,wu2024mirage}.

\paragraph{Axis 3: Barrier placement.}
Barriers synchronize producer completion with consumer start---misplacement causes bubbles or races \citep{shah2024flashattention3,semianalysis2024tma}.
\textbf{Placement rule:} one barrier pair per ping-pong stage; consumers wait only on the buffer they consume; producers signal only after async copy completes \citep{nvidia2022hopper,yirage2026}.
Count barrier slots in residency budget---synchronization metadata consumes planning headroom \citep{chen2020compilerbasedhardw}.

\paragraph{Barrier walkthrough.}
For buffer A/B ping-pong: producer issues TMA$\rightarrow$A, signals \texttt{mbarrier}; consumer waits, reads A, computes; producer loads B while consumer works on A \citep{semianalysis2024tma,shah2024flashattention3}.
Swap roles on buffers next iteration---barrier indices must alternate consistently \citep{nvidia2022hopper,yirage2026}.
Chapter~\ref{chap:ch08} details TMA descriptor setup; this chapter fixes \emph{who} issues them \citep{semianalysis2024tma,dao2022flashattention,patel2025llminference}.

\paragraph{Three-axis summary.}
Ratio fixes starvation; skew fixes spill; barriers fix races and bubbles \citep{shah2024flashattention3,memoryfloor2026,yirage2026}.
YiRage tiling pass searches all three jointly under Ch.~6 caps \citep{wu2024mirage,chen2020compilerbasedhardw,mpk2025}.

\paragraph{Axis interaction example.}
If Axis~1 demands more producers but Axis~2 cannot skew further, shrink tile (Axis implicit) or split fusion \citep{yirage2026,dao2022flashattention,shah2024flashattention3}.
If Axis~3 adds barriers that lengthen producer critical path, revisit Axis~1---barriers can negate producer gains \citep{semianalysis2024tma,nvidia2022hopper,patel2025llminference}.
Document trade-offs in tiling IR comments for future bisect \citep{chen2020compilerbasedhardw,wu2024mirage,mpk2025}.

Validate with Nsight memory vs compute warp stalls---not FLOPs alone \citep{memoryfloor2026,yirage2026}.

\paragraph{Register skew worked example.}
Suppose 256 threads split: 128 producer threads at 24 registers, 128 consumer threads at 112 registers \citep{shah2024flashattention3,nvidia2022hopper}.
Total ${\approx}128\cdot24 + 128\cdot112 = 17{,}408$ register slots---under typical SM file when occupancy target is one block \citep{nvidia2022hopper,memoryfloor2026}.
Push consumer to 200 registers without dropping producers $\rightarrow$ spill risk; rerun Ch.~6 peak \citep{yirage2026,dao2022flashattention}.

\paragraph{Barrier budget.}
Each ping-pong stage needs arrive/wait pairs on mbarrier objects \citep{semianalysis2024tma,nvidia2022hopper}.
Decode layers with two streamed operands (QKV + KV) may need two barrier chains---count them in the schedule sketch \citep{shah2024flashattention3,yirage2026}.
Mis-ordered barriers manifest as rare correctness bugs or steady 5--10\% bubble overhead \citep{patel2025llminference,taxbreak2026}.

\paragraph{Inter-warpgroup overlap (decode scope).}
FA3 overlaps softmax in one warpgroup with GEMM in another---valuable when both stages exist in the fused region \citep{shah2024flashattention3}.
Thin decode GEMV may not justify extra warpgroups---overlap adds role complexity \citep{patel2025llminference,memoryfloor2026}.
Apply overlap only when cycle-accounting shows idle tensor cores \citep{shah2024flashattention3,yirage2026}.

\paragraph{Simulation before silicon.}
Use stall simulation or Nsight warp-state metrics to validate ratio proposals before locking tiling IR \citep{patel2025llminference,shah2024flashattention3,yirage2026}.
Worksheets are hypotheses---measurement confirms \citep{taxbreak2026,memoryfloor2026,chen2020compilerbasedhardw}.
Reject ratios that improve TFLOPs but not tokens/sec at batch-1 \citep{kwon2023vllm,patel2025llminference}.

\paragraph{Thread mapping granularity.}
Roles bind at warp/warpgroup on GPU, thread/SIMD on CPU, tile on NPU \citep{shah2024flashattention3,amd2024aie,dlbook}.

\subsection{GPU role mapping}
\label{sec:ch07_thread_mapping}

Producer warps + consumer warpgroups; register skew toward consumers \citep{shah2024flashattention3,nvidia2022hopper}.
Persistent CTAs (one per SM) with in-kernel tile handoff---dispatch stays on device \citep{shah2024flashattention3,mpk2025}.
\textbf{Avoid:} repeating Hopper hierarchy lessons---see Chapter~\ref{chap:ch04} \citep{nvidia2022hopper,semianalysis2024tma}.

\paragraph{GPU decode checklist.}
Assign producers to async copy path; consumers to warpgroup matmul \citep{semianalysis2024tma,shah2024flashattention3}.
Verify WGMMA is warpgroup-collective---roles bind at warpgroup granularity for consumers \citep{nvidia2022hopper,patel2025llminference}.
Use cluster multicast when multiple CTAs consume the same weight tile---static cluster membership required \citep{nvidia2022hopper,shah2024flashattention3,yirage2026}.
After skew, confirm Ch.~6 shared-memory peak still legal \citep{dao2022flashattention,memoryfloor2026,chen2020compilerbasedhardw}.

\paragraph{Persistent kernel mechanics.}
Grid size = SM count; each CTA loops logical tiles \citep{shah2024flashattention3,mpk2025}.
Epilogue of tile $n$ overlaps prologue of tile $n{+}1$ when roles are pipelined \citep{shah2024flashattention3,semianalysis2024tma}.
This is L2 sweet spot: one host launch, structured in-kernel progress \citep{nvidia2024cudagraphs,patel2025llminference,taxbreak2026}.

\subsection{CPU role mapping}

Pin decode threads to cores owning weight pages; split prefetch vs compute threads weakly \citep{dlbook,patel2025llminference}.
Staticization is \emph{affinity policy}, not warp specialization \citep{kwon2023vllm,memoryfloor2026}.
NUMA mistakes look like role imbalance---half bandwidth with idle cores \citep{patel2025llminference,taxbreak2026}.

\paragraph{CPU decode checklist.}
Partition reader threads (prefetch weight/KV blocks) and compute threads (GEMV/attention micro-kernels) \citep{dlbook,kwon2023vllm}.
Pin each partition to the socket that owns the pages it reads \citep{patel2025llminference,memoryfloor2026}.
Measure remote NUMA accesses---not just cache misses \citep{taxbreak2026,chen2020compilerbasedhardw}.
CPU ``static roles'' are stable thread-function mappings across tokens \citep{yirage2026,patel2025llminference}.

\subsection{NPU role mapping}

Each tile is a pipeline stage---DMA in, MAC, DMA out---fixed at compile \citep{amd2024xdna,amd2024aie}.
\textbf{Avoid:} restating XDNA tile catalogs---see Chapter~\ref{chap:ch05} \citep{amd2024xdna,yirage2026}.
Role plan equals DMA graph plus spatial placement \citep{patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{NPU decode checklist.}
Map attention sweep as spatial pipeline across tile row/column \citep{amd2024aie,dao2022flashattention}.
Double-buffer descriptors alternate per streamed operand---roles include DMA engine vs MAC array \citep{amd2024xdna,patel2025llminference}.
Illegal role+tile plan fails compile---no silent fallback \citep{yirage2026,memoryfloor2026,taxbreak2026}.
Compare DDR bytes/token before blaming ``slow NPU'' \citep{memoryfloor2026,amd2024aie}.

\paragraph{Tri-hardware deployment narrative.}
A fleet might serve GPU in cloud and NPU on edge---same YiRage IR, different role maps \citep{yirage2026,patel2025llminference,amd2024xdna,nvidia2022hopper}.
GPU path: semi-static warp roles inside persistent CTAs \citep{shah2024flashattention3,mpk2025}.
NPU path: fully static tile stages with DMA descriptors \citep{amd2024aie,amd2024xdna,chen2020compilerbasedhardw}.
CPU path: pinned reader/compute threads per socket \citep{dlbook,kwon2023vllm,memoryfloor2026}.
Triplet CI compiles all three or documents intentional single-backend deferral \citep{yirage2026,taxbreak2026}.

\paragraph{Cross-class lesson.}
Same fused IR needs three role maps---triplet CI should reject GPU-only schedules \citep{yirage2026,amd2024aie,nvidia2022hopper,taxbreak2026}.

\paragraph{GPU persistent kernel note.}
Launch CTAs = SM count (e.g.\ 132 on H100 SXM5); in-kernel tile loop assigns work without host \citep{shah2024flashattention3,mpk2025}.
Role assignment still matters inside each CTA---persistent $\neq$ unified warps \citep{patel2025llminference,yirage2026}.
Persistent + warp specialization is the usual L2 sweet spot \citep{nvidia2024cudagraphs,shah2024flashattention3}.

\paragraph{CPU staticization limits.}
OS schedulers migrate threads---``static role'' means pinning and partition, not permanent warp identity \citep{dlbook,patel2025llminference}.
Use thread pools with fixed reader/compute roles per socket \citep{kwon2023vllm,memoryfloor2026}.
Gains come from NUMA affinity and fewer handoffs---not from eliminating the OS entirely \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{NPU spatial roles.}
Tiles along a column form a pipeline---stage $k$ always performs the same op \citep{amd2024xdna,amd2024aie}.
Reconfiguration mid-inference is a different graph---staticization assumes fixed topology per bucket \citep{yirage2026,patel2025llminference}.
Role map equals placement + DMA descriptors---Chapter~\ref{chap:ch05} backend lowering emits it \citep{amd2024xdna,chen2020compilerbasedhardw}.

\paragraph{Reading the economics table.}
Start L1 if you are still changing graphs weekly \citep{nvidia2024cudagraphs,patel2025llminference}.
Move L2 when fusion boundaries stabilize and warp roles are testable \citep{shah2024flashattention3,yirage2026}.
Attempt L3 only with frozen models, green Ch.~6 worksheets, and MPK/Mirage toolchain \citep{mpk2025,wu2024mirage,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Honest limit.}
Irregular work (causal ragged rows) may need in-kernel tile schedulers---small dynamic core inside persistent kernels \citep{shah2024flashattention3}.
Batch-1 dense decode is usually regular enough for near-L3 staticization \citep{kwon2023vllm,patel2025llminference}.

\paragraph{L1 deep dive (CUDA Graph).}
Capture a launch sequence once; replay with one host launch per token \citep{nvidia2024cudagraphs,taxbreak2026}.
Ops remain separate kernels inside the graph---roles are per-kernel, not fused \citep{patel2025llminference}.
Good when you need quick wins without rewriting fusion \citep{yirage2026,memoryfloor2026}.

\paragraph{L2 deep dive (persistent + roles).}
One grid of resident CTAs; warp specialization inside each CTA \citep{shah2024flashattention3,mpk2025}.
In-kernel tile scheduler handles unequal tile counts without host \citep{shah2024flashattention3}.
Balances flexibility and launch reduction---recommended default for production decode \citep{patel2025llminference,nvidia2024cudagraphs}.

\paragraph{L3 deep dive (megakernel).}
SM-level task graph; decentralized in-kernel scheduling across operators \citep{mpk2025,wu2024mirage}.
Reports $1.2$--$6.7\times$ end-to-end latency wins over per-op serving when launch storm dominates \citep{mpk2025,memoryfloor2026,taxbreak2026}.
Requires frozen fusion boundaries and proven residency+role worksheets \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Migration path.}
Most teams: L1 $\rightarrow$ L2 (add fusion + warp roles) $\rightarrow$ L3 only if launches still hurt after fusion \citep{taxbreak2026,patel2025llminference,mpk2025}.
Skipping L2 worksheets and jumping to L3 yields fragile megakernels that spill silently \citep{memoryfloor2026,yirage2026}.

\paragraph{Depth compounding.}
Per-operator stacks pay orchestration tax once per layer per token \citep{taxbreak2026,mpk2025}.
Static megakernels pay once per token regardless of depth---asymptotic win no inner-loop tweak matches \citep{memoryfloor2026,patel2025llminference}.
Document layer count when arguing for L3---deep models amplify launch storms \citep{taxbreak2026,wu2024mirage}.

\paragraph{CUTLASS / Stream-K note.}
Library tile schedulers stay in-kernel---compatible with L2 when roles are fixed inside each persistent CTA \citep{shah2024flashattention3,patel2025llminference}.
Do not confuse library scheduling with host per-op dispatch \citep{taxbreak2026,yirage2026}.

\paragraph{When not to staticize.}
Highly irregular shapes, dynamic expert counts per token without bucketing, or rapid A/B graph changes \citep{liu2024deepseekv3,patel2025llminference,mpk2025}.
Stay L1--L2 until shapes and graphs stabilize \citep{nvidia2024cudagraphs,yirage2026,taxbreak2026}.
Staticization is a business decision as much as a kernel decision \citep{patel2025llminference,chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Record chosen staticization level and launch-count evidence in benchmark TSV \citep{taxbreak2026,nvidia2024cudagraphs}.

\paragraph{Closed loop.}
Mirage proposes fusion $\rightarrow$ memory pass certifies footprint $\rightarrow$ tiling pass assigns roles $\rightarrow$ illegal plans reject with split hint \citep{wu2024mirage,yirage2026,mpk2025}.
Chapter~20 superoptimizer consumes legal role IR---static assignment is its structural substrate \citep{mpk2025,chen2020compilerbasedhardw}.

\paragraph{Pass pseudocode narrative.}
\textbf{Input:} fused subgraph $G$ with residency metadata $R$ from Ch.~6 \citep{yirage2026,chen2020compilerbasedhardw}.
\textbf{Loop:} propose tile shape $T$; propose split $(p,c)$ producer/consumer counts; allocate registers; place barriers \citep{shah2024flashattention3,wu2024mirage}.
\textbf{Check:} simulate stalls; verify $R$ still valid under skew \citep{memoryfloor2026,dao2022flashattention}.
\textbf{Accept:} emit schedule IR; \textbf{reject:} split $G$ or shrink $T$ with reason \citep{yirage2026,patel2025llminference,mpk2025}.
This is constrained search---not a single template table \citep{wu2024mirage,chen2020compilerbasedhardw}.

\paragraph{Per-target divergence.}
GPU search explores warp splits under shared-memory caps; NPU search explores tile stages under SRAM caps \citep{amd2024aie,nvidia2022hopper,yirage2026}.
Precision changes tile bytes---co-decide format with tile shape \citep{shah2024flashattention3,dlbook,memoryfloor2026}.

\paragraph{Error contract.}
Failures cite: overflow tensor, role split attempted, recommended fusion edge, backend cap row \citep{yirage2026,patel2025llminference}.
Opaque errors recreate GPU-porting pain on NPU \citep{amd2024xdna,chen2020compilerbasedhardw}.

\paragraph{Search algorithm sketch.}
Start from memory-pass max legal tile; propose producer/consumer split; place barriers; simulate stall counters \citep{wu2024mirage,yirage2026,shah2024flashattention3}.
If starvation or overflow, shrink tile or split fusion; if still failing, emit structured error \citep{mpk2025,chen2020compilerbasedhardw}.
Megakernel search (Ch.~20) receives only feasible schedules---search does not fix illegal roles \citep{wu2024mirage,mpk2025}.

\paragraph{Regression tests.}
Golden tests: stored role ratio + barrier count for canonical layers \citep{yirage2026,wu2024mirage}.
CI fails when tiling pass output drifts without worksheet update \citep{chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Operator fusion interaction.}
Tiling pass grows fusion until memory pass or role search fails \citep{wu2024mirage,yirage2026,shah2024flashattention3}.
Each added op changes load/compute mismatch---ratio must be re-evaluated \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.
This is why megakernel search and tiling pass iterate rather than run once \citep{mpk2025,chen2020compilerbasedhardw}.

\paragraph{Backend lowering handoff.}
GPU lowering emits warp-specialized PTX/CUDA with barrier indices from schedule IR \citep{shah2024flashattention3,nvidia2022hopper,yirage2026}.
NPU lowering emits DMA graphs with tile stage IDs \citep{amd2024xdna,amd2024aie,patel2025llminference}.
CPU lowering emits threaded task structs with affinity tags \citep{dlbook,chen2020compilerbasedhardw,kwon2023vllm}.
Same schedule IR surface---three backends \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Composition with Chapter~6 memory pass.}
Memory pass fixes \emph{what} fits; tiling pass fixes \emph{who} executes while it fits \citep{yirage2026,dao2022flashattention}.
Register skew from tiling can invalidate memory pass---run passes in a loop until fixed point or split \citep{chen2020compilerbasedhardw,memoryfloor2026,shah2024flashattention3}.

\paragraph{Fusion boundary coupling.}
Tiling pass must co-decide how far to fuse: too little fusion $\rightarrow$ dispatch tax returns; too much $\rightarrow$ residency or role imbalance \citep{taxbreak2026,memoryfloor2026,yirage2026}.
Stopping rule: largest fused region where memory pass \emph{and} tiling pass both succeed \citep{wu2024mirage,shah2024flashattention3,chen2020compilerbasedhardw}.
This is Chapter~\ref{chap:ch06} export-edge logic with roles in the loop \citep{dao2022flashattention,patel2025llminference}.

\paragraph{Precision and tile co-search.}
FP8/int8 tiles move fewer bytes---may allow smaller producer teams or larger consumer tiles \citep{shah2024flashattention3,dlbook}.
Tiling pass must search format and shape jointly for decode cells \citep{memoryfloor2026,yirage2026}.
Bytes/token and role balance move together---do not tune them in isolation \citep{taxbreak2026,patel2025llminference}.

\paragraph{Documentation bundle.}
Ship with every staticization merge: staticization level, ratio worksheet, tri-hardware role row, tiling IR excerpt, checklist \citep{yirage2026,chen2020compilerbasedhardw,shah2024flashattention3,taxbreak2026,patel2025llminference}.
Private warp splits do not survive team turnover \citep{mpk2025,wu2024mirage}.

\paragraph{$\checkmark$ Practice checkpoint.}
Archive tiling-pass schedule IR snippet on every staticization PR \citep{yirage2026,wu2024mirage}.

\section{Role Assignment Pitfalls and Checklist}
\label{sec:ch07_role_pitfalls}

\subsection{Five common anti-patterns}
\begin{enumerate}
\item \textbf{Ratio imbalance.}
\emph{Symptom:} consumer warps stall on \texttt{mbarrier}; producers idle \citep{shah2024flashattention3,patel2025llminference}.
\emph{Root cause:} prefill-biased producer/consumer split on decode GEMV \citep{taxbreak2026,memoryfloor2026}.
\emph{Fix:} re-run Axis~1 worksheet; add producer warps \citep{yirage2026}.
\emph{Prevention:} Pattern~2 mandatory on decode PRs \citep{shah2024flashattention3,chen2020compilerbasedhardw}.

\item \textbf{Barrier misplacement.}
\emph{Symptom:} pipeline bubbles, rare data races \citep{semianalysis2024tma,nvidia2022hopper}.
\emph{Root cause:} consumer starts before TMA completion signal \citep{shah2024flashattention3}.
\emph{Fix:} one barrier pair per ping-pong stage; verify with race check \citep{yirage2026}.
\emph{Prevention:} barrier walkthrough in Section~\ref{sec:ch07_role_decision} \citep{semianalysis2024tma,patel2025llminference}.

\item \textbf{Over-staticization.}
\emph{Symptom:} some SMs idle on irregular batches \citep{shah2024flashattention3,mpk2025}.
\emph{Root cause:} L3 megakernel on workloads needing tile scheduler \citep{patel2025llminference}.
\emph{Fix:} step down to L2 persistent; keep host graph flexibility \citep{nvidia2024cudagraphs}.
\emph{Prevention:} Table~\ref{tab:ch07_static_economics} review before L3 commitment \citep{mpk2025,yirage2026}.

\item \textbf{Resource omission.}
\emph{Symptom:} spill after enabling ping-pong roles \citep{memoryfloor2026,yirage2026}.
\emph{Root cause:} role plan ignored Ch.~6 double-buffer bytes or register skew \citep{dao2022flashattention,chen2020compilerbasedhardw}.
\emph{Fix:} joint residency+role worksheet; Section~\ref{sec:ch07_joint_residency} \citep{yirage2026,shah2024flashattention3}.
\emph{Prevention:} Pattern~3 on every skew change \citep{wu2024mirage,mpk2025}.

\item \textbf{Prefill copy-paste.}
\emph{Symptom:} high TFLOPs, poor tokens/sec at batch-1 \citep{shah2024flashattention3,taxbreak2026}.
\emph{Root cause:} consumer-heavy split on memory-bound decode \citep{memoryfloor2026,patel2025llminference}.
\emph{Fix:} decode worksheet (Table~\ref{tab:ch07_role_worked_example}) \citep{yirage2026}.
\emph{Prevention:} separate decode and prefill benchmark tabs \citep{kwon2023vllm,shah2024flashattention3}.
\end{enumerate}

\paragraph{Anti-pattern culture.}
Treat ``we copied FA3 config'' as a red flag in review \citep{shah2024flashattention3,patel2025llminference,taxbreak2026}.
Require decode ratio worksheet even when prefill kernel exists \citep{yirage2026,kwon2023vllm,memoryfloor2026}.
Static roles without measurement are folklore---stall counters or simulation required \citep{patel2025llminference,chen2020compilerbasedhardw,shah2024flashattention3}.

\paragraph{Debug playbook (expanded).}
\textbf{Stalls rising:} check producer count first, barrier order second, tile size third \citep{shah2024flashattention3,yirage2026,semianalysis2024tma}.
\textbf{Spill appearing:} rerun Ch.~6 peak with skew; reduce consumer registers or split fusion \citep{memoryfloor2026,dao2022flashattention,chen2020compilerbasedhardw}.
\textbf{Launches flat:} you optimized inner loop but not staticization level---revisit Table~\ref{tab:ch07_static_levels} \citep{taxbreak2026,nvidia2024cudagraphs,mpk2025}.
\textbf{NPU fail:} compare role map row to GPU row---do not port warp counts literally \citep{amd2024xdna,patel2025llminference,yirage2026}.

\paragraph{Pattern 1: Launch-storm diagnosis.}

\textbf{Notes:} validate stalls, not TFLOPs \citep{memoryfloor2026}.

\paragraph{Pattern 3: Joint residency rerun.}
\textbf{Scene:} register skew after warp split \citep{shah2024flashattention3,nvidia2022hopper}.

\textbf{Benefit:} catches spill before production \citep{memoryfloor2026}.
\textbf{Notes:} roles and residency are coupled \citep{wu2024mirage}.

\textbf{Scene:} CUDA schedule works; XDNA compile fails \citep{amd2024xdna,taxbreak2026}.

\textbf{Benefit:} fleet-safe IR \citep{amd2024aie,nvidia2022hopper}.
\textbf{Notes:} IR parity $\neq$ role parity \citep{yirage2026}.

\paragraph{Pattern 5: Ladder documentation.}
\textbf{Scene:} team debates megakernel vs graphs \citep{mpk2025,nvidia2024cudagraphs}.

\textbf{Notes:} L3 needs frozen fusion \citep{wu2024mirage,mpk2025}.

\paragraph{Pattern 6: Tiling pass artifact.}
\textbf{Scene:} hand-tuned warp split lost on model update \citep{shah2024flashattention3,yirage2026}.

\paragraph{Pattern usage.}
Require Pattern~2 on decode PRs; Pattern~4 on IR changes; Pattern~6 on staticization merges \citep{yirage2026,taxbreak2026,shah2024flashattention3,patel2025llminference,chen2020compilerbasedhardw}.

\section{Key Takeaways}
\label{sec:ch07_key_takeaways}

Static role assignment closes the loop opened in Chapter~\ref{chap:ch06}: residency budgets become actor assignments that eliminate per-token dispatch \citep{yirage2026,shah2024flashattention3,mpk2025,patel2025llminference}.
The principles below pair design rules with actions your team can adopt this sprint \citep{chen2020compilerbasedhardw,taxbreak2026,memoryfloor2026}.

\begin{itemize}
\item \textbf{Static-first principle.}
Decode pays scheduling per token---fix roles at compile time when workload is regular \citep{taxbreak2026,mpk2025,patel2025llminference}.
Launch storms (847.5/token on 1B dense) are assignment problems as much as fusion problems \citep{taxbreak2026}.
\textbf{Action:} pick L1--L3 level explicitly; measure launches/token before and after \citep{nvidia2024cudagraphs,yirage2026}.

\item \textbf{Ratio-adaptation principle.}
Producer/consumer split follows memory/compute mismatch---decode tilts producer-heavy vs prefill \citep{shah2024flashattention3,memoryfloor2026,kwon2023vllm}.
Copying FA3 prefill splits to batch-1 decode is anti-pattern~5 \citep{patel2025llminference,taxbreak2026}.
\textbf{Action:} complete Table~\ref{tab:ch07_role_worked_example} for your layer; attach stall counters \citep{yirage2026}.

\item \textbf{Resource-linkage principle.}
Role assignment changes register residency---joint optimize with Chapter~\ref{chap:ch06} \citep{dao2022flashattention,yirage2026,chen2020compilerbasedhardw}.
Skew without peak rerun is how spill sneaks into production \citep{memoryfloor2026,nvidia2022hopper}.
\textbf{Action:} rerun peak worksheet after every warp skew change \citep{yirage2026,dao2022flashattention}.

\item \textbf{Graded-landing principle.}
Higher staticization is not always better---match level to model churn and shape stability \citep{mpk2025,patel2025llminference,nvidia2024cudagraphs}.
L3 megakernels trade flexibility for launch elimination---document the trade \citep{taxbreak2026,wu2024mirage}.
\textbf{Action:} record level in benchmark metadata and README \citep{taxbreak2026,yirage2026}.

\item \textbf{Compiler-internalization principle.}
Roles belong in YiRage tiling pass output---not tribal CUDA knowledge \citep{yirage2026,wu2024mirage,mpk2025}.
Chapter~20 search consumes role IR---hand splits do not compose across model versions \citep{wu2024mirage,chen2020compilerbasedhardw,patel2025llminference}.
\textbf{Action:} attach schedule IR + checklist to CI artifacts; block drift without worksheet updates \citep{yirage2026,shah2024flashattention3,taxbreak2026}.
\end{itemize}

Roles (Ch.~7) $\rightarrow$ async pipelines (Ch.~8) $\rightarrow$ sync discipline (Ch.~9) $\rightarrow$ softmax carriers (Ch.~10) $\rightarrow$ assembly (Ch.~11) \citep{dao2022flashattention,semianalysis2024tma,shah2024flashattention3,mpk2025,patel2025llminference}.

\section{Conclusion}
\label{sec:ch07_conclusion}

Static role assignment spends Chapter~\ref{chap:ch06}'s residency budget on a schedule-free structure: every warp, warpgroup, or tile knows its job before the first token \citep{shah2024flashattention3,mpk2025,yirage2026}.
The quantitative framework, tri-hardware map, staticization ladder, and tiling pass turn principle into repeatable engineering \citep{patel2025llminference,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Closing metaphor.}
If Chapter~\ref{chap:ch06} is the warehouse layout, this chapter is the org chart---who unloads trucks (producers) and who assembles orders (consumers) \citep{dao2022flashattention,yirage2026,shah2024flashattention3}.
A perfect layout with no job titles still has people standing in the loading bay asking ``what next?'' each token \citep{taxbreak2026,mpk2025}.
Static roles eliminate that question; Chapter~\ref{chap:ch08} keeps the trucks arriving on time \citep{semianalysis2024tma,dao2022flashattention}.

Chapter~\ref{chap:ch08} addresses the next failure mode: \textbf{keeping producers fed}---TMA double-buffer pipelines and async movement so statically assigned consumers never stall waiting for data \citep{semianalysis2024tma,dao2022flashattention}.
Carry role worksheets and staticization level into every async-pipeline change \citep{yirage2026,memoryfloor2026}.

\paragraph{Part~IV bridge.}
Roles (this chapter) + movement (Ch.~8) + sync (Ch.~9) + carriers (Ch.~10) assemble the megakernel stack \citep{dao2022flashattention,shah2024flashattention3,mpk2025}.
