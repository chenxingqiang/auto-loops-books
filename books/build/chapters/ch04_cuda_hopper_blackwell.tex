\section{Why Hopper Features Do Not Automatically Speed Up Decode}
\label{sec:industrial_hook}

One production team spent a month raising tensor-core utilization on H100---end-to-end batch-1 decode latency fell only ${\sim}3\%$.
Nsight showed excellent TMA overlap and higher TC occupancy, but bytes/token and launches/token were unchanged: activations still exported to HBM between every op boundary \citep{memoryfloor2026,taxbreak2026}.
\textbf{Hopper features hide latency and widen on-chip capacity; they do not remove traffic you never fused away.}

\paragraph{Bridge from Chapters~2--3.}
Chapter~2 said plan residency before exports; Chapter~3 gave the byte budgets \citep{yirage2026,chen2020compilerbasedhardw}.
This chapter instantiates those budgets on Hopper: 228\,KB shared memory, TMA, clusters, and tensor cores as \emph{tools in a fixed optimization order}---not a shopping list \citep{nvidia2022hopper,semianalysis2024tma}.

\paragraph{Hopper decode optimization priority (use this order).}
\begin{enumerate}
\item \textbf{Cut activation HBM traffic}---layer fusion (Chapter~2 export-edge mindset); largest gain \citep{memoryfloor2026,dao2022flashattention}.
\item \textbf{Cut kernel launch overhead}---CUDA Graph + MegaKernel; attacks launches/token \citep{taxbreak2026,nvidia2024cudagraphs}.
\item \textbf{Hide memory latency}---TMA double-buffer; does not reduce bytes \citep{semianalysis2024tma}.
\item \textbf{Widen fusion tiles}---thread-block clusters + DSM \citep{nvidia2022hopper}.
\item \textbf{Minimize sync scope}---warp shuffle before block/cluster barriers \citep{dao2022flashattention}.
\item \textbf{Tune tensor cores and PTX last}---when bytes/token and launches/token are already clean \citep{patel2025llminference,memoryfloor2026}.
\end{enumerate}

\paragraph{Terminology alignment with Chapters~1--3.}
We use \emph{kernel launch overhead} for per-token launch tax, \emph{scheduling overhead} for host/framework orchestration, and \emph{data residency} for on-chip lifetime of activation carriers \citep{taxbreak2026,chen2020compilerbasedhardw,memoryfloor2026}.

\section{Hopper Memory Hierarchy: Fusion Hard Boundaries}
\label{sec:cuda_memory_hierarchy}

Decode MegaKernels hold QKV tiles, online softmax carriers, and SwiGLU fragments simultaneously---each must map to a CUDA tier for the kernel lifetime \citep{dao2022flashattention,yirage2026}.
Spill to HBM is a bytes/token bill; treat it as a fusion failure \citep{memoryfloor2026}.

\paragraph{Terminology.}
A \textbf{CTA} (cooperative thread array) is a CUDA thread block---the launch grain that shares one shared-memory pool \citep{nvidia2022hopper}.
Hopper exposes up to 228\,KB configurable shared memory per SM (227\,KB usable per block after reserve) and a 65{,}536-register file \citep{nvidia2022hopper}.

\paragraph{Shared memory capacity (constraint loop).}
\textbf{Engineering meaning:} hard ceiling for fused decode tiles---Chapter~3's GPU row, now Hopper-specific \citep{yirage2026}.
\textbf{Common pitfall:} tensor bytes only, ignoring padding, double buffers, softmax score tiles \citep{dao2022flashattention}.
\textbf{Debug:} Nsight Compute shared-memory config; elevated \texttt{local memory traffic} signals spill \citep{patel2025llminference}.

\paragraph{Register pressure.}
Fusion deepens live ranges; occupancy may drop yet bytes/token still wins when HBM exports disappear \citep{memoryfloor2026,semianalysis2024tma}.
\textbf{Debug:} registers per thread and spill counters before MMA tile sweeps \citep{yirage2026}.

\paragraph{KV versus activation traffic.}
Weights and KV legitimately stream from HBM each token---fusion targets \emph{activation} exports between attention, softmax, and MLP \citep{kwon2023vllm,memoryfloor2026,dao2022flashattention}.
A common review mistake is celebrating lower DRAM traffic while KV alone explains the counter---diff activation bytes specifically \citep{patel2025llminference,taxbreak2026}.

\paragraph{Roofline at batch one.}
Decode GEMMs present thin $M$ with large $K/N$; arithmetic intensity stays on the memory roof for realistic LLM widths \citep{dlbook,memoryfloor2026}.
Registers and shared memory buy effective intensity without changing FLOP counts---that is the mechanical-sympathy lever Hopper provides \citep{nvidia2022hopper,semianalysis2024tma}.

\paragraph{Blackwell note.}
Successor SKUs extend TMA and low-precision tensor paths; residency invariants in this section survive---only capacity rows and legality tables change in the chip model \citep{liu2024deepseekv3,yirage2026,patel2025llminference}.

\paragraph{Cross-hardware note.}
GPU shared memory is software-managed---flexible but easy to overflow \citep{nvidia2022hopper}.
XDNA tile SRAM is fixed at compile time---inflexible but deterministic (Chapter~5) \citep{amd2024xdna,amd2024aie}.
Same Chapter~2 residency goal; different legality mechanics \citep{chen2020compilerbasedhardw}.

\paragraph{$\checkmark$ Practice checkpoint.}
Statically budget shared memory + registers for the full fused region; reject merges that exceed 227\,KB usable before codegen \citep{yirage2026,memoryfloor2026}.

\paragraph{Worked tier assignment exercise.}
For one transformer layer, list every $\Theta(d)$ tensor between attention and MLP: post-norm hidden, Q/K/V fragments, attention output, MLP intermediates, residuals \citep{dao2022flashattention,memoryfloor2026}.
Mark each as register, shared, or global for your fused plan \citep{yirage2026,chen2020compilerbasedhardw}.
Any global mark between fused stages is a bytes/token bug unless proven dead \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Spill versus intentional HBM.}
Intentional traffic: weights, KV appends, final layer outputs to framework buffers \citep{kwon2023vllm,dlbook}.
Spill traffic: softmax carriers, score tiles, or MLP fragments written because shared memory overflowed \citep{memoryfloor2026,dao2022flashattention,patel2025llminference}.
Nsight distinguishes them via local memory loads and stack-like access patterns \citep{semianalysis2024tma}.

\paragraph{Occupancy versus fusion trade.}
High shared-memory configs lower resident blocks per SM yet may still win on ms/token when fusion deletes HBM passes \citep{memoryfloor2026,semianalysis2024tma,taxbreak2026}.
Optimize occupancy only after proving legality and bytes/token improvement \citep{yirage2026,patel2025llminference}.
Lab charts that show ``low occupancy'' without bytes/token context mislead reviewers \citep{memoryfloor2026}.

\paragraph{Example unfused traffic.}
Llama-class stacks often materialize six to eight $\Theta(d)$ activation buffers per layer at batch-1 \citep{taxbreak2026,dao2022flashattention,memoryfloor2026}.
At $d{=}4096$ BF16, six round trips imply roughly $6 \times 4096 \times 2 \approx 49$\,KB activation traffic per layer per token before KV reads \citep{kwon2023vllm,memoryfloor2026}.
Fusion targets that bill first \citep{chen2020compilerbasedhardw,yirage2026}.

\paragraph{Shared-memory bank conflicts (constraint loop).}
\textbf{Engineering meaning:} legal capacity can still serialize when strided layouts hit the same 32-way bank set---Chapter~3's GPU row, now layout-specific \citep{nvidia2022hopper,shah2024flashattention3}.
\textbf{Common pitfall:} padding score tiles for capacity but leaving WGMMA-unfriendly strides \citep{dao2022flashattention}.
\textbf{Debug:} Nsight shared-memory conflict counters; compare swizzled versus naive layouts before blaming TMA \citep{yirage2026,patel2025llminference}.
Hopper fusion must swizzle for \textbf{WGMMA} (warpgroup matrix multiply-accumulate) consumption, not only fit byte totals \citep{semianalysis2024tma,shah2024flashattention3}.

\paragraph{Chapter~2 iron rule link.}
Iron Rule~2 (keep activations on-chip across stages) is implemented here as shared-memory and register budgets \citep{chen2020compilerbasedhardw,memoryfloor2026,dao2022flashattention}.
Violating the rule exports to global---bytes/token rises even if TMA overlap looks healthy \citep{semianalysis2024tma,taxbreak2026}.

\paragraph{L2 hidden export.}
Even legal shared-memory plans can lose if every stage writes full vectors through L2 to HBM \citep{memoryfloor2026,kwon2023vllm}.
Fusion must minimize round trips, not only fit in shared memory while exporting intermediates \citep{chen2020compilerbasedhardw,dao2022flashattention,yirage2026}.

\paragraph{Multi-hardware delta (again).}
CPU L3 blocking and XDNA static tiles solve the same export problem with different legality \citep{amd2024xdna,dlbook,rotem2018glow,patel2025llminference}.
Hopper's programmable shared memory is powerful and easy to overflow---that is the engineering tension \citep{nvidia2022hopper,yirage2026,memoryfloor2026}.

\paragraph{Memory tier cheat sheet for reviewers.}
When reviewing CUDA diffs ask: where do QKV fragments live between ops? Where do $(m,\ell,o)$ live in the KV loop? Where does SwiGLU intermediate sit? \citep{dao2022flashattention,memoryfloor2026,yirage2026}
Any answer of ``global'' between fused stages is a regression unless proven dead \citep{chen2020compilerbasedhardw,taxbreak2026}.

\section{Tensor Memory Accelerator: Hide Latency, Not Traffic}
\label{sec:tma}

\textbf{TMA} (Tensor Memory Accelerator) issues asynchronous bulk copies from global memory to shared memory while MMA units compute on the previous tile \citep{nvidia2022hopper,semianalysis2024tma}.
TMA overlaps latency; only fusion reduces activation bytes/token \citep{memoryfloor2026}.

\paragraph{Applicable when.}
Tile boxes ${\gtrsim}128{\times}128$ with contiguous global addresses and amortized descriptor setup---weight blocks, contiguous KV slices, steady double-buffer pipelines inside a MegaKernel \citep{semianalysis2024tma,dao2023flashdecoding}.

\paragraph{Avoid when.}
Batch-1 $M{=}1$ micro-tiles, irregular paged-KV gathers, or descriptor setup dominating copy time \citep{kwon2023vllm,taxbreak2026}.
Profile TMA versus vector loads on the target shape \citep{yirage2026}.

\paragraph{Common pitfalls.}
Double-buffer handoff bugs (compute on buffer being overwritten); paged KV non-contiguous addresses; mandating TMA on thin tiles \citep{dao2023flashdecoding,patel2025llminference}.

\paragraph{Debug.}
Nsight Compute: \texttt{TMA busy cycles} vs \texttt{MMA busy cycles}---ratio below ${\sim}0.3$ suggests weak TMA benefit; check \texttt{local memory loads} for spill \citep{semianalysis2024tma}.

\paragraph{Paged KV co-design.}
vLLM block tables map logical tokens to non-contiguous physical blocks \citep{kwon2023vllm}.
TMA descriptors assume regular layouts---MegaKernels rebuild or index descriptors per block inside the KV loop \citep{dao2023flashdecoding,yirage2026}.
This is production-hard; Chapter~8 returns to double-buffer theory \citep{semianalysis2024tma}.

\paragraph{Manual load fallback.}
Vectorized global loads remain valid when TMA setup dominates---YiRage should lower both paths and select with a profile-guided cost model, not a global compile flag \citep{yirage2026,taxbreak2026,dlbook}.
Teams that mandate TMA in code review without shapes invite the anti-pattern in Section~\ref{sec:hopper_tuning_practice} \citep{patel2025llminference}.

\paragraph{Batch-1 thin-$M$ reality.}
Many decode GEMMs present $M{=}1$ with large inner dimension \citep{dlbook,taxbreak2026}.
TMA shines when copy boxes amortize over deep pipelines inside a MegaKernel---not when each score fragment is a separate descriptor \citep{semianalysis2024tma,yirage2026}.
Profile on \emph{your} head dimension and KV block size, not a square GEMM microbench \citep{patel2025llminference,memoryfloor2026}.

\paragraph{Energy angle.}
HBM transactions dominate decode energy \citep{memoryfloor2026,patel2025llminference}.
Fusion bytes/token savings matter for TCO even when ms/token gains look modest in lab cells \citep{taxbreak2026,amd2024xdna}.
TMA overlap saves time; fusion saves joules per token \citep{semianalysis2024tma,memoryfloor2026}.

\paragraph{Synchronization case study.}
Double-buffered TMA needs one barrier after copy completes and one before overwriting the consumed buffer \citep{semianalysis2024tma,yirage2026,nvidia2022hopper}.
Extra barriers after each warp shuffle in softmax add pipeline bubbles without safety benefit \citep{dao2022flashattention,dlbook}.
Compiler sync insertion should be edge-driven on the fused DAG \citep{chen2020compilerbasedhardw,yirage2026}.

\paragraph{Long-context stability.}
TMA misalignment bugs may hide at $T{=}512$ and explode at $T{=}8192$ \citep{dao2023flashdecoding,patel2025llminference}.
Always include long-ctx buckets in Hopper validation---not only the bucket your laptop tests \citep{kwon2023vllm,yirage2026}.

\paragraph{Observability hooks.}
Stable kernel names derived from pass hashes help profilers map samples to bufferization tiers \citep{yirage2026,chen2020compilerbasedhardw,patel2025llminference}.
Production builds may strip debug tags but should retain residency class notes in release artifacts \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Warp-group context.}
Hopper issues WGMMA from warpgroups of four warps---thirty-two threads each \citep{shah2024flashattention3,nvidia2022hopper}.
Fusion planners must align head partitions and tile shapes to warpgroup granularity or leave MMA lanes idle \citep{dao2022flashattention,yirage2026,patel2025llminference}.

\paragraph{First-token versus steady state.}
Compile and capture costs hit first token; steady decode steps reveal residency wins \citep{nvidia2024cudagraphs,kwon2023vllm,taxbreak2026}.
Benchmark both when product SLOs include cold start \citep{patel2025llminference,memoryfloor2026}.

\paragraph{Descriptor lifecycle.}
Host or device code builds a TMA descriptor with global layout, shared destination, and copy box \citep{nvidia2022hopper,semianalysis2024tma}.
Weight descriptors are often static per compiled bucket; KV descriptors may change with block-table indices each iteration \citep{kwon2023vllm,yirage2026}.
Misaligned layouts produce silent numerical drift---always pair kernel changes with FP64 reference diffs at long ctx \citep{dao2023flashdecoding}.

\paragraph{Figure~\ref{fig:tma_pipeline} usage.}
The timeline is the steady-state target---getting there requires correct double-buffer handoffs and legal tile sizes \citep{semianalysis2024tma,yirage2026,dao2022flashattention}.
If steady state never appears in timelines, fix fusion legality before tuning descriptor fields \citep{patel2025llminference,memoryfloor2026}.

\paragraph{Chapter~2 link.}
TMA implements \emph{pipeline movement} on-chip---moving data while math runs---but does not replace export-edge removal \citep{chen2020compilerbasedhardw,memoryfloor2026}.

\paragraph{Cluster versus single-block decision tree.}
If fused tile fits in 227\,KB usable with margin, stay single-block \citep{nvidia2022hopper,yirage2026}.
If score tile or SwiGLU buffer exceeds block cap but fits pooled DSM, plan cluster \citep{semianalysis2024tma,dao2023flashdecoding}.
If neither fits, split fusion at Chapter~2 export edge---do not spill \citep{memoryfloor2026,chen2020compilerbasedhardw,taxbreak2026}.

\paragraph{Flash-Decoding without extra launches.}
KV splits across SMs need in-kernel online softmax merges \citep{dao2023flashdecoding,dao2022flashattention}.
Extra merge kernels reopen launches/token---design cluster or in-kernel merge before accepting multi-kernel fallback \citep{taxbreak2026,nvidia2024cudagraphs,yirage2026}.

\paragraph{$\checkmark$ Practice checkpoint.}
Confirm double-buffer invariants in code review; one barrier after TMA complete, one before buffer reuse \citep{yirage2026,semianalysis2024tma}.

\section{Thread Block Clusters and Distributed Shared Memory}
\label{sec:ch04_cluster_dsm}

Hopper \textbf{thread-block clusters} pool \textbf{DSM} (distributed shared memory) across cooperating CTAs---widening the on-chip fusion envelope without an HBM export \citep{nvidia2022hopper,semianalysis2024tma}.

\paragraph{Applicable when.}
Score tiles or fused buffers exceed single-block shared memory; Flash-Decoding-style KV splits need cross-block softmax reductions \citep{dao2023flashdecoding,dao2022flashattention}.

\paragraph{Avoid when.}
Footprint already fits one block---clusters add sync and launch complexity without residency win \citep{yirage2026}.

\paragraph{Common pitfalls.}
Cluster launch illegal on target SKU; DSM double-counted in planners; fallback merge kernel reintroduces launches/token \citep{taxbreak2026,chen2020compilerbasedhardw}.

\paragraph{Debug.}
Compile-time cluster legality report; Nsight timeline for extra barriers; compare launches/token with single-block plan \citep{yirage2026,patel2025llminference}.

YiRage must reject illegal cluster dims at compile time---no silent multi-kernel fallback \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Flash-Decoding link.}
When KV is split across SMs, partial softmax statistics must merge on-chip \citep{dao2023flashdecoding,dao2022flashattention}.
An extra merge kernel reopens launches/token---cluster DSM exists to keep the merge inside the MegaKernel capture region \citep{taxbreak2026,nvidia2024cudagraphs}.
If your SKU forbids the cluster shape, document the multi-kernel fallback cost explicitly in the worksheet \citep{patel2025llminference}.

\paragraph{Capacity accounting with DSM.}
Cluster pooling increases peak scratch but also increases barrier scope \citep{nvidia2022hopper,semianalysis2024tma}.
Planners must sum DSM bytes across CTAs in the cluster---double-booking is as fatal as single-block overflow \citep{yirage2026,memoryfloor2026}.
Chapter~3's inequality mindset applies; only the geometry changes \citep{chen2020compilerbasedhardw}.

\paragraph{Comparison to CPU AVX paths.}
CPU decode uses cache-blocked GEMMs and vectorized exp2 on softmax \citep{dlbook,patel2025llminference,amd2024xdna}.
Hopper wins when fusion keeps data on SM; CPU wins when GPU launch storms dominate at low QPS \citep{taxbreak2026,memoryfloor2026,yirage2026}.
Triplet tests prevent declaring victory on GPU ms/token alone \citep{amd2024aie,patel2025llminference}.

\paragraph{Grid sync warning.}
Device-wide synchronization stalls every CTA and destroys graph-capture friendliness \citep{taxbreak2026,nvidia2024cudagraphs,nvidia2022hopper}.
If an algorithm seems to need grid sync per token, revisit fusion boundaries or cluster merges first \citep{dao2023flashdecoding,yirage2026}.

\paragraph{Producer-consumer sync edges.}
List edges in the fused DAG where shared-memory buffers hand off between TMA, MMA, and epilogue phases \citep{yirage2026,chen2020compilerbasedhardw,semianalysis2024tma}.
Insert barriers only on those edges---extra block syncs show as bubbles in Nsight timelines \citep{patel2025llminference,dao2022flashattention}.

\paragraph{Figure~\ref{fig:cuda_sync_levels} usage.}
Pick the leftmost mechanism that preserves correctness---grid sync is almost never the answer in per-token decode \citep{taxbreak2026,nvidia2022hopper,dao2022flashattention}.
Chapter~9 expands sync insertion algorithms \citep{yirage2026,chen2020compilerbasedhardw}.

\paragraph{Quantitative intuition.}
Removing six $d$-vector HBM round trips at $d{=}4096$ BF16 saves ${\sim}49$\,KB activation traffic per layer per token---often larger than a 10-point TC utilization gain on $1{\times}4096$ GEMM \citep{memoryfloor2026,taxbreak2026}.
After fusion cleans bytes/token, TMA-fed MMA epilogues matter \citep{semianalysis2024tma,dao2022flashattention}.

\paragraph{SFU versus MMA balance.}
Attention decode interleaves WGMMA matmuls with SFU-heavy softmax \citep{dao2022flashattention,nvidia2022hopper}.
Profiling both pipelines prevents false ``TC-bound'' diagnoses when softmax is the long pole inside the same SM \citep{patel2025llminference,liu2024deepseekv3}.
Refer back to Section~\ref{sec:ch04_tensor_core_bounds} before opening tile configurators \citep{memoryfloor2026}.

\paragraph{Quantization on Hopper.}
FP8 and INT8 weights need dequant in-register or in shared memory \citep{liu2024deepseekv3,patel2025llminference,nvidia2022hopper}.
Scales consume the same residency budget as softmax carriers---co-decide with fusion grouping \citep{memoryfloor2026,yirage2026}.
Dropping precision without retile can change padding and spill behavior \citep{chen2020compilerbasedhardw}.

\paragraph{Blackwell FP4 trajectory.}
Successor chips advertise wider low-precision tensor paths \citep{liu2024deepseekv3,nvidia2022hopper,patel2025llminference}.
Porting re-tiles kernels but preserves the pyramid: bytes, launches, latency, TC \citep{memoryfloor2026,taxbreak2026,yirage2026,semianalysis2024tma}.

\paragraph{Team A versus Team B (retold).}
Team A improves MMA tile from 1\% to 3\% TC util; Team B fuses an MLP boundary saving ${\sim}40\%$ activation bytes---only Team B moves p99 at batch-1 when $R_{\mathrm{floor}}$ is low \citep{memoryfloor2026,taxbreak2026,patel2025llminference,dao2022flashattention}.
Use this story in backlog prioritization \citep{yirage2026,taxbreak2026}.

\paragraph{Table~\ref{tab:tc_decode} usage.}
Match profiler signals to the ``first action'' column before opening code \citep{patel2025llminference,memoryfloor2026,taxbreak2026}.
High TC util with flat ms/token is a diagnostic row, not a success row \citep{memoryfloor2026,dao2022flashattention}.

\paragraph{PTX review culture.}
Softmax-related PTX changes are not ``micro-optimizations''---they are ABI changes \citep{dao2022flashattention,liu2024deepseekv3,yirage2026,patel2025llminference}.
Treat them with the same rigor as fusion grouping changes \citep{chen2020compilerbasedhardw,dao2023flashdecoding}.

\section{PTX and Softmax Micro-ops}
\label{sec:ch04_ptx}

Online softmax uses \textbf{SFU} (special-function unit) pipelines for \textbf{exp2}-style exponentials \citep{dao2022flashattention,nvidia2022hopper}.
\textbf{WGMMA} (warp-group matrix multiply-accumulate) is Hopper's tensor-core instruction issued by warpgroups of four warps \citep{shah2024flashattention3}.

\paragraph{PTX as ABI.}
Reviewed \texttt{ex2.approx} sequences with explicit max-subtraction and documented \textbf{FTZ} (flush-to-zero) behavior \citep{liu2024deepseekv3,patel2025llminference}.
Changing PTX without FP64 reference diffs at $T{=}8192$ breaks fleet determinism \citep{dao2023flashdecoding,yirage2026}.

\paragraph{Advance notice.}
This subsection needs basic CUDA/PTX literacy; skipping it does not block fusion or TMA work above \citep{dlbook}.

\paragraph{$\checkmark$ Practice checkpoint.}
Softmax PTX changes require FP64 diffs at ctx $\in\{512,2048,8192\}$ before merge \citep{dao2022flashattention,yirage2026}.

\paragraph{Inline PTX in production.}
DeepSeek-style kernels select SFU instructions predictably rather than hoping the compiler discovers them \citep{liu2024deepseekv3,yirage2026}.
Separate softmax launches break MegaKernel boundaries and reopen launches/token \citep{taxbreak2026,memoryfloor2026,dao2022flashattention}.
PTX belongs inside the fused region, not as a follow-on kernel \citep{yirage2026,chen2020compilerbasedhardw}.

\section{YiRage CUDA Backend: Hardware Constraints as Compile Gates}
\label{sec:ch04_yirage_cuda_backend}

\paragraph{Advance notice.}

YiRage lowers the same decode IR to CUDA, CPU, and XDNA---Hopper legality is dynamic residency checking against chip models from Chapter~3 \citep{yirage2026,chen2020compilerbasedhardw,amd2024xdna}.

\paragraph{Five compiler invariants (decode mode).}
\begin{enumerate}
\item \textbf{No activation-sized global stores} inside a fused region---\emph{YiRage:} \texttt{BufferizationPass} rejects illegal stores at compile time instead of emitting silent spill \citep{memoryfloor2026,yirage2026}.
\item \textbf{TMA legality is per-copy}---\emph{YiRage:} \texttt{TmaSelectionPass} chooses TMA or vector loads per copy edge \citep{semianalysis2024tma,taxbreak2026}.
\item \textbf{Cluster dims are compile-time contracts}---\emph{YiRage:} \texttt{ClusterPlanningPass} fails the build on illegal DSM geometry \citep{nvidia2022hopper,yirage2026}.
\item \textbf{Softmax PTX is versioned ABI}---\emph{YiRage:} \texttt{PtxLoweringPass} pins reviewed \texttt{exp2} sequences; CI diffs long-ctx numerics \citep{dao2022flashattention,liu2024deepseekv3}.
\item \textbf{Triplet bufferization}---\emph{YiRage:} \texttt{FusionGroupingPass} must export legality summaries for CUDA, CPU, and XDNA backends \citep{amd2024aie,patel2025llminference}.
\end{enumerate}

\section{Hopper Decode Tuning in Practice}
\label{sec:hopper_tuning_practice}

This section consolidates profiling workflow, reusable patterns, a quantified case study, and concentrated anti-patterns---the material formerly scattered across profiling, patterns, and compiler-reference sections \citep{patel2025llminference,taxbreak2026}.

\subsection{Profile-first workflow}
Start from median ms/token at BS${=}1$; decompose launches/token (TaxBreak) and bytes/token (Memory-Floor / Nsight DRAM) \citep{taxbreak2026,memoryfloor2026}.
Nsight Systems for launch storms and graph replay; Nsight Compute for spill, DRAM bytes, TMA vs MMA busy cycles \citep{patel2025llminference,semianalysis2024tma}.
\textbf{Order:} end-to-end token latency $\rightarrow$ bytes $\rightarrow$ launches $\rightarrow$ TC utilization \citep{memoryfloor2026}.

\paragraph{Systems versus Compute.}
Systems answers ``how many launches and how much host noise''; Compute answers ``did we spill and did DRAM bytes drop'' \citep{patel2025llminference,semianalysis2024tma,nvidia2024cudagraphs}.
A fused kernel can lose isolated kernel timers yet win end-to-end ms/token when launch storms disappear \citep{taxbreak2026,memoryfloor2026}.
Never promote based on kernel-only timers alone \citep{patel2025llminference}.

\paragraph{Register carriers for online softmax.}
Each head keeps $(m,\ell)$ scalars and a partial output vector---often FP32 even when matmul uses BF16 \citep{dao2022flashattention,dlbook}.
Sixteen heads multiply register pressure; warp-specialized layouts assign warpgroups per head cluster to keep shuffle reductions in-register \citep{nvidia2022hopper,yirage2026,shah2024flashattention3}.
This is why the shared-memory sheet and register sheet are one joint budget \citep{memoryfloor2026}.

\paragraph{Postmortem sequence.}
When Hopper decode regresses after a merge: diff launches/token, replay bytes/token worksheet, compare DRAM delta on fused kernel, bisect graph vs fusion, \emph{then} consider driver or clock issues \citep{taxbreak2026,memoryfloor2026,patel2025llminference,nvidia2024cudagraphs}.
Skipping bytes/token replay wastes days on launch-only noise \citep{yirage2026}.

\paragraph{Teaching versus production CUDA.}
Courses emphasize square GEMM microbenchmarks; production decode emphasizes residency graphs and goodput counters \citep{dlbook,taxbreak2026,memoryfloor2026}.
This chapter bridges that gap for Hopper specifically \citep{semianalysis2024tma,nvidia2022hopper}.

\paragraph{Roadmap to later chapters.}
Chapter~8 specializes TMA double-buffer theory; Chapter~9 sync hierarchy; Chapter~10 softmax carriers; Chapter~11 full MegaKernel assembly \citep{dao2022flashattention,dao2023flashdecoding,taxbreak2026,yirage2026}.
Hopper bounds here are prerequisites---later chapters reference these labels rather than re-derive capacities \citep{nvidia2022hopper,semianalysis2024tma}.

\paragraph{Open research threads.}
Dynamic shapes without re-capture, multi-GPU tensor-parallel MegaKernels, and MoE expert-local fusion remain active \citep{liu2024deepseekv3,kwon2023vllm,patel2025llminference}.
This chapter documents single-GPU batch-1 baselines engineers can extend \citep{taxbreak2026,memoryfloor2026}.

\paragraph{Industrial narrative (closing practice section).}
Goodput engineering on Hopper is measurable: launches/token, bytes/token, ms/token together \citep{taxbreak2026,memoryfloor2026,patel2025llminference,dlbook}.
Skillful residency beats SKU shopping when $R_{\mathrm{floor}}$ is low \citep{memoryfloor2026,taxbreak2026,dao2022flashattention,yirage2026}.

\subsection{Engineering patterns}
\paragraph{Pattern 1: Fused layer skeleton.}
\textbf{Scene:} single-layer decode on Hopper \citep{taxbreak2026}.
\textbf{Solution:} TMA load $\rightarrow$ QKV MMA $\rightarrow$ KV loop with online softmax $\rightarrow$ SwiGLU $\rightarrow$ residual---no activation HBM stores \citep{dao2022flashattention,semianalysis2024tma}.
\textbf{Benefit:} ${\sim}6$--$8$ HBM round trips removed; launches drop from ${\sim}12$ to $1$ per layer \citep{memoryfloor2026}.
\textbf{Notes:} pre-compute shared-memory + register budget (Section~\ref{sec:cuda_memory_hierarchy}) \citep{yirage2026}.

\paragraph{Pattern 2: Context buckets + CUDA Graphs.}
\textbf{Scene:} production ctx $\in\{512,2048,8192\}$ \citep{kwon2023vllm,nvidia2024cudagraphs}.
\textbf{Solution:} separate captured graphs per bucket; static loop bounds inside MegaKernel \citep{yirage2026}.
\textbf{Benefit:} launches/token collapse without changing math \citep{taxbreak2026}.
\textbf{Notes:} graphs without fusion still pay full bytes/token \citep{memoryfloor2026}.

\paragraph{Pattern 3: Warp-specialized TMA.}
\textbf{Scene:} KV loop memory-bound \citep{semianalysis2024tma}.
\textbf{Solution:} dedicated warps issue TMA while MMA warps consume previous tile \citep{nvidia2022hopper}.
\textbf{Benefit:} raises TMA/MMA overlap ratio \citep{patel2025llminference}.
\textbf{Notes:} misbalanced roles stall the pipeline \citep{yirage2026}.

\paragraph{Pattern 4: Softmax on shuffle + SFU.}
\textbf{Scene:} attention decode \citep{dao2022flashattention}.
\textbf{Solution:} max via warp shuffle; \textbf{exp2} on SFU; carriers in FP32 \citep{dlbook,liu2024deepseekv3}.
\textbf{Benefit:} avoids extra global softmax materialization \citep{memoryfloor2026}.
\textbf{Notes:} Chapter~10 owns numerics; this chapter owns placement \citep{dao2022flashattention}.

\paragraph{Pattern 5: Graph + fusion composition.}
\textbf{Scene:} H100 cell with low $R_{\mathrm{floor}}$ \citep{memoryfloor2026}.
\textbf{Solution:} fuse first, capture graph second \citep{nvidia2024cudagraphs,taxbreak2026}.
\textbf{Benefit:} bytes and launches both move \citep{patel2025llminference}.
\textbf{Notes:} ablation rows must label which lever moved \citep{memoryfloor2026}.

\paragraph{Pattern 7: PagedAttention inside MegaKernel.}
\textbf{Scene:} production serving with vLLM block tables \citep{kwon2023vllm}.
\textbf{Solution:} device-side block index walk; gather or per-block TMA inside KV loop \citep{dao2023flashdecoding,yirage2026}.
\textbf{Benefit:} keeps paging without per-op launches \citep{taxbreak2026}.
\textbf{Notes:} hardest Hopper integration point---profile at 8K and 32K ctx \citep{patel2025llminference}.

\paragraph{Pattern 6: Triplet parity.}
\textbf{Scene:} fleet with GPU + NPU endpoints \citep{amd2024xdna,patel2025llminference}.
\textbf{Solution:} same IR, three backends; compare normalized bytes/token \citep{yirage2026}.
\textbf{Benefit:} prevents GPU-only schedule drift \citep{chen2020compilerbasedhardw}.

Adding a convenience buffer beyond Table~\ref{tab:ch04_smem_budget} triggers spill or occupancy collapse---recompute the sheet before merge \citep{yirage2026,dao2022flashattention,semianalysis2024tma,nvidia2022hopper}.

\paragraph{Profile interpretation for the case.}
After fusion, Systems should show one launch per layer; Compute should show lower DRAM throughput with similar MMA instruction counts \citep{taxbreak2026,nvidia2024cudagraphs,patel2025llminference}.
If TC utilization rises but Table~\ref{tab:ch04_worked_results} ms/token is flat, the team optimized the wrong row \citep{memoryfloor2026}.
Contrast with L4 and XDNA exports of the same IR to keep fleet decisions honest \citep{amd2024xdna,memoryfloor2026,yirage2026}.

\paragraph{Unfused baseline narrative.}
Operator-first stacks pay TaxBreak launch counts \emph{and} Memory-Floor activation bytes \citep{taxbreak2026,memoryfloor2026}.
Hopper fusion attacks both; graphs alone attack only launches \citep{nvidia2024cudagraphs,patel2025llminference}.
Table~\ref{tab:ch04_worked_results} is the template for your model row---replace numbers, keep columns \citep{yirage2026,taxbreak2026}.

\paragraph{Review question.}
A teammate proposes TMA on every $1{\times}128$ score fragment but still stores attention output to global before MLP \citep{memoryfloor2026,dao2022flashattention}.
Ask: what happens to bytes/token and Chapter~10 carrier residency? \citep{yirage2026,dao2022flashattention}
Correct answer: bytes stay high; MegaKernel legality fails despite pretty TMA timelines \citep{memoryfloor2026,patel2025llminference}.

\paragraph{KV loop structure.}
For each KV block: TMA $K/V$ tiles, MMA $QK^\top$, online softmax update, MMA $PV$ accumulate \citep{dao2022flashattention,semianalysis2024tma,dao2023flashdecoding}.
The loop body must stay inside the same capture region as QKV and MLP---exporting partial attention between blocks reopens bytes/token \citep{memoryfloor2026,yirage2026,taxbreak2026}.

\paragraph{Residual update placement.}
Final residual can be in-place in shared memory when dimensions align \citep{dao2022flashattention,yirage2026}.
A global residual write mid-layer is another $\Theta(d)$ export---flag in review \citep{memoryfloor2026,chen2020compilerbasedhardw}.

\paragraph{GQA head accounting.}
Grouped-query attention reduces KV heads versus Q heads---KV loop traffic scales with KV head count, not Q count \citep{kwon2023vllm,dao2022flashattention,taxbreak2026}.
Worked example uses 16 Q / 4 KV; adjust line items for your architecture \citep{yirage2026,patel2025llminference}.

\subsection{Five common Hopper decode anti-patterns}
\begin{enumerate}
\item \textbf{TMA everywhere} on $M{=}1$ micro-tiles.
\emph{Symptom:} TMA/MMA busy ratio ${<}0.3$ with flat ms/token \citep{semianalysis2024tma}.
\emph{Debug:} compare vector-load path; reject tiles below ${\sim}128{\times}128$ \citep{taxbreak2026,dlbook}.

\item \textbf{TC utilization chasing} while bytes/token flat.
\emph{Symptom:} TC utilization rises, Table~\ref{tab:ch04_worked_results} ms/token unchanged \citep{memoryfloor2026}.
\emph{Debug:} Nsight DRAM bytes first; return to pyramid level~1 \citep{patel2025llminference}.

\item \textbf{Occupancy tuning} that accepts register spill.
\emph{Symptom:} high occupancy, rising \texttt{local memory loads} \citep{yirage2026}.
\emph{Debug:} spill counters versus Table~\ref{tab:ch04_smem_budget} high-water \citep{memoryfloor2026}.

\item \textbf{Graph capture without fusion.}
\emph{Symptom:} launches/token collapse, bytes/token flat (Table~\ref{tab:ch04_ablation}, row~2) \citep{nvidia2024cudagraphs}.
\emph{Debug:} ablation row must show bytes moving, not only launches \citep{memoryfloor2026}.

\item \textbf{Fusion without capacity sheet.}
\emph{Symptom:} kernel runs, shared high-water exceeds 227\,KB usable, silent spill \citep{nvidia2022hopper}.
\emph{Debug:} static Table~\ref{tab:ch04_smem_budget}; treat spill as compile failure \citep{yirage2026,memoryfloor2026}.
\end{enumerate}

\section{Key Takeaways}
\label{sec:ch04_key_takeaways}

\begin{itemize}
\item \textbf{Priority principle.}
Hopper decode: cut HBM activation traffic, then launches, then latency, then TC \citep{memoryfloor2026,taxbreak2026}.
\textbf{Action:} follow Figure~\ref{fig:hopper_priority_pyramid}; reject PRs that invert the order \citep{patel2025llminference}.

\item \textbf{Residency boundary principle.}
227\,KB usable shared memory and the register file are hard fusion caps---spill means failure \citep{nvidia2022hopper,yirage2026}.
\textbf{Action:} attach static byte sheets; treat spill counters as build breaks \citep{memoryfloor2026}.

\item \textbf{Async copy principle.}
TMA hides latency; fusion removes bytes---compose both, confuse neither \citep{semianalysis2024tma,memoryfloor2026}.
\textbf{Action:} verify bytes/token dropped before celebrating TMA overlap \citep{patel2025llminference}.

\item \textbf{Minimal sync principle.}
Warp shuffle $\rightarrow$ CTA sync $\rightarrow$ cluster barrier; never grid sync per token \citep{dao2022flashattention,nvidia2022hopper}.
\textbf{Action:} audit barrier placement on fused DAG edges only \citep{yirage2026}.

\item \textbf{Verification principle.}
launches/token, bytes/token, and ms/token must move together---TC utilization alone is invalid evidence \citep{taxbreak2026,memoryfloor2026}.
\textbf{Action:} store Table~\ref{tab:ch04_worked_results} and Table~\ref{tab:ch04_ablation} rows in CI artifacts; compare against Table~\ref{tab:hopper_priority_pyramid} before merge \citep{yirage2026,patel2025llminference}.
\end{itemize}
